## 도메인 개요

전시(Display) 도메인은 고객앱 화면의 **시각적 구성 요소**를 어드민에서 관리하는 기능이다.
3계층 구조로 이루어진다.

```
섹션종류 (SectionType)     → 재사용 가능한 UI 블록 타입 정의 (필드 스키마 포함)
    ↓ 참조
템플릿 (Template)          → XML로 와이어프레임 구조를 정의하고 각 area에 섹션종류를 지정
                             페이지 생성 시 XML을 파싱하여 초기 섹션 구성을 복사 생성
    ↓ 복사(XML 파싱)
페이지 (DisplayPage)       → 실제 게시되는 전시 페이지 (섹션별 콘텐츠 데이터 포함)
```

**템플릿 XML 구조 (와이어프레임)**:
```xml
<template id="TPL-001" name="홈 기본" type="HOME">
  <row seq="1">
    <area seq="1" label="메인 배너" width="full" sectionType="HERO_BANNER" required="true"/>
  </row>
  <row seq="2">
    <area seq="1" label="추천 상품" width="full" sectionType="PRODUCT_CAROUSEL" required="false"/>
  </row>
  <row seq="3">
    <area seq="1" label="왼쪽 이미지" width="1/2" sectionType="IMAGE_LINK" required="false"/>
    <area seq="2" label="오른쪽 이미지" width="1/2" sectionType="IMAGE_LINK" required="false"/>
  </row>
</template>
```

| XML 요소 | 주요 속성 | 설명 |
|---------|---------|------|
| `<template>` | id, name, type | 템플릿 메타정보 |
| `<row>` | seq | 수평 행 (위→아래 순서) |
| `<area>` | seq, label, width, sectionType, required | 영역 (열 분할) |

- `width`: full / 1/2 / 1/3 / 2/3
- `sectionType`: ACTIVE 상태 섹션종류 코드만 허용

## 공통 코드

### 페이지 유형 (PAGE_TYPE)
| 코드 | 라벨 |
|------|------|
| HOME | 홈 |
| CATEGORY | 카테고리 |
| EXHIBITION | 기획전 |
| EXHIBITION_MAIN | 기획전 메인 |
| PROMOTION | 프로모션 |
| BRAND | 브랜드 |

### 페이지 상태 (PAGE_STATUS)
| 코드 | 라벨 |
|------|------|
| PUBLISHED | 게시중 |
| SCHEDULED | 예약 |
| DRAFT | 미게시 |
| DEPRECATED | 폐기 |

### 섹션종류 상태
| 코드 | 라벨 |
|------|------|
| ACTIVE | 활성 |
| INACTIVE | 비활성 |
| DEPRECATED | 폐기 |

### 섹션 필드 타입 (FIELD_TYPE)
| 코드 | 설명 |
|------|------|
| 이미지 | imageUrl + linkUrl + altText + linkTarget 4개 속성 |
| 텍스트 | 단문/장문 + 플레이스홀더 |
| 링크 | URL |
| 색상 | HEX 색상값 |
| 숫자 | 정수/소수 |
| 날짜시간 | datetime |
| 노출선택 | Layered / Carousel / Tiled |
| 상품 | 상품 ID 선택 |
| 이미지배열 | N개 이미지 아이템 (각 4속성 + visible + sortOrder) |
| 상품배열 | N개 상품 (검색 팝업) |
| 텍스트배열 | N개 텍스트 |
