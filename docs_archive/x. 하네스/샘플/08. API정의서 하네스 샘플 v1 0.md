# ⑧ API 정의서 — Harness 샘플

> **샘플**: ORD-001 주문 생성 API

---

## 문서 헤더

```yaml
api_id: ORD-001
api_name: 주문 생성
domain: Order
type: C                             # C=개발주도 (기획·화면에서 도출)
source_req: FR-ORD-001              # ① 원천 요구사항
source_policy: POL-ORD-001, POL-ORD-002  # ② 배송비 정책, 쿠폰 정책
source_domain: DOM-ORDER            # ③ 도메인 정의
source_process: BPM-ORD-001         # ④ 업무흐름
source_screen: CUS-040              # ⑤ 주문서 화면
source_entity: ord_order, ord_order_item, ord_platform_order  # ⑥ ERD
source_tech: TC-001, TC-002, TC-007  # ⑦ 기술 제약
```

## 6개 Harness 종합

```
[Context Harness]                           ← ③ DOM-ORDER 참조 + Sequence 서브산출물
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
bounded_context: (DOM-ORDER 참조 — 주문 생성~구매확정 범위)
dependencies: (AI-H6 — Catalog, Promotion, Member 동기 호출 / Payment, Notification 비동기)
communications: (AI-H6 참조)

endpoint:
  method: POST
  path: /api/v1/orders
  auth: JWT 로그인 필수
  role: [CUSTOMER]

sequence_ref: SEQ-ORD-001           # ⑧-1 Sequence 서브산출물 참조

[Requirements Validation Harness]           ← ⑤ CUS-040 화면정의에서 도출
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
request:
  | 필드 | 타입 | 필수 | 제약조건 |
  |------|------|------|---------|
  | cartItemIds | List<Long> | Y | 1개 이상, 본인 장바구니 상품만 |
  | couponId | Long | N | 유효한 쿠폰 ID, NULL 허용 |
  | pointAmount | Long | N | 0 이상, 보유 포인트 이하, NULL=0 처리 |
  | deliveryAddressId | Long | Y | 본인 등록 배송지 ID |

response:
  success:
    status: 201
    body: |
      {
        "orderId": 1001,
        "orderNo": "ORD20260703001",
        "finalAmount": 47000,
        "orderStatus": "TEMP",
        "paymentUrl": "/orders/1001/payment"
      }
  error_catalog:
    - {code: OUT_OF_STOCK,          http: 409, condition: "선택 상품 재고 부족",             message_key: "error.order.out_of_stock"}
    - {code: COUPON_EXPIRED,        http: 422, condition: "쿠폰 만료일 초과",               message_key: "error.coupon.expired"}
    - {code: COUPON_ALREADY_USED,   http: 422, condition: "이미 사용된 쿠폰",               message_key: "error.coupon.already_used"}
    - {code: COUPON_MIN_AMOUNT,     http: 422, condition: "최소 주문 금액 미달",             message_key: "error.coupon.min_amount"}
    - {code: POINT_INSUFFICIENT,    http: 422, condition: "포인트 잔액 부족",               message_key: "error.point.insufficient"}
    - {code: CART_ITEMS_EMPTY,      http: 400, condition: "cartItemIds 빈 배열",            message_key: "error.cart.items_empty"}
    - {code: CART_ITEM_NOT_OWNED,   http: 403, condition: "타인 장바구니 상품 포함",         message_key: "error.cart.not_owned"}

cross_field_rules:
  - rule: "pointAmount + couponDiscount <= subtotal (최종 금액 음수 방지)"
  - rule: "cartItemIds의 모든 상품이 요청자 member_id 소유여야 함"

[Domain Constraint Harness]                 ← ①② 에서 상속
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
HARD:
  - HC-ORD-001: 재고 부족 상품 주문 금지 (출처: FR-ORD-001)
  - HC-ORD-002: 보유 포인트 초과 사용 금지 (출처: FR-ORD-001)
  - HC-ORD-003: 만료·사용된 쿠폰 적용 금지 (출처: FR-ORD-001)
  - HC-ORD-004: 주문 수량 1 이상 (출처: FR-ORD-001)
  - TC-001: 물리적 DELETE 금지 (출처: 기술정의서)
  - TC-007: Outbox INSERT는 @Transactional 내 (출처: 기술정의서)
SOFT:
  - POL-ORD-001: 배송비 부과 정책 (5만원 기준, 도서산간 추가)
  - POL-ORD-002: 쿠폰 할인 계산 정책 (정액/정률)

[Data Contract Harness]                     ← ⑥ ERD 참조 + Data Contract 서브산출물
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
invariants: (⑥ AI-H15 참조 — final_amount 계산 일치, 음수 방지)
state_transition: (⑥ AI-H16 참조 — 초기 상태: TEMP)
soft_delete: (⑥ AI-H17 참조)

data_contract_ref: DC-ORD-001       # ⑧-2 Data Contract 서브산출물 참조

[Output Schema Harness]                     ← ⑦ 기술정의 상속 + API별 직접 작성
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
layer: Controller → Service → Repository (com.runnshop.order.*)
pattern: Command (쓰기)
expected_classes:
  - CustomerOrderController          # POST /api/v1/orders 진입점
  - AdminOrderController             # 관리자용 동일 로직 (TC-006)
  - OrderService                     # 비즈니스 로직, @Transactional
  - OrderRepository                  # INSERT ord_order, ord_order_item, ord_platform_order
  - OutboxRepository                 # INSERT ord_outbox
  - CreateOrderRequest               # 요청 DTO
  - CreateOrderResponse              # 응답 DTO
transaction_annotation: "@Transactional(readOnly = false) on OrderService.createOrder()"
event_publishing:
  timing: AFTER_COMMIT (Outbox 스케줄러)
  method: OutboxRepository.save() → Kafka (OutboxPublisherBatch)

[Feedback Loop Harness]                     ← ① AI-H2에서 분배
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
test_scenarios:
  - "정상 주문 생성 → 201 Created, orderId 반환"
  - "재고 부족 → 409 OUT_OF_STOCK"
  - "쿠폰 만료 → 422 COUPON_EXPIRED"
  - "포인트 초과 → 422 POINT_INSUFFICIENT"
  - "빈 cartItemIds → 400 CART_ITEMS_EMPTY"
  - "타인 장바구니 상품 → 403 CART_ITEM_NOT_OWNED"
  - "비로그인 → 401 UNAUTHORIZED"
quality_gate:
  p95_latency: 1000ms
  test_coverage: 80%
```
