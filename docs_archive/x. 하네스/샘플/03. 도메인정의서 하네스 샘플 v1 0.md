# ③ 도메인 정의서 — Harness 샘플

> **샘플 도메인**: Order (DOM-ORDER)

---

## 기본 섹션

```
도메인 ID       : DOM-ORDER
도메인명        : Order
핵심 책임       : 주문 생명주기 오케스트레이션 (생성 → 결제 → 배송 → 구매확정)
레이어          : 거래
상태            : CONFIRMED

[도메인 범위 (Bounded Context)]
• 시작: 고객이 주문서를 진입하는 시점
• 종료: 구매확정(CONFIRMED) 또는 반품완료(RETURN_COMPLETED)
• 소유 엔티티: ord_platform_order, ord_order, ord_order_item, ord_cart, ord_outbox
• 소유 이벤트: ORDER_CREATED, ORDER_CONFIRMED, ORDER_CANCELLED,
               CANCEL_REQUESTED, RETURN_REQUESTED, EXCHANGE_REQUESTED

[도메인 간 관계]
• 동기 호출 대상: Catalog(재고 확인·예약), Member(포인트 잔액 확인), Promotion(쿠폰 유효성·할인 계산)
• 비동기 이벤트 발행 대상: Payment(결제 요청), Notification(알림), Settlement(정산 집계)
• 복제 테이블 참조: cat_product_replica(상품명·이미지), mbr_member_replica(회원 정보)
```

  - "OrderService에서 cat_sku_stock 테이블 직접 UPDATE (재고 직접 차감)"
