# ⑥ ERD (엔티티 정의서) — Harness 샘플

> **샘플 도메인**: Order / **테이블**: ord_order (주문 헤더)

## 기본 섹션

```
테이블명       : ord_order
도메인         : Order
설명           : 입점사별 주문 헤더 (플랫폼 주문 1건 → 입점사별 N건)

[컬럼 정의]
| # | 컬럼명 | 타입 | 필수 | 기본값 | 설명 |
|---|--------|------|------|--------|------|
| 1 | order_id | BIGINT | Y | auto_increment | PK |
| 2 | platform_order_id | BIGINT | Y | - | FK → ord_platform_order.platform_order_id |
| 3 | order_no | VARCHAR(20) | Y | - | 주문번호 (노출용, 불변) 예: ORD20260703001 |
| 4 | member_id | BIGINT | Y | - | FK → mbr_member.member_id (불변) |
| 5 | vendor_id | BIGINT | Y | - | FK → vnd_vendor.vendor_id |
| 6 | order_status | VARCHAR(30) | Y | 'TEMP' | 주문 상태 |
| 7 | subtotal | BIGINT | Y | - | 상품 합계 (할인 전, 원 단위) |
| 8 | shipping_fee | BIGINT | Y | 0 | 배송비 |
| 9 | discount_amount | BIGINT | Y | 0 | 쿠폰+포인트 할인 합계 |
| 10 | final_amount | BIGINT | Y | - | 최종 결제 금액 |
| 11 | coupon_id | BIGINT | N | NULL | 사용 쿠폰 ID |
| 12 | point_used | BIGINT | Y | 0 | 사용 포인트 |
| 13 | delivery_address_id | BIGINT | Y | - | FK → mbr_delivery_address |
| 14 | is_deleted | BOOLEAN | Y | FALSE | 소프트 삭제 플래그 |
| 15 | created_at | TIMESTAMP | Y | NOW() | 생성일시 (불변) |
| 16 | updated_at | TIMESTAMP | Y | NOW() | 수정일시 |

[인덱스]
| 인덱스명 | 컬럼 | 유형 | 비고 |
|---------|------|------|------|
| idx_ord_order_platform | platform_order_id | NORMAL | 플랫폼 주문별 입점사 주문 조회 |
| idx_ord_order_member | member_id, created_at DESC | NORMAL | 회원 주문 목록 (최신순) |
| idx_ord_order_vendor | vendor_id, order_status | NORMAL | 입점사 주문 관리 |
| idx_ord_order_status | order_status, created_at | NORMAL | 배치 상태별 주문 조회 |

[관계]
• FK: platform_order_id → ord_platform_order.platform_order_id
• FK: member_id → mbr_member.member_id
• FK: vendor_id → vnd_vendor.vendor_id
• FK: delivery_address_id → mbr_delivery_address.address_id
• 1:N: ord_order → ord_order_item
```
