### API 레벨 영속성 계약 (직접 작성)

```yaml
persistence:
  target_tables:
    - ord_platform_order   # INSERT (플랫폼 주문 묶음 헤더)
    - ord_order            # INSERT (입점사별 주문, 1건 이상)
    - ord_order_item       # INSERT (주문 상품 라인, N건)
    - ord_outbox           # INSERT (ORDER_CREATED 이벤트)
    # 복제 테이블 READ ONLY: cat_product_replica, mbr_member_replica (write 금지)
```

#### read_fields (이 API가 조회하는 필드)

| 필드 | 테이블 | 조건 | 비고 |
|------|--------|------|------|
| cart_item_id, sku_id, quantity, unit_price | ord_cart | WHERE cart_item_id IN (:ids) AND member_id = :memberId AND is_deleted = FALSE | 장바구니 → 주문 변환 |
| sku_id, stock_qty | cat_sku_stock_replica | WHERE sku_id IN (:skuIds) AND is_deleted = FALSE | CatalogPublicApi 내부 조회 (복제 READ ONLY) |
| member_id, point_balance, grade | mbr_member_replica | WHERE member_id = :memberId AND is_deleted = FALSE | 포인트 잔액 확인 |
| coupon_id, discount_type, discount_value, discount_rate, min_order_amount, expired_at, used | prm_coupon | WHERE coupon_id = :couponId | PromotionPublicApi 내부 조회 |
| vendor_id | cat_product_replica | WHERE sku_id IN (:skuIds) | 입점사별 주문 분리 기준 |
| zip_code 범위 | cfg_island_zipcode | WHERE zip_code = :zip | 도서산간 배송비 기준 |

#### write_fields (이 API가 기록하는 필드)

| 필드 | 테이블 | 액션 | 비고 |
|------|--------|------|------|
| platform_order_id, member_id, total_subtotal, total_shipping_fee, total_discount, final_amount, created_at | ord_platform_order | INSERT | 플랫폼 주문 묶음 |
| order_id, platform_order_id, order_no, member_id, vendor_id, order_status='TEMP', subtotal, shipping_fee, discount_amount, final_amount, coupon_id, point_used, delivery_address_id, created_at | ord_order | INSERT (입점사별 N건) | 입점사별 주문 |
| order_item_id, order_id, sku_id, product_name, option_name, quantity, unit_price, total_price | ord_order_item | INSERT (상품별 M건) | 주문 상품 라인 |
| outbox_id, event_type='ORDER_CREATED', aggregate_id=orderId, payload(JSON), created_at, published=FALSE | ord_outbox | INSERT | Outbox 이벤트 |
