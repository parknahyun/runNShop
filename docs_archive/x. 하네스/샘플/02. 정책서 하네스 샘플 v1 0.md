# ② 정책서 — Harness 샘플

> **샘플 도메인**: Order / **정책**: POL-ORD-001 배송비 정책, POL-ORD-002 쿠폰 적용 정책

## POL-ORD-001 배송비 정책

### 기본 섹션

```
정책 ID        : POL-ORD-001
정책명          : 주문 배송비 부과 정책
적용 도메인     : Order
적용 대상       : 고객 (전체)
우선순위        : 1
상태            : CONFIRMED
변경 이력       : 2026-07-03 최초 작성

[정책 내용]
상품 합계 금액(쿠폰·포인트 적용 전)이 50,000원 미만이면 배송비 3,000원을 부과한다.
50,000원 이상이면 무료 배송이다.
도서·산간 지역(제주도·울릉도 등)은 추가 배송비 3,000원이 부과된다.

[적용 조건]
• 상품 합계 = 주문 상품들의 (단가 × 수량) 합산
• 도서산간 여부: 배송지 우편번호 기준 (zip_code 범위 테이블 참조)
• 쿠폰·포인트 할인 후 금액이 아닌 상품 원가 합계 기준

[예외 처리]
• 무료배송 쿠폰 적용 시 → 배송비 면제 (도서산간 추가 배송비도 면제)
• 입점사별 배송비 정책이 별도 설정된 경우 → 입점사 정책 우선
```

### AI 보강 섹션

```
[AI-H3] 정책 코드화 (실행 가능한 규칙)      ← Domain Constraint Harness (원천)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
constraint_type: SOFT

rule_expression: |
  subtotal = SUM(item.unit_price × item.quantity)   # 할인 전 상품 합계
  
  IF has_free_shipping_coupon THEN
    shipping_fee = 0
  ELSE IF subtotal >= 50000 THEN
    shipping_fee = 0
  ELSE
    shipping_fee = 3000
  
  IF is_island_area(delivery_zip_code) AND NOT has_free_shipping_coupon THEN
    shipping_fee += 3000

applies_to:
  - req_id: FR-ORD-001   # 고객 주문 생성

wrong_pattern: |
  - subtotal 계산 시 쿠폰 할인 후 금액 기준으로 계산 (정책은 할인 전 기준)
  - 무료배송 쿠폰 적용 시에도 도서산간 추가 배송비를 부과
  - shipping_fee를 하드코딩(3000)으로 작성 (Config 테이블에서 조회해야 함)

[AI-H4] 변경 영향 범위                      ← Context Harness (전파 추적)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
affected_domains: [Order, Settlement]
affected_apis: [ORD-001 주문 생성, ORD-005 주문 금액 재계산]
affected_batches: []
change_frequency: 낮음

※ 배송비 금액(3000원, 50000원 기준선)은 Config 테이블에서 관리
  → AI 코딩 지시: "배송비 금액은 ShippingConfig.findByKey()로 조회"
```

## POL-ORD-002 쿠폰 적용 정책

### 기본 섹션

```
정책 ID        : POL-ORD-002
정책명          : 주문 쿠폰 적용 정책
적용 도메인     : Order, Promotion
적용 대상       : 고객 (전체)
우선순위        : 1
상태            : CONFIRMED
변경 이력       : 2026-07-03 최초 작성

[정책 내용]
주문 1건당 1개의 쿠폰만 적용할 수 있다.
쿠폰 적용 대상: 전체 주문 쿠폰 / 특정 카테고리 쿠폰 / 특정 입점사 쿠폰
할인 방식: 정액 할인(discount_value원) / 정률 할인(discount_rate%)
최소 주문 금액(min_order_amount) 미달 시 쿠폰 적용 불가

[예외 처리]
• 쿠폰 만료(expired_at < 현재) → 적용 불가, COUPON_EXPIRED 오류
• 쿠폰 이미 사용(used=TRUE) → 적용 불가, COUPON_ALREADY_USED 오류
• 최소 주문 금액 미달 → 적용 불가, COUPON_MIN_AMOUNT_NOT_MET 오류
```

### AI 보강 섹션

```
[AI-H3] 정책 코드화 (실행 가능한 규칙)      ← Domain Constraint Harness (원천)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
constraint_type: HARD

rule_expression: |
  # 쿠폰 유효성 검증
  IF coupon.expired_at <= NOW()       THEN RAISE COUPON_EXPIRED
  IF coupon.used == TRUE              THEN RAISE COUPON_ALREADY_USED
  IF subtotal < coupon.min_order_amt  THEN RAISE COUPON_MIN_AMOUNT_NOT_MET
  
  # 할인 금액 계산
  IF coupon.discount_type == "FIXED"  THEN discount = coupon.discount_value
  IF coupon.discount_type == "RATE"   THEN discount = FLOOR(subtotal × coupon.discount_rate / 100)
  
  # 최종 금액 (음수 방지)
  final_amount = MAX(0, subtotal - discount - point_amount + shipping_fee)

applies_to:
  - req_id: FR-ORD-001   # 고객 주문 생성

wrong_pattern: |
  - discount_rate를 퍼센트가 아닌 소수로 처리 (0.1 × subtotal vs 10% × subtotal)
  - 쿠폰 사용 처리(used=TRUE 업데이트)를 주문 생성과 별도 트랜잭션으로 처리
  - final_amount에 음수 방지(MAX(0, ...)) 없이 계산

[AI-H4] 변경 영향 범위                      ← Context Harness (전파 추적)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
affected_domains: [Order, Promotion, Settlement]
affected_apis: [ORD-001 주문 생성, PRM-010 쿠폰 발급]
affected_batches: [CouponExpireBatch]
change_frequency: 보통
```
