# ③ 도메인 정의서 (BC·모듈 설계) — Harness 표준양식

- **매핑 Harness**: Context Harness (공간축 원천)
- **원천 작성 항목**: 도메인 경계 규칙, 모듈 간 통신 계약, 의존 방향 제약
- **AI-H**: AI-H5 (도메인 경계), AI-H6 (통신 계약), AI-H7 (의존 방향)

---

## 기본 섹션 (일반 방법론)

```
도메인 ID       : DOM-{도메인명}          (예: DOM-ORDER)
도메인명        : 
핵심 책임       : 
레이어          : 거래 / 상품 / 고객 / 혜택 / 파트너 / 운영
상태            : DRAFT / CONFIRMED

[도메인 범위 (Bounded Context)]
• 시작: 
• 종료: 
• 소유 엔티티: 
• 소유 이벤트: 

[도메인 간 관계]
• 동기 호출 대상: 
• 비동기 이벤트 발행 대상: 
• 복제 테이블 참조: 
```

## AI 보강 섹션

```
[AI-H5] 도메인 경계 규칙                     ← Context Harness (공간축 원천)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
boundary_rules:
  - "{도메인}은 {타 도메인} 테이블에 직접 접근 금지 (PublicApi 또는 복제 테이블만)"
  - "{도메인}이 {타 도메인} 로직을 직접 수행 금지 (이벤트 발행으로 위임)"
  - "타 도메인이 {prefix}_ 테이블에 직접 INSERT/UPDATE 금지"

wrong_patterns:
  - "{Domain}Service에서 {타도메인 prefix}_ 테이블 직접 조회/변경"
  - "{타도메인}Service에서 {prefix}_테이블.status를 직접 변경"
  - "Repository에서 타 도메인 prefix 테이블 JOIN"

[AI-H6] 모듈 간 통신 계약                    ← Context Harness (공간축 원천)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
communications:
  - target: {도메인명}
    type: SYNC_API / ASYNC_EVENT / REPLICA_TABLE
    interface: "{PublicApi 메서드명 또는 이벤트명}"
    failure_action: ""
    outbox: true / false         # ASYNC_EVENT인 경우만

  - target: {도메인명}
    type: REPLICA_TABLE
    table: {prefix}_replica
    sync: "{배치명} ({주기})"
    usage: "READ ONLY"

[AI-H7] 의존 방향 제약                       ← Context Harness (공간축 원천)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
allowed_dependencies:
  - {도메인} (동기)
  - {도메인} (동기 + 복제)

forbidden_dependencies:
  - "{타 도메인} → {이 도메인} 직접 호출 금지 (이벤트만 수신)"

dependency_direction: |
  {이 도메인} → {도메인A} ✅
  {이 도메인} → {도메인B} ✅ (이벤트)
  {도메인B} → {이 도메인} ❌ (역방향 금지)
```

---

## 작성 기준

| 항목 | 기준 |
|------|------|
| boundary_rules | AI가 코드 생성 시 모듈 경계를 넘지 않도록 하는 제약 (3개 이상) |
| wrong_patterns | AI가 흔히 저지르는 경계 위반 패턴 (구체적인 코드 패턴으로 표현) |
| communications | SYNC_API / ASYNC_EVENT / REPLICA_TABLE 중 택일하여 모든 타 도메인 통신 정의 |
| outbox | ASYNC_EVENT이면 반드시 outbox: true 명시 |
| forbidden_dependencies | 역방향 호출을 AI가 코드로 구현하지 못하도록 명시적 금지 |

## 하위 문서 역참조 경로

```
DOM-{DOM}
  └─ 공간축 원천 → ⑧ API정의서 Context Harness에서 참조
  └─ 통신 계약  → ④ 업무흐름 동기/비동기 구분(AI-H10)으로 연결
  └─ 복제 테이블 → ⑥ ERD의 AI-H18 복제 테이블 규칙과 연계
```
