## 1. 문서 개요

### 1.1 시스템 개요

runNshop은 러닝 전문 e커머스 플랫폼으로 3개 애플리케이션으로 구성된다.

| 애플리케이션 | URL | 대상 | 채널 |
|-----------|-----|------|------|
| 고객 웹 | www.runNshop.com | 일반 고객 | 모바일 웹 (360px) |
| 플랫폼 어드민 | admin.runNshop.com | 플랫폼 운영자 | PC 웹 |
| 입점사 BO | partners.runNshop.com | 입점사 담당자 | PC 웹 |

### 1.2 기술 스택

| 항목 | 기술 |
|------|------|
| 백엔드 | Spring Boot + Kotlin |
| 프론트엔드 | React + Next.js |
| DB | PostgreSQL + MyBatis |
| 캐시 | Redis |
| 검색 | Elasticsearch |
| 파일 | AWS S3 |
| 이벤트 | Outbox Pattern |
| 배포 | Docker Compose → Kubernetes |

### 1.3 아키텍처

- Modular Monolith (1단계) → MSA (2단계)
- 12개 Bounded Context
- 107개 DB 테이블 + 5개 복제 테이블

## 2. 플랫폼 공통

### FR-COM-001 다국어 지원
- **우선순위**: P3
- **내용**: 1단계 한국어 단일 언어. 2단계 다국어 확장 고려
- **제약**: 현재 한국어만 지원

### FR-COM-002 직매입 운영
- **우선순위**: P1
- **내용**:
  - 플랫폼 직매입 전용 입점사 계정 기초 데이터 생성
  - vendor_id=1 예약, is_platform_direct=TRUE
  - 정산 계산 제외
  - 상품 등록·배송·클레임 어드민 처리

### FR-COM-003 알림 발송
- **우선순위**: P1
- **내용**:
  - 채널 우선순위: 카카오 알림톡 → SMS → 이메일 (Fallback)
  - 야간 차단: 22시~08시 마케팅 알림
  - 거래 알림: 24시간 필수 발송
  - 재시도: 최대 3회 (즉시→30초→1분)
  - 취합 배치: 09·13·18시

### FR-COM-004 Outbox Pattern 이벤트 처리
- **우선순위**: P1
- **내용**:
  - 비즈니스 로직 + Outbox 저장 단일 트랜잭션
  - Consumer 상시 대기·PENDING 즉시 감지
  - 실패 시 DLQ 적재·운영팀 알림
  - 재기동 시 PENDING·PROCESSING 자동 재발행

### FR-COM-005 소프트 삭제
- **우선순위**: P1
- **내용**:
  - 전 테이블 물리적 DELETE 금지
  - is_deleted=TRUE 소프트 삭제만 허용
  - deleted_at·deleted_by 기록

### FR-COM-006 개인정보 보호
- **우선순위**: P1
- **내용**:

  - 회원 목록 조회 시 필수 검색어 입력 필수
  - 접근 이력 자동 기록 (AOP)

## 3. 회원 (Member)

### FR-MBR-001 회원가입
- **우선순위**: P1
- **내용**:
  - 가입 방식: 이메일·네이버·Apple
  - 본인인증: 가입 시 옵션널 (주문 시 필수)
  - 이메일·휴대폰 중복 가입 불가
  - 약관 동의: 이용약관·개인정보 필수, 마케팅 선택
  - 웰컴 쿠폰 자동 발급
- **관련 화면**: CUS-081-01~05
- **관련 API**: `/api/v1/auth/join`

### FR-MBR-002 로그인·인증
- **우선순위**: P1
- **내용**:
  - 이메일·SNS (네이버·Apple) 로그인
  - JWT Access Token + Refresh Token 발급
  - 로그인 실패 5회 → 3일 계정 잠금
  - SNS 로그인 후 장바구니 머지
  - 머지 후 재고·행사 유효성 검사
- **관련 화면**: CUS-080
- **관련 API**: `/api/v1/auth/login`, `/api/v1/auth/social/{provider}`

### FR-MBR-003 SNS OAuth 인증
- **우선순위**: P1
- **내용**:
  - 1단계: 네이버·Apple
  - OAuth URL 생성 → SNS 인증 → Token 교환 → 사용자 정보 수신
  - provider_id 기준 기존 회원 매칭
  - Apple: 이름 최초 1회, 이메일 릴레이 처리
- **관련 API**: `/api/v1/auth/social/{provider}`

### FR-MBR-004 회원 등급 관리
- **우선순위**: P1
- **내용**:
  - 4단계: New·Runner·Pacer·Elite
  - 산정 기준: 최근 3개월 구매금액 + 활동지수
  - 산정 주기: 매월 1일 자동 갱신 (MemberGradeBatch)
  - 하향 유예: 1개월
  - 등급 승급 시 즉시 쿠폰 지급
  - 매년 12/31 등급별 연말 쿠폰 일괄 지급 (YearEndGradeCouponBatch)

| 등급 | 구매금액 | 활동지수 | 적립률 | 무료배송 |
|------|---------|---------|--------|--------|
| New | - | - | 0.5% | 5만원 |
| Runner | 100만원↑ | 10점↑ | 1.0% | 3만원 |
| Pacer | 200만원↑ | 20점↑ | 1.5% | 2만원 |
| Elite | 300만원↑ | 30점↑ | 2.0% | 무조건 |

### FR-MBR-005 포인트 관리
- **우선순위**: P1
- **내용**:
  - 적립: 구매확정 후 등급별 적립률 (최대 1,000원/건)
  - 사용: 1,000원 이상 보유 시, 결제금액 100%까지
  - 유효기간: 3년 (소멸 30일 전 알림)
  - 입점사 부담: 30%
- **관련 테이블**: mbr_point

### FR-MBR-006 쿠폰 관리
- **우선순위**: P1
- **내용**:
  - 보유 쿠폰 목록·사용 이력 조회
  - 쿠폰 적용: 주문서에서 선택
  - 유효기간: 발행일 기준 최대 90일
  - 복원: 취소·반품 시 자동 복원
- **관련 테이블**: mbr_member_coupon, mbr_member_coupon_log

### FR-MBR-007 배송지 관리
- **우선순위**: P1
- **내용**:
  - 최대 5개 배송지 등록
  - 기본 배송지 설정
  - 주문서 진입 시 기본 배송지 자동 선택
- **관련 화면**: CUS-063

### FR-MBR-008 약관 동의 관리
- **우선순위**: P1
- **내용**:
  - 약관 갱신 시 재동의 팝업 강제 노출
  - 필수 약관 미동의 시 서비스 이용 불가
  - 선택 약관 미동의 시 서비스 이용 가능
  - 동의 이력 저장 (mbr_terms_agreement)

### FR-MBR-009 러닝 프로필
- **우선순위**: P2

## 4. 상품·카탈로그 (Catalog)

### FR-CAT-001 카테고리 관리
- **우선순위**: P1
- **내용**:
  - 표준 카테고리: 상품 등록 기준
  - 전시 카테고리: 고객 화면 노출 기준
  - N:M 매핑 (cat_standard_display_category_mapping)
  - 자동 매핑: is_default=TRUE 기준
  - 우선순위: BRAND(2) > CATEGORY(1) > DEFAULT(0)

### FR-CAT-002 상품 등록
- **우선순위**: P1
- **내용**:
  - 6단계: 기본정보·가격·이미지·상세소개·SKU·완료
  - 임시저장(DRAFT) 지원
  - 이미지: 최대 10장·5MB
  - 금지어: BLOCK(차단)·MASK(마스킹)
  - 상품 상세 타입 자동 적용
- **관련 화면**: VND-010-002

### FR-CAT-003 상품 심사
- **우선순위**: P1
- **내용**:
  - 상태: DRAFT → REVIEW_REQUESTED → UNDER_REVIEW → ON_SALE/REJECTED
  - Rekognition 이미지 비동기 분석 (2단계)
  - 반려 3회 이상: MD 특별 검토 플래그
  - 재심사: 거절 후 30일 이후 가능
  - 심사 기간: 7영업일 이내

### FR-CAT-004 재고 관리
- **우선순위**: P1
- **내용**:
  - 3테이블 구조: cat_sku → cat_sku_stock → cat_sku_stock_history
  - 품절 자동 전환: available_quantity=0 → SOLD_OUT
  - 취소 재고 복구: 자동 (SOLD_OUT → ON_SALE)
  - 반품 재고 복구: 수동 (입점사 검수 후)
  - 변경 이력 source: ORDER·CANCEL_RESTORE·RETURN_RESTORE·CATALOG

### FR-CAT-005 상품 미리보기
- **우선순위**: P1
- **내용**:
  - preview_token 발급 (Redis TTL 30분)
  - 고객 화면 기준 렌더링
  - 미리보기 모드 배너 표시
  - 장바구니·구매·찜 비활성

### FR-CAT-006 전시 페이지 관리
- **우선순위**: P1
- **내용**:
  - 유형: 홈·카테고리·기획전
  - 즉시 게시·예약 게시 지원
  - 예약: 페이지당 1개만 허용 (조건부 유니크 인덱스)
  - 운영 중 수정: DRAFT_EDIT 행 별도 생성
  - 편집 잠금: 30분 (동시 편집 방지)

| 상태 | 설명 |
|------|------|
| DRAFT | 최초 작성 중 |
| DRAFT_EDIT | PUBLISHED 수정 중 |
| PUBLISHED | 고객 화면 노출 |
| SCHEDULED | 예약 대기 |
| RESERVED | 이전 버전 보관 |
| CLOSED | 종료 |
| CANCELLED | 예약 취소 |

### FR-CAT-007 브랜드 관리
- **우선순위**: P1
- **내용**:
  - 브랜드 등록·수정·삭제

## 6. 주문 (Order)

- **내용**:
  - 입점사별 그룹핑 표시
  - 할인 혜택 안내 (쿠폰·포인트·장바구니할인)
  - 비로그인 장바구니 지원 (로그인 시 머지)
  - 수량 변경·삭제·전체 삭제
- **관련 테이블**: ord_cart
- **관련 화면**: CUS-040

### FR-ORD-002 장바구니 유효성 검사
- **우선순위**: P1
- **내용**:
  - 재고 확인: 진입·머지 시 매번 실행
  - 행사 유효성: 변경 시에만 (carted_at vs updated_at)
  - 품절 SKU 비활성 처리·안내
  - 로그인 후 머지 시에도 동일 검사

### FR-ORD-003 주문서 처리
- **우선순위**: P1
- **내용**:
  - 주문 전 휴대폰 OTP 인증 필수 (세션 기준 1회)
  - 배송지 자동 선택 (기본 배송지)
  - 할인 적용: 행사가→수량할인→쿠폰→장바구니할인→포인트
  - 동기 사전 확인: Catalog·Promotion·Member API
- **관련 화면**: CUS-041

### FR-ORD-004 주문 생성
- **우선순위**: P1
- **내용**:
  - 2계층: ord_platform_order (고객) + ord_order (입점사)
  - 비동기 생성: PROCESSING 상태 (3분 타임아웃)
  - 재고 확정 차감 후 품절 여부 자동 확인
  - TEMP 타임아웃: 30분 → CANCELLED (TempOrderTimeoutBatch)

### FR-ORD-005 주문 목록·상세
- **우선순위**: P1
- **내용**:
  - 기간별 조회 (1개월·3개월·6개월·1년)
  - PlatformOrder 단위 표시
