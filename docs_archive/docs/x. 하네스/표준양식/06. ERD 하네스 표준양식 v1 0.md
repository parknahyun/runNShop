# ⑥ ERD (엔티티 정의서) — Harness 표준양식

- **매핑 Harness**: Data Contract Harness (원천)
- **원천 작성 항목**: 데이터 불변식, 상태 전이 머신, 소프트 삭제·감사 규칙, 복제 테이블 규칙
- **AI-H**: AI-H15 (불변식), AI-H16 (상태 전이), AI-H17 (소프트 삭제), AI-H18 (복제 테이블)
- **참고**: Data Contract 서브산출물(⑧-2)의 도메인 레벨 입력 원천

---

## 기본 섹션 (일반 방법론)

```
테이블명       : {prefix}_{entity_name}   (예: ord_cart)
도메인         : 
설명           : 

[컬럼 정의]
| # | 컬럼명 | 타입 | 필수 | 기본값 | 설명 |
|---|--------|------|------|--------|------|
| 1 | {pk}_id | BIGINT | Y | auto | PK |
| 2 | is_deleted | BOOLEAN | Y | FALSE | 소프트 삭제 플래그 |
| 3 | created_at | TIMESTAMP | Y | NOW() | |
| 4 | updated_at | TIMESTAMP | Y | NOW() | |

[인덱스]
| 인덱스명 | 컬럼 | 유형 | 비고 |
|---------|------|------|------|

[관계]
• FK: {컬럼} → {참조 테이블}.{참조 컬럼}
```

## AI 보강 섹션

```
[AI-H15] 데이터 불변식                        ← Data Contract Harness (원천)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
invariants:
  - "{조건} (위반 시 처리 방법)"
  - "{필드A} + {필드B} UNIQUE (중복 금지)"
  - "is_deleted=TRUE인 행은 조회 기본 제외"

[AI-H16] 상태 전이 머신 (상태 컬럼이 있는 엔티티만) ← Data Contract Harness (원천)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
status_field: {status_column_name}
transitions:
  {INITIAL_STATUS}: [{NEXT_STATUS1}, {NEXT_STATUS2}]
  {STATUS_A}: [{STATUS_B}]
  {FINAL_STATUS}: []             # 최종 상태 = 전이 대상 없음

forbidden_transitions:
  - from: {STATUS}
    to: {STATUS}
    reason: "{허용하면 안 되는 이유}"

[AI-H17] 소프트 삭제·감사 규칙                ← Data Contract Harness (원천)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
soft_delete: true
immutable_fields: []             # 생성 후 수정 금지 컬럼 목록
audit_trigger: true / false      # Audit 도메인 자동 기록 여부
default_query_scope: "is_deleted = FALSE"

[AI-H18] 복제 테이블 규칙 (해당 시)           ← Data Contract Harness (원천)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
is_replica: false / true
sync_source: {원본 도메인}.{원본 테이블}
sync_method: BATCH / EVENT
sync_schedule: "매 {N}분 ({BatchName})"
write_allowed: false             # 복제 테이블 직접 쓰기 금지
```

## 작성 기준

| 항목 | 기준 |
|------|------|
| invariants | Repository/Service에서 항상 보장해야 할 조건 (AI가 검증 코드 생성 근거) |
| forbidden_transitions | AI가 status 변경 코드 작성 시 허용 전이만 구현하도록 차단 |
| immutable_fields | AI가 UPDATE 쿼리에서 반드시 제외해야 할 컬럼 |
| AI-H16 생략 | 상태 컬럼이 없는 테이블(장바구니, 설정 등)은 생략 가능 |
| AI-H18 생략 | 복제 테이블이 아닌 경우 생략 가능 |

## 하위 문서 역참조 경로

```
{prefix}_{table}
  └─ 불변식·전이 → Data Contract 서브산출물 DC-{DOM}-{SEQ}에서 API별 구체화
  └─ soft_delete → Data Contract default_query_scope에 반영
  └─ 복제 테이블 → ③ 도메인정의 AI-H6 통신 계약(REPLICA_TABLE)과 연계
```
