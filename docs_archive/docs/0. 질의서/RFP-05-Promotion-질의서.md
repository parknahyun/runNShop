# 질의서 — Promotion (프로모션, 발주사 대상)

> **목적**: 프로모션 도메인의 업무 범위·정책을 발주사로부터 확인한다.
> **사용 시점**: 착수(Kick-off) 미팅 또는 도메인정의서(DB) 작성 전
> **반영 대상**: `DB-도메인정의서`(Promotion 책임 정의)

| # | 질문 | 답변 | 비고 |
|---|---|---|---|
| 1 | 쿠폰 종류는 어떤 것이 필요한가? (전체/카테고리/상품별, 정액/정률, 최초구매 쿠폰 등) | 발행 주체(플랫폼/입점사)와 적용 기준(상품 단위/카테고리 단위/주문 단위)으로 구분되는 쿠폰 체계를 지원한다. 가입 시 자동 발급되는 웰컴 쿠폰, 등급 승급 시 즉시 지급되는 등급 쿠폰, 매년 12/31 등급별 일괄 지급되는 연말 쿠폰이 있다. 정액/정률 구분과 "최초구매 전용 쿠폰" 같은 세부 유형은 문서에 명시되어 있지 않다. | 요구사항 FR-PRO-001, FR-MBR-001·006, 정책서 9.1·9.3 |
| 2 | 쿠폰 발급 방식은 무엇인가? (자동지급, 다운로드, 이벤트 응모, 프로모션 코드 입력) | 자동지급 방식(가입 시 웰컴 쿠폰, 등급 승급/연말 등급 쿠폰)은 명확히 정의되어 있다. 쿠폰 다운로드·이벤트 응모·프로모션 코드 입력 방식에 대한 별도 규정은 문서에 없다. | 자동지급 외 방식은 '-' |
| 3 | 할인 정책의 우선순위·중복 적용 규칙이 있는가? (쿠폰+포인트+행사가 동시 적용 가능 여부) | 있다. 주문서에서 행사가 → 수량할인 → 쿠폰 → 장바구니할인 → 포인트 순으로 순차 적용되며 모두 동시 적용 가능하다. 쿠폰은 플랫폼 쿠폰과 입점사 쿠폰이 중복 적용 가능하나 동일 주체의 쿠폰은 1장만 적용된다. 장바구니 할인과 쿠폰의 중복 적용 가능 여부는 프로모션 설정에서 개별 제어한다. | 요구사항 FR-ORD-003, 정책서 9.1·9.2 |
| 4 | 기획전·이벤트 페이지 운영 빈도는 어느 정도로 예상하는가? | 문서에 운영 빈도(주기·건수) 수치는 명시되어 있지 않다. | - |
| 5 | 프로모션 효과 분석(전환율, ROI 측정)이 필요한가? | 문서에 프로모션 전환율·ROI 등 효과 분석 기능에 대한 요구사항이 명시되어 있지 않다. | - |
| 6 | 운영·CS·마케팅 관련 부가 기능(공지사항, FAQ, 배너 관리 등)이 이 영역에 포함되는가? | 포함되지 않는다. 공지사항·약관·배너 관리는 Promotion이 아닌 Config(플랫폼/운영) 도메인의 책임으로 별도 정의되어 있다. FAQ 관리 기능은 문서에 명시되어 있지 않다. | 요구사항 FR-CFG-004, BC 13.Config |
