# Payment 도메인 기능요구사항 (EARS)

| 항목 | 내용 |
|---|---|
| 산출물 ID | SPEC-EARS-PAYMENT-001 |
| Scope | Bolt (Payment 도메인) |
| 상태 | DRAFT-v1 |
| 작성일 | 2026-07-30 |
| 입력 자산 | 도메인기능표(04-Payment.md, 23개 소분류), runNshop_policy_v1_2.md §12.1~§12.5/§18.4, 용어집, 제약사항(CONS-004/005) |

> **Payment 도메인 특성**: 프로토타입에서 사실상 미구현 상태(전용 화면 0개)이며, 결제 정보는
> Order 상세의 "결제정보" 탭에서만 간접 조회된다. 이 EARS는 본개발 구현 기준으로 작성하되,
> 프로토타입 범위는 우선순위로 구분한다.
>
> **제약사항 연동**:
> - CONS-004: PG는 토스페이먼츠 단일 연동(1단계 신용카드, 2단계 간편결제)
> - CONS-005: 계좌이체·무통장입금·휴대폰결제·해외결제·자동결제는 정책 범위 밖
