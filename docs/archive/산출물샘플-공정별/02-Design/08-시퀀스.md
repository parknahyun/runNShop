# 샘플: 시퀀스 (Design, Bolt)

```plantuml
@startuml
actor Customer
participant OrderController
participant OrderService
participant "StockService(Catalog)" as Stock
participant PaymentService
participant PG as "PG(Mock)"
participant OutboxTable

Customer -> OrderController ++: POST /orders/{id}/payment
OrderController -> OrderService ++: pay(orderId, method)

rect rgb(230,245,230)
  note over OrderService, Stock: @Transactional 범위 ①
  OrderService -> Stock ++: reserveStock(skuId, qty)
  Stock --> OrderService --: RESERVED
  alt 재고 부족
    OrderService --> OrderController: 422 ERR_STOCK_SOLDOUT
  end
end

OrderService -> PaymentService ++: requestPayment(orderId, amount)
PaymentService -> PG ++: approve(pgToken)
PG --> PaymentService --: APPROVED

rect rgb(230,245,230)
  note over OrderService, OutboxTable: @Transactional 범위 ②
  PaymentService -> OrderService: onApproved()
  OrderService -> OrderService: status TEMP -> PAID
  OrderService -> OutboxTable: INSERT ORDER_PAID (AFTER_COMMIT)
end

OrderService --> OrderController --: 200 PAID
OrderController --> Customer --: 결제 완료 화면

== 실패 분기 ==
alt PG 승인 실패
  PG --> PaymentService: DECLINED
  PaymentService -> OrderService: onFailed()
  OrderService -> Stock: releaseStock(skuId, qty)
  OrderService -> OrderService: status TEMP -> PAYMENT_FAILED
end
@enduml
```
wrong_patterns: "PG 응답 대기를 트랜잭션 안에서 동기 블로킹" 금지(트랜잭션 시간 과다), "이벤트를 BEFORE_COMMIT에 발행" 금지
