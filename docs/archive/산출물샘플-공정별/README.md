# 산출물샘플 — 공정별

> 지침서의 Spec/Design/Tasks/Code 분류 체계. "이 산출물이 어떤 성격인가"를 기준으로 그룹핑.

```
00-Proposal/      ← 착수 산출물 (문제정의·목표·범위·대안비교)
01-Spec/          ← 요구사항 산출물 (제약사항·NFR·EARS·GWT·인터페이스)
02-Design/        ← 설계 산출물 (컴포넌트·ERD·상태머신·시퀀스·화면 등)
03-Tasks/         ← 관리 산출물 (RACI·DoD·WBS·리스크)
04-Code/          ← 구현 산출물 (코드·자동검증·단위테스트)
05-통합테스트/     ← 통합테스트 산출물 (계획·실행·결과)
06-안정화/         ← 안정화 산출물 (Runbook·Go-Live·결과보고)
```
