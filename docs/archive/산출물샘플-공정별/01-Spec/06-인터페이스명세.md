# 샘플: 인터페이스 명세 (Spec, Bolt 단위)

> Bolt: 주문결제.

```yaml
openapi: 3.0.0
paths:
  /api/v1/orders/{orderId}/payment:
    post:
      summary: 주문 결제 요청
      parameters:
        - name: orderId
          in: path
          required: true
          schema: { type: string }
      requestBody:
        content:
          application/json:
            schema:
              type: object
              required: [paymentMethod]
              properties:
                paymentMethod:
                  type: string
                  enum: [CARD, VIRTUAL_ACCOUNT, EASY_PAY]
                pgToken:
                  type: string
                  description: PG 결제창에서 발급된 임시 토큰
      responses:
        "200":
          description: 결제 성공
          content:
            application/json:
              schema:
                type: object
                properties:
                  code: { type: string, example: SUCCESS }
                  data:
                    type: object
                    properties:
                      orderId: { type: string }
                      orderStatus: { type: string, example: PAID }
                      paidAt: { type: string, format: date-time }
        "409":
          description: 이미 결제된 주문(중복 요청)
          content:
            application/json:
              schema:
                type: object
                properties:
                  code: { type: string, example: ERR_PAY_ALREADY_PAID }
                  message: { type: string }
        "422":
          description: 재고 부족 또는 PG 승인 실패
          content:
            application/json:
              schema:
                type: object
                properties:
                  code: { type: string, example: ERR_PAY_DECLINED }
                  message: { type: string }
                  detail: { type: string }
```

---
근거: 이 샘플에서 신규 작성 — `05-수용기준(GWT).md`의 예외 시나리오(AC-004/005/006)와 409/422 응답을 대응시킴.
