# 샘플: 컴포넌트 (Design, Project 단위)

```
Order Module            Payment Module           Inventory(Catalog) Module
┌──────────────┐        ┌──────────────┐         ┌──────────────┐
│ OrderController│──────▶│PaymentController│      │ StockService  │
│ OrderService   │◀────▶│PaymentService   │──────▶│ (재고 선점 API)│
│ OrderRepository│       │PaymentGateway   │       └──────────────┘
└──────────────┘        │ (PG 어댑터)      │
                         └──────────────┘
```
- **책임**: Order=주문 오케스트레이션(상태 관리), Payment=PG 연동·결제 상태 관리, Inventory=재고 선점/복원
- **경계 규칙**: Order는 Inventory 테이블 직접 접근 금지 → StockService의 PublicApi만 호출
- **배포 단위**: 현재 Modular Monolith 내 패키지 분리(`com.runnshop.order`, `com.runnshop.payment`)

## 앱별 메뉴구조

> Project Scope로 앱 전체 네비게이션 트리를 정의한다. 상위 유스케이스(Domain)의 선행자료로 활용.

### runNshop-admin (플랫폼 어드민)

| 셸 구조 | 설명 |
|---|---|
| NavBar | 로고 + 검색 + 알림 + 프로필 |
| Sidebar | 1depth 메뉴(아이콘+텍스트), 접힘/펼침 토글 |
| TabBar | MDI 방식 다중 탭(열린 화면 관리) |
| TabContent | 선택된 탭의 화면 렌더링 영역 |

```
1depth              2depth              화면(Bolt 대응)
─────────────────────────────────────────────────────────
홈                  —                   대시보드
주문관리            주문내역             주문목록·주문상세
                    클레임관리           클레임목록·클레임상세
상품관리            상품목록             상품목록·상품상세
                    상품심사             심사목록
                    카테고리(표준)       카테고리트리
                    카테고리(전시)       전시카테고리 매핑
                    브랜드               브랜드목록

                    등급관리             등급목록·등급설정

                    장바구니할인         할인규칙 목록
```

### runNshop-mobile (플랫폼 고객웹)

| 셸 구조 | 설명 |
|---|---|
| Header | 로고 + 검색 + 알림 + 장바구니 |
| Content | 페이지 단위 App Router |
| BottomNav | 홈·카테고리·검색·마이페이지 |

```
BottomNav           경로                화면(Bolt 대응)
─────────────────────────────────────────────────────────
홈                  /                   메인(전시 페이지)
카테고리            /category           카테고리 목록·상품목록
검색                /search             검색결과
마이페이지          /my                 마이페이지 허브
                    /my/orders          주문내역
                    /my/orders/[id]     주문상세
                    /my/claims          클레임내역
                    /my/points          포인트내역
                    /my/coupons         쿠폰함
                    /my/reviews         내 리뷰
                    /my/address         배송지관리
                    /my/payment-methods 결제수단관리
                    /my/settings        설정
장바구니            /cart               장바구니
주문서              /checkout           주문서
상품상세            /products/[id]      상품상세
```
