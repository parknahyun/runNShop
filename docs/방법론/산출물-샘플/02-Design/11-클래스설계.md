# 샘플: 클래스 설계 (Design, Bolt)

```
OrderController
  + pay(orderId, request): ResponseEntity
OrderService
  + pay(orderId, method): OrderPaymentResult
  - validateNotDuplicate(order)
  - transitionToPaid(order)
PaymentService
  + requestPayment(orderId, amount): PaymentResult
  + handleCallback(pgResponse)
StockService (PublicApi, Catalog 소유)
  + reserveStock(skuId, qty): ReservationResult
  + releaseStock(skuId, qty)
```
책임 분배: 상태 전이 검증은 OrderService, PG 통신은 PaymentService, 재고는 Catalog 도메인 소유(Order는 API로만 접근)
