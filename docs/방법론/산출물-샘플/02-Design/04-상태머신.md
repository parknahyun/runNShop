# 샘플: 상태머신 (Design, Domain: Order)

```
TEMP ──(결제요청 성공)──▶ PAID ──(구매확정 등, 별도 Bolt)──▶ ...
TEMP ──(PG 승인 실패/타임아웃)──▶ PAYMENT_FAILED ──(재시도)──▶ TEMP
```

| forbidden_transitions | 사유 |
|---|---|
| PAID → TEMP | 결제 완료 후 임시 상태로 되돌릴 수 없음 |
| PAYMENT_FAILED → PAID (직접) | 반드시 재결제(TEMP 경유) 절차를 거쳐야 함 |

---
근거: 이 샘플에서 신규 작성.
