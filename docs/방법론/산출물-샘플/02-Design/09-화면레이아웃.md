# 샘플: 화면 레이아웃(확정) (Design, Bolt)

| UI 요소 | 호출 API | 시점 |
|---|---|---|
| 결제수단 선택 라디오 | - | 로컬 상태 |
| 결제하기 버튼 | `POST /orders/{id}/payment` | onClick |
| 결제 진행 스피너 | - | 요청 중(300ms 지연 후 표시) |
| 결제 완료/실패 화면 | - | 응답에 따라 분기 |

검증규칙: 결제수단 미선택 시 버튼 비활성화. state: `paymentStatus`(REQUESTED/APPROVED/FAILED), refresh trigger: API 응답 수신 시.
