## 이벤트 스키마 상세 (주요 3개)

### PaymentRequested

```json
{
  "eventId": "evt_01H...",
  "eventType": "PaymentRequested",
  "timestamp": "2026-07-30T10:00:00Z",
  "payload": {
    "orderId": "ord_01H...",
    "platformOrderId": "pord_01H...",
    "amount": 25000,
    "pointAmount": 5000,
    "paymentMethod": "CARD",
    "pgProvider": "TOSS"
  }
}
```

### PaymentCompleted

```json
{
  "eventId": "evt_01H...",
  "eventType": "PaymentCompleted",
  "timestamp": "2026-07-30T10:00:05Z",
  "payload": {
    "orderId": "ord_01H...",
    "paymentId": "pay_01H...",
    "paidAmount": 25000,
    "pgTransactionId": "toss_tx_abc123",
    "approvedAt": "2026-07-30T10:00:04Z"
  }
}
```

### StockReserveRequested (동기 API)

```json
{
  "orderId": "ord_01H...",
  "items": [
    { "skuId": "sku_001", "qty": 2 },
    { "skuId": "sku_002", "qty": 1 }
  ]
}
```
응답:
```json
{
  "orderId": "ord_01H...",
  "reservationId": "rsv_01H...",
  "result": "SUCCESS",
  "reservedItems": [
    { "skuId": "sku_001", "qty": 2 },
    { "skuId": "sku_002", "qty": 1 }
  ]
}
```

## 동기/비동기 판단 기준

| 기준 | 동기(API) | 비동기(Outbox) |
|---|---|---|
| 응답 대기 필수 | 재고선점(결과에 따라 주문 진행/차단 결정) | 나머지 전부 |
| 트랜잭션 경계 | 호출자 트랜잭션 안에서 결과 확인 필요 | AFTER_COMMIT 발행 |
| 실패 처리 | 즉시 롤백 | 재시도 + 최종실패 시 에스컬레이션 |
