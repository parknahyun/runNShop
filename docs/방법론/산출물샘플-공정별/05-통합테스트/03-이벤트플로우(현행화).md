# 샘플: 이벤트 플로우(현행화) (통합테스트, Domain 간)

`../02-Design/06-이벤트플로우.md` 대비 확인 결과: ORDER_PAID 이벤트가 Notification 도메인에서 아직
구독 미구현(별도 Bolt 미착수) — 이벤트 스키마 자체는 설계와 일치, 구독자 목록만 "예정"으로 갱신.

| 이벤트명 | 설계상 구독 도메인 | 실제 구독 확인 |
|---|---|---|
| ORDER_PAID | Payment(내부), Settlement, Notification | Settlement만 구독 확인, Notification 미구현(Human Review) |
| STOCK_RESERVED | Order | 확인(동기 응답) |

## Human Review 필요 항목
| # | 항목 | 사유 |
|---|---|---|
| 1 | Notification 도메인 구독 미구현 | 별도 Bolt(알림) 착수 전이므로 이 배치 범위에서 제외할지 여부 확인 |
