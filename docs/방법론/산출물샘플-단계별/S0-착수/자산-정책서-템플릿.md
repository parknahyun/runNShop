# 자산 정책서 (이커머스 표준 템플릿)

> **작성 목적**: 발주자(사업자)에게 전달하여 비즈니스 정책을 수집하기 위한 템플릿.
> 대부분의 사업자는 정식 정책서가 없으므로, 이 문서를 보내고 수정·확인 받은 내용을 기준으로 산출물을 작성한다.
>
> **흐름 내 위치**:
> ```
> 착수(Proposal) → 자산 정책서 발송 → 발주자 수정·회수 → 범위정의·구조설계의 입력 자산
> ```
>
> **작성 주체**: 시니어 개발자 + AI (템플릿 작성) → 발주자/기획자 (내용 채움·확인)
>
> **기본값 원칙**: 각 항목에 이커머스 업계 일반적인 기본값을 미리 채워둔다.
> 발주자는 "기본값 그대로 OK" 또는 "이렇게 변경"만 표기하면 된다.

## 사용 가이드

### 발주자에게 전달 시 안내 문구 (예시)

> "아래 정책서는 이커머스 플랫폼의 일반적인 기준을 미리 채워둔 것입니다.
> 각 항목의 기본값을 확인하시고, **변경이 필요한 부분만** '발주자 확인' 칸에 기재해 주세요.
> 기본값 그대로 진행할 항목은 빈칸으로 두시면 됩니다."

### 회수 후 처리

1. 변경된 항목 → 산출물의 **작성 원천**으로 명시 (예: "정책서 1.3: 최대 수량 50개")
2. 기본값 유지 항목 → 그대로 적용
3. 미응답 항목 → 확인 요청 or 기본값 적용 후 검토 시 확인
