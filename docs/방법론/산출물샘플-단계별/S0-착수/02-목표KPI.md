# 샘플: 목표·KPI

> **단계**: 착수
> **문서범위**: Project
> **문서종류**: Proposal
>
> **작성 목적**: 프로젝트의 성공 기준을 정량적으로 정의한다.
> "무엇이 달성되면 이 프로젝트가 성공인가"를 측정 가능한 지표로 확정한다.
>
> **흐름 내 위치**:
> ```
> 문제정의서 → 목표KPI → 이해관계자맵
> ```
>
> **작성 주체**: PM/사업 담당자 + AI 협업 (의사결정권자 승인)

---

## 필수 항목

| # | 항목 | 설명 |
|---|---|---|
| 1 | **Objective** | 프로젝트 목표 (1~3개) |
| 2 | **Key Results** | 목표별 측정 지표 (각 2~4개) |
| 3 | **Baseline vs Target** | 현재 수준 vs 목표 수준 비교 |
| 4 | **측정 시점** | 언제 측정하는가 (마일스톤/안정화 후) |

## 작성 팁

| 팁 | 설명 |
|---|---|
| **SMART 원칙** | Specific·Measurable·Achievable·Relevant·Time-bound |
| **Baseline 필수** | 현재 수준 없이 목표만 있으면 달성 여부 판단 불가 |
| **3개 목표 이내** | 집중하지 않으면 모두 실패 |
| **안정화 단계에서 현행화** | 실측치로 Baseline·Target 보정 |
