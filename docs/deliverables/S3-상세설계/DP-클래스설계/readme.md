# 클래스 설계 — 주문·결제 도메인

> **단계**: 상세설계 (S3)
> **문서범위**: Bolt (Order + Payment)
> **문서종류**: Design
>
> **작성 목적**: 시퀀스(DM)에 등장한 참여 객체를 클래스 구조로 전환한다.
> "어떤 클래스가 어떤 책임을 갖고, 어떤 메서드를 제공하는가"를 확정하여
> 구현(코드) 단계의 직접 입력이 된다.
>
> **흐름 내 위치**:
> ```
> DM 시퀀스 (참여 객체) → DP 클래스 설계 → 구현
> ```
