### 화면 구성

| 영역 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| 타이틀 | — | "주문 현황" |
| FilterBar | — (FE 상태) | 키워드(주문번호·상품명·고객명), 상태 Select, 기간(from~to), 조회 버튼 |
| SummaryBar | GET /api/admin/v1/orders → 응답 집계 | 전체·접수·결제완료·준비중·배송중·배송완료·구매확정·취소 건수 카드 |
| Toolbar | — | 엑셀 다운로드 버튼 |
| OrderTable (DataGrid) | GET /api/admin/v1/orders | 주문번호, 상품명, 주문자, 입점사, 상태(뱃지), 결제금액, 주문일시 |
| Pagination | — (FE 상태) | 페이지 이동, 페이지 사이즈 변경 |

### 상세 화면 (OrderDetail — MDI 탭)

| 탭 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| 주문상품 (OrderItemsTab) | GET /api/admin/v1/orders/{orderId} | 상태 뱃지, 주문일시, 상품 테이블(상품명/옵션/수량/단가/소계) |
| 결제정보 (PaymentInfoTab) | GET /api/admin/v1/orders/{orderId}/payment | 상품합계, 할인금액, 배송비, 실결제금액, 결제수단, PG사, 거래ID, 결제일시 |
| 배송정보 (ShippingInfoTab) | GET /api/admin/v1/orders/{orderId}/shipping | 수령인, 연락처(마스킹), 주소, 배송메모, 배송사, 운송장번호, 출고일, 배송상태 |
| CS·클레임 (ClaimTab) | GET /api/admin/v1/orders/{orderId}/claims | CS 액션 버튼(클레임 접수, 장바구니 담아주기, 예외 취소), 클레임 이력 목록 |
| 주문문의 (InquiryTab) | GET /api/admin/v1/orders/{orderId}/inquiries | 문의 목록(문의번호, 유형, 상태, 작성자, 등록일시) + [문의 등록] 버튼 |
| 변경이력 (ChangeLogTab) | GET /api/admin/v1/orders/{orderId}/logs | 타임라인(일시, 이벤트, 상세) |

### 화면 전환

| 트리거 | 이동 화면 (SCR-ID) |
|---|---|
| 목록 행 클릭 | SCR-A-002 (주문상세 MDI 탭, 같은 화면 내 탭 오픈) |
| CS·클레임 탭 → 클레임번호 클릭 | SCR-A-004 (클레임상세 MDI 탭, 같은 화면 내 탭 오픈) |
| 주문문의 탭 → 문의번호 클릭 | 문의 상세/답변 모달 (화면 전환 아님) |
| 주문문의 탭 → [문의 등록] 클릭 | 문의 등록 모달 (화면 전환 아님) |
