### 화면 구성

| 영역 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| 타이틀 | — | "주문 목록" |
| FilterBar | — (FE 상태) | 상태 Select, 기간(from~to), 키워드(주문번호·상품명·고객명), 조회 버튼 |
| SummaryBar | GET /api/partner/v1/orders → 집계 | 전체·접수·결제완료·준비중·배송중·배송완료 건수 카드 |
| Toolbar | — | 엑셀 다운로드, 일괄 출고 처리 버튼 |
| OrderTable (DataGrid) | GET /api/partner/v1/orders | 주문번호, 상품명, 고객명, 수량, 금액, 상태(뱃지), 주문일자 |
| Pagination | — (FE 상태) | 페이지 이동, 페이지 사이즈 변경 |

### 상세 화면 (OrderDetail — MDI 탭, admin §11 참조)

| 탭 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| 주문상품 (OrderItemTab) | GET /api/partner/v1/orders/{orderId} | 상태, 주문일시, 상품 테이블(상품명*/옵션*/주문수량/클레임진행/완료/단가/소계) + [출고 처리] 버튼(PAYMENT_COMPLETED만) |
| 배송정보 (ShippingTab) | GET /api/partner/v1/orders/{orderId}/shipping | 수령인(마스킹), 연락처(마스킹), 주소, 배송메모, 택배사/운송장/배송상태. 미입력 시 [배송정보 입력] 버튼 |
| 클레임 (ClaimTab) | GET /api/partner/v1/orders/{orderId}/claims | 클레임 목록 조회(번호/유형/상태/환불금액/추가배송비+결제상태/접수일시). 클레임번호 클릭 → 클레임상세 MDI 탭에서 수거확인·품질점검·재배송 수행. 이 탭에서는 목록 조회만 제공 |
| 변경이력 (LogTab) | GET /api/partner/v1/orders/{orderId}/logs | 타임라인(일시, 이벤트, 상세) — 역순 표시 |
