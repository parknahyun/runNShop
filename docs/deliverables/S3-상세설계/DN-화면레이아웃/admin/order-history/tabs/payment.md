### 화면 구성

| 영역 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| 금액 패널 | GET /api/admin/v1/orders/{orderId} → `payment` | 상품 합계, 상품 할인(ⓘ 툴팁), 장바구니할인(ⓘ 툴팁), 쿠폰 할인, 포인트 사용, 배송비(ⓘ 툴팁), 실결제금액 |
| 결제수단 패널 | GET /api/admin/v1/orders/{orderId} → `payment` | 결제수단, PG사, 거래ID, 결제일시 |
| ⓘ 할인/배송비 상세 툴팁 | GET /api/admin/v1/orders/{orderId} → `payment.discount_breakdown` 등 | 할인 항목별 명세(행사명·금액), 입점사별 배송비 명세 |
