### 화면 구성

| 영역 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| 상태/주문일시 | GET /api/admin/v1/orders/{orderId} | 상태 뱃지, 주문일시 |
| 상품 테이블 | GET /api/admin/v1/orders/{orderId} → `items[]` | 상품명*, 옵션*, 주문수량, 클레임진행, 완료, 단가, 소계 |

> \* 상품명·옵션명은 주문(ord_order_item)의 스냅샷 속성을 사용 (현재 상품정보와 다를 수 있음)
