### 화면 구성

| 영역 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| 문의 목록 테이블 | GET /api/admin/v1/orders/{orderId} → `inquiries[]` | 문의번호, 유형, 상태(뱃지), 작성자(마스킹), 등록일시 |
| 문의 상세/답변 모달 | GET /api/admin/v1/orders/{orderId}/inquiries/{inquiryId}(예정) | 문의 내용(첨부 포함), 답변(답변자/답변일), 답변 입력 폼, 주문번호 등록/변경 |

### 기능 (Function)

| 기능명 | 트리거 | 동작 | 검증/제약사항 |
|---|---|---|---|
| 문의 등록 | [문의 등록] 클릭 | 문의 등록 모달 오픈 | — |
| 답변 등록 | 상세 모달 [답변 등록] 클릭 | 답변 저장 (API 연동 예정) | 답변 내용 필수 |
| 주문번호 등록/변경 | 상세 모달 [변경]/[주문번호 등록] 클릭 | 주문번호 수동 매핑 | 레거시/이관 건의 주문번호 누락 시 콜센터가 고객 확인 후 수동 등록 |

### 화면 전환

| 트리거 | 이동 화면 |
|---|---|
| 문의번호 클릭 | 문의 상세/답변 모달 (화면 전환 아님) |
| [문의 등록] 클릭 | 문의 등록 모달 (화면 전환 아님) |
