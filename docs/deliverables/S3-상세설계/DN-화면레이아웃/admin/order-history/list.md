### 화면 구성

| 영역 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| 타이틀 | — | "주문 현황" |
| FilterBar | — (FE 상태) | 키워드(주문번호·상품명·고객명), 상태 Select, 기간(from~to), 조회 버튼 |
| SummaryBar | GET /api/admin/v1/orders → 응답 집계 | 전체·접수·결제완료·준비중·배송중·배송완료·구매확정·취소 건수 카드 |
| Toolbar | — | 엑셀 다운로드 버튼 |
| OrderTable (DataGrid) | GET /api/admin/v1/orders | 주문번호, 상품명, 주문자, 입점사, 상태(뱃지), 결제금액, 주문일시 |
| Pagination | — (FE 상태) | 페이지 이동, 페이지 사이즈 변경 |
