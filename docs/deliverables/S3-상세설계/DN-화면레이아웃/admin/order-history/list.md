### 화면 구성

| 영역 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| 타이틀 | — | "주문 현황" |
| FilterBar | — (FE 상태) | 키워드(주문번호·상품명·고객명), 상태 Select(허용값: 전체/접수/결제완료/준비중/배송중/배송완료/구매확정/취소 — [DL-인터페이스명세/order.md](../../../DL-인터페이스명세/order.md#api-022) §15 매핑표 참조), 기간(from~to), 조회 버튼 |
| SummaryBar | GET /api/admin/v1/orders → 서버가 상태별로 집계한 건수(클라이언트 재계산 아님) | 전체·접수·결제완료·준비중·배송중·배송완료·구매확정·취소 건수 카드 |
| Toolbar | — | 엑셀 다운로드 버튼 |
| OrderTable (DataGrid) | GET /api/admin/v1/orders | 주문번호, 상품명, 주문자, 입점사, 상태(뱃지), 결제금액, 주문일시 |
| Pagination | — (FE 상태) | 페이지 이동, 페이지 사이즈 변경 |

> **"배송중" 표시 근거**: `ord_order.status`는 `PREPARING`에서 바로 `DELIVERED`로 전이하며 중간에 "배송중"이라는 원시 상태는 없다([DH-상태머신/order.md](../../../../S2-구조설계/DH-상태머신/order.md) §1, v6 10상태). API-022/023의 `status` 필드는 `PREPARING` + 연결된 `ord_shipment(OUTBOUND)`에 **운송장번호가 등록(status=IN_TRANSIT)**되었는지를 서버에서 조인해 `IN_DELIVERY`로 변환한 "표시 상태"다 — 매핑 상세는 [API-022](../../../DL-인터페이스명세/order.md#api-022)(§15).
