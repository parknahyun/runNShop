| Toolbar | — | 엑셀 다운로드 버튼 |
| ClaimTable (DataGrid) | GET /api/admin/v1/claims | 클레임번호, 원주문번호, 유형, 상태(뱃지 — **접수(RECEIVED) 후 24시간 초과 시 ⚠ 강조 아이콘 표시**), 귀책(뱃지), 신청경로, 환불금액, 신청일시, 처리완료일시 |
| Pagination | — (FE 상태) | 페이지 이동, 페이지 사이즈 변경 |

### 상세 화면 (ClaimDetail — MDI 탭)

| 탭 | 데이터 소스 (API) | 표시 내용 |
|---|---|---|
| 클레임상품 (ClaimItemTab) | GET /api/admin/v1/claims/{claimId} | 원주문번호, 접수일, 사유·상세사유, 귀책, 신청경로, 클레임 상품 테이블(상품명*/옵션*/수량/결제금액/상태), **첨부사진(업로더별 구분 표시 — "고객 첨부"(접수 시)와 "입점사 첨부"(품질점검 불합격 증빙, REQ-ORD-072)를 별도 섹션으로 나열, 혼재 나열 금지)**, **귀책 판정(상단에 "고객 신고: {submitted_responsibility}" 참고 표시 + 고객귀책/입점사귀책 라디오 + [판정 확정] 버튼 — 고객 제출 사유와 다르게 CS가 최종 확정 가능, REQ-ORD-066)**, CS 메모 입력, 처리 액션 버튼([처리시작]/[처리완료]/[반려]) |
| 환불정보 (RefundTab) | GET /api/admin/v1/claims/{claimId}/refund | 아이템 결제금액 = 환불금액 (배송비 미차감), 환불수단(원결제 수단 기본, 불가 시 현금/계좌 대체 — CS 변경 가능), 환불상태, 환불예정일. 품질점검 불합격 시 환불 불가 안내 |
| 배송정보 (ShippingTab) | GET /api/admin/v1/claims/{claimId}/shipping | 추가배송비 테이블(수거/반송 — 금액·결제상태·결제일시), 수거 정보(택배사·운송장·상태·요청일시·회수지), 재배송 정보(교환 시에만 — 택배사·운송장·상태. PICKUP 진입 시 자동 선출고되어 이미 발송 완료된 건), **반송 정보(반품 시 — 품질점검 불합격 + 반송배송비 결제완료 후 shipment(RETURN) 택배사·운송장·상태 조회, 입점사 등록)**, **FAILED 상태 처리(수거/재배송/반송 공통 — 배송실패 시 실패사유 표시 + [재발송 처리] 버튼 노출, 입점사 또는 CS 담당자 수행 가능, REQ-ORD-062)** → `POST /api/partner/v1/shipping/{shipmentId}/reship (Admin Bearer도 허용)` |
| 변경이력 (LogTab) | GET /api/admin/v1/claims/{claimId}/logs | 타임라인(일시, 이벤트, 상세 — 접수→배송비결제→접수확인→수거요청→수거진행→품질점검→환불/반려) |
