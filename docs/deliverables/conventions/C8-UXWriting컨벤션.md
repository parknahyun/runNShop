# C8 UXWriting컨벤션

> **수립 데드라인**: S3 화면레이아웃 작성 전 | **참고 대상**: DN 화면레이아웃, 알림 문구
> **C2 용어컨벤션 연계**: C2가 "무슨 용어를 사용할 것인가"를 정의하고, C8이 "그 용어를 사용자에게 어떻게 표현할 것인가"를 정의한다.

---

## 1. 목적

같은 상황에서는 누구나 같은 방식으로 문구를 작성할 수 있도록,
UI 콘텐츠·메시지·표기의 일관된 규칙을 정의한다.

---

## 2. 기본 원칙

| 원칙 | 설명 |
|------|------|
| 사용자 중심 | 시스템이 아닌 사용자 관점에서 표현 |
| 명확성 | 한 문장에 하나의 의미만 전달 |
| 간결성 | 불필요한 수식어 제거, UI 영역 고려 |
| 행동 유도 | 에러/안내 시 사용자가 할 수 있는 행동을 함께 안내 |
| 주어 | 불필요한 시스템 주어 생략, 대상(주문/배송/결제)은 명시 |
| 존칭 | mobile: "~해 주세요" / admin·partner: "~합니다" |

---

## 3. 앱별 톤앤매너

| 앱 | 톤 | 종결 어미 | 예시 |
|----|-----|-----------|------|
| mobile (고객) | 친근하고 부드러움 | ~해 주세요, ~됐어요 | "주문이 완료됐어요!" |
| admin (어드민) | 간결하고 사무적 | ~합니다, ~됩니다 | "주문이 취소되었습니다." |
| partner (입점사) | 간결하고 사무적 | ~합니다, ~됩니다 | "출고 처리가 완료되었습니다." |

## 4. UI 콘텐츠 작성 규칙

### 4.1 Label

| 규칙 | 예시 |
|------|------|
| 명사형 (간결) | "상품명", "배송지", "결제 수단" |
| 동사 금지 | ✗ "상품명을 입력", ✓ "상품명" |
| Label은 Placeholder로 대체하지 않음 | Label + Placeholder 함께 사용 |

### 4.2 Button

**의미 구분 (혼용 금지):**

| 버튼 | 의미 | 사용 상황 |
|------|------|-----------|
| 확인 | 메시지/결과를 확인하고 닫음 | Alert, Info Dialog |
| 완료 | 현재 작업 흐름을 완료 | 신청 완료, 등록 완료 |
| 저장 | 입력/변경 내용을 저장 | 폼 저장 |
| 적용 | 변경사항을 현재 화면에 반영 | 쿠폰 적용, 필터 적용 |
| 취소 | 현재 작업을 취소 (데이터 미저장) | 모달 취소, 작성 취소 |
| 뒤로 | 이전 화면으로 이동 | 네비게이션 |
| 삭제 | 리소스를 제거 | Confirmation 후 실행 |

**라벨 규칙:**

| 유형 | mobile | admin/partner |
|------|--------|---------------|
| 긍정 CTA | 동사형 ("결제하기", "신청하기") | 동사형 ("저장", "등록") |
| 부정 | "취소", "닫기" | "취소", "닫기" |
| 조회 | — | "조회" (admin) |
| 검색 | "검색" (고객) | — |

### 4.3 Placeholder

| 규칙 | 예시 |
|------|------|
| 입력 안내 (동사형) | "상품명을 입력해 주세요" |
| 검색 안내 | "주문번호·상품명·고객명" |
| Label 대체 금지 | Placeholder만으로 의미 전달 ✗ |

### 4.4 Helper Text

| 규칙 | 예시 |
|------|------|
| 입력 조건 안내 | "최소 1,000P부터 사용 가능" |
| 제한사항 안내 | "최대 3장까지 첨부 가능" |
| 위치 | 입력 필드 하단 |

### 4.5 Tooltip

| 규칙 | 예시 |
|------|------|
| 보조 설명 | ⓘ 클릭 시 "나이키 행사 -15,000원 / 아식스 행사 -5,000원" |
| 짧게 | 2~3줄 이내 |

## 5. 메시지 작성 규칙

### 구조 원칙

> **무엇이 일어났는지 + 사용자가 할 수 있는 행동**

### 유형별 규칙

| 유형 | 목적 | 패턴 (mobile) | 패턴 (admin) |
|------|------|---------------|--------------|
| **Success** | 정상 처리 완료 | "{대상}이(가) 완료됐어요!" | "{대상}이(가) 완료되었습니다." |
| **Error** | 처리 실패 | "{문제}. {행동 안내}" | "{문제}. {행동 안내}" |
| **Validation** | 입력 오류 | "{필드}을(를) 확인해 주세요." | "{필드}을(를) 확인하세요." |
| **Warning** | 주의/위험 안내 | "⚠ {결과 안내}" | "⚠ {결과 안내}" |
| **Confirmation** | 파괴적 행동 전 확인 | "{대상}을(를) {행동}할까요?" | "{대상}을(를) {행동}하시겠습니까?" |
| **Info** | 정보 전달 | "현재 {상태}입니다." | "현재 {상태}입니다." |
| **Loading** | 처리 중 | "{행동} 중이에요..." | "{행동} 중입니다..." |
| **Permission** | 권한 부족 | "접근 권한이 없어요." | "접근 권한이 없습니다." |
| **System** | 시스템 장애 | "일시적인 오류가 발생했어요. 잠시 후 다시 시도해 주세요." | "일시적인 오류가 발생했습니다." |

### 예시

| 유형 | mobile | admin |
|------|--------|-------|
| Success | "주문이 완료됐어요!" | "주문이 취소되었습니다." |
| Error | "결제에 실패했어요. 결제 정보를 확인해 주세요." | "저장에 실패했습니다. 다시 시도하세요." |
| Validation | "배송지를 입력해 주세요." | "필수 항목을 확인하세요." |
| Warning | "삭제하면 복구할 수 없어요." | "삭제 시 복구할 수 없습니다." |
| Confirmation | "주문을 취소할까요?" | "이 주문을 예외 취소하시겠습니까?" |
| Loading | "결제 진행 중이에요..." | "처리 중입니다..." |

## 6. UI 유형별 사용 기준

| UI 유형 | 용도 | 자동 닫힘 | 사용자 행동 |
|---------|------|-----------|-------------|
| **Toast** | 짧은 성공/상태 알림 | ✅ 2~3초 | 불필요 |
| **Inline Message** | 필드별 입력 오류 | ✗ | 입력 수정 시 사라짐 |
| **Alert (Banner)** | 중요 안내/경고 | ✗ | 닫기 가능 |
| **Dialog (Modal)** | 사용자 의사결정 필요 | ✗ | 버튼 클릭 필수 |
| **Notification (알림톡)** | 비동기 이벤트 전달 | — | 외부 채널 |
| **Tooltip** | 보조 설명 | hover/click 해제 | — |

### Confirmation Dialog 규칙

| 요소 | 규칙 | 예시 |
|------|------|------|
| 제목 | 질문형 | "상품을 삭제할까요?" |
| 설명 | 결과 안내 | "삭제한 상품은 복구할 수 없습니다." |
| 부정 버튼 (좌) | 취소/돌아가기 | "취소" |
| 긍정 버튼 (우) | 행동 동사 | "삭제", "취소하기" |
| 파괴적 행동 | 긍정 버튼 빨간색 | error 색상 |

## 7. 상태별 콘텐츠

| 상태 | mobile | admin |
|------|--------|-------|
| **Empty State** | "아직 {대상}이(가) 없어요." + CTA 버튼 | "{대상}이(가) 없습니다." |
| **Error State** | "정보를 불러올 수 없어요. 다시 시도해 주세요." + [다시 시도] | "데이터를 불러오지 못했습니다." + [재시도] |
| **Loading State** | Skeleton 또는 "불러오는 중..." | Skeleton 또는 "로딩 중..." |
| **Maintenance** | "서비스 점검 중이에요. {시간}에 다시 만나요!" | "시스템 점검 중입니다. ({시간} 완료 예정)" |
| **Placeholder (개발용)** | — | "해당 기능은 준비 중입니다." |

> PlaceholderPage 문구는 **개발 환경에서만 사용**하며, 운영 환경에서는 노출하지 않는다.

## 8. 표기 규칙

### 8.1 날짜·시간

| 상황 | mobile | admin |
|------|--------|-------|
| 날짜만 | 2026.08.21 | 2026.08.21 |
| 날짜+시간 | 2026.08.21 15:30 | 2026.08.21 15:30 |
| 시간만 | 15:30 | 15:30 |
| 기간 | 2026.08.01 ~ 2026.08.31 | 2026.08.01 ~ 2026.08.31 |

### 8.2 상대 시간 (mobile)

| 경과 | 표시 |
|------|------|
| ~1분 | 방금 전 |
| ~59분 | N분 전 |
| ~23시간 | N시간 전 |
| ~6일 | N일 전 |
| 7일+ | YYYY.MM.DD |

### 8.3 금액

| 표기 | 사용 | 예시 |
|------|------|------|
| `{숫자}원` | 기본 (공백 없음) | 35,000원 |
| 천단위 콤마 | 필수 | 1,500,000원 |
| 할인 전 | 취소선 | ~~50,000원~~ |
| 할인 후 | 강조 (굵게/primary 색) | **35,000원** |
| 할인율 | `N%` | 30% |
| 할인 금액 | `-{금액}` | -15,000원 |
| 포인트 | `{숫자}P` | 5,200P |
| 무료 | "무료" (0원 표시 ✗) | 배송비 무료 |

### 8.4 수량

| 표기 | 예시 |
|------|------|
| 기본 | 3개 |
| 장 | 쿠폰 2장 |
| 건 | 주문 5건 |

### 8.5 전화번호

| 표기 | 예시 |
|------|------|
| 마스킹 | 010-\*\*\*\*-5678 |
| 전체 표시 (본인) | 010-1234-5678 |

## 9. 금칙어·권장어

| 금지/지양 | 권장 | 이유 |
|-----------|------|------|
| 삭제하시겠습니까? | 삭제할까요? | 간결 |
| 에러가 발생했습니다 | 오류가 발생했습니다 | 순우리말 우선 |
| 실패하였습니다 | 처리하지 못했습니다 | 부드러움 |
| 유저 | 사용자 / 고객 | C2 용어 |
| 업데이트 | 수정 / 갱신 | C2 용어 |
| OK | 확인 | 한글화 |
| Cancel | 취소 | 한글화 |
| 로딩 중입니다 (mobile) | 불러오는 중이에요 | 톤앤매너 |
| 데이터가 없습니다 (mobile) | 아직 정보가 없어요 | 사용자 친화 |
| 셀러/판매자 | 입점사 | C2 표준 용어 |
| 오더번호 | 주문번호 | C2 표준 용어 |

## 10. 접근성 Writing

| 규칙 | 설명 | 예시 |
|------|------|------|
| 아이콘만으로 의미 전달 금지 | 텍스트 라벨 또는 aria-label 필수 | `aria-label="닫기"` (✗ "X"만) |
| 링크/버튼 목적 명확 | "여기를 클릭하세요" 금지 | ✓ "주문 상세 보기" |
| 이미지 대체텍스트 | 의미 있는 이미지에 alt 필수 | `alt="나이키 페가수스 41 블랙"` |
| 숫자+단위 명시 | 단위 없는 숫자 금지 | ✓ "3개", ✗ "3" |
| 색상만으로 상태 전달 금지 | 텍스트 또는 아이콘 병행 | ✓ "⦿결제완료" (색+텍스트) |
