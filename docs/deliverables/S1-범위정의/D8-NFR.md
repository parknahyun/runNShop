# NFR (비기능 요구사항)

> **단계**: 범위정의
> **문서범위**: Project
> **문서종류**: Spec
>
> **작성 목적**: 시스템이 충족해야 할 품질 속성(성능·가용성·보안·유지보수성 등)을 정량적으로 정의한다.
> **흐름 내 위치**: 제약사항 → **NFR** → 컴포넌트
> **작성 주체**: 시니어 + AI (기획 검토)

## NFR 분류 체계

ISO 25010 품질 특성 모델을 기반으로, runNshop에 적용 가능한 항목을 선별하여 정의한다.

## 1. 성능 효율성 (Performance Efficiency)

| ID | 항목 | 기준 | 측정 방법 | 비고 |
|---|---|---|---|---|
| NFR-PE-01 | 상품 목록 API 응답시간 | ≤ 1초 (p95) | 부하 테스트 (k6/JMeter) | P-3 출처 |
| NFR-PE-02 | 주문·결제 API 응답시간 | ≤ 5초 (p95, 전체 트랜잭션) | 부하 테스트 | P-3 출처 |
| NFR-PE-03 | 동시 접속자 수 | 1,000명 동시 처리 | 부하 테스트 | P-3 출처 |
| NFR-PE-04 | 페이지 초기 로딩 (FCP) | ≤ 2초 (고객웹, 3G 환경) | Lighthouse | 모바일 최적화 |
| NFR-PE-05 | API 서버 CPU 사용률 | ≤ 70% (정상 부하) | APM 모니터링 | 스케일아웃 트리거 기준 |
| NFR-PE-06 | 검색 응답시간 | ≤ 500ms (p95) | 부하 테스트 | 상품 검색 전용 |

## 5.1 자가평가

- **완전성**: 충족 — ISO 25010 7대 품질 특성 + 보안 강화 25개 항목(5개 하위 카테고리) 포함, 프로토타입 단계 예외 구분 명확
- **일관성**: 충족 — `D2-목표KPI.md` P-3/P-4 수치 그대로 반영, `D7-제약사항.md`와 모순 없음
- **추적성**: 충족 — 모든 항목에 출처·측정 방법 명시
- **실행가능성**: 충족 — 정량적 기준 + 측정 방법 쌍으로 기술, 테스트 단계에서 즉시 검증 가능
