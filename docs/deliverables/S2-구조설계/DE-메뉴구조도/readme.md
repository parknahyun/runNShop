## 앱별 메뉴 구조

메뉴는 도메인이 아닌 **앱(채널) 단위**로 구성한다 — 하나의 도메인(예: Order)이 여러 앱의 메뉴에
흩어져 나타나므로, 앱별 파일로 분리해 각 프론트엔드 개발자가 자기 앱의 전체 메뉴 트리를 한 파일에서
확인할 수 있게 한다.

| 앱 | 파일 |
|---|---|
| runNshop-admin (플랫폼 어드민) | [admin.md](admin.md) |
| runNshop-partner (입점사 어드민) | [partner.md](partner.md) |
| runNshop-mobile (고객웹) | [mobile.md](mobile.md) |

## Platform Bolt vs Domain Bolt 구분

| 구분 | 범위 | 메뉴구조도에서의 위치 |
|---|---|---|
| **Platform Bolt** | 셸 구조 (NavBar·Sidebar·TabBar·BottomNav·로그인·공통 컴포넌트) | 각 앱 파일의 "셸 구조" 행 |
| **Domain Bolt** | 업무 화면 (1depth~2depth 메뉴의 각 화면) | 각 앱 파일의 나머지 전체 |

> Platform Bolt는 모든 Domain Bolt의 선행 조건이다.
