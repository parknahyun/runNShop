| `gray-200` | (Tailwind 기본) | 구분선 |

| `gray-600` | (Tailwind 기본) | 보조 텍스트 |

| 용도 | 값 |
|---|---|

## 1-2. Component

### Button

| 변형 | Tailwind 클래스 패턴 | 용도 |
|---|---|---|
| Primary | `bg-primary text-white px-4 py-3 rounded font-bold` | 구매하기, 장바구니 |
| Secondary | `border border-gray-300 px-4 py-3 rounded` | 옵션 선택, 취소 |
| Text | `text-primary text-sm` | 더보기, 링크 |
| Disabled | `bg-gray-200 text-gray-400 cursor-not-allowed` | 비활성 |

### Badge

| 변형 | 스타일 | 용도 |
|---|---|---|
| NEW | `bg-secondary text-white text-xs px-1` | 신상품 |
| SALE | `bg-primary text-white text-xs px-1` | 할인 |
| 품절 | `bg-gray-500/70 text-white` (오버레이) | 재고 없음 |
| 상태 | `bg-success/warning/error text-white text-xs rounded px-2` | 주문 상태 |

### Input

| 변형 | 패턴 | 용도 |
|---|---|---|
| Text | `border border-gray-300 rounded px-3 py-2 text-sm` | 일반 입력 |
| Search | 돋보기 아이콘 + `rounded-full bg-gray-100` | 검색 |
| Stepper | `-` `수량` `+` 버튼 조합 | 수량 선택 |

### Card

| 변형 | 구조 | 용도 |
|---|---|---|
| ProductCard | 이미지(1:1) + 뱃지 + 상품명 + 가격 | 상품 목록 |
| OrderCard | 주문번호 + 상태뱃지 + 상품요약 + 금액 | 주문 목록 |
| ClaimCard | 클레임번호 + 유형 + 상태 + 타임라인 | 클레임 목록 |

### Toast

| 변형 | Tailwind 클래스 패턴 | 용도 |
|---|---|---|
| Success | `fixed bottom-16 left-1/2 -translate-x-1/2 bg-secondary text-white px-4 py-2 rounded-lg text-xs shadow-lg z-50` | 장바구니 담기 완료, 저장 완료 |
| Error | `fixed bottom-16 left-1/2 -translate-x-1/2 bg-error text-white px-4 py-2 rounded-lg text-xs shadow-lg z-50` | 결제 실패, 재고 부족 |
| 동작 | 2초 후 자동 fadeOut (opacity transition 300ms) | |

### LayerPopup (BottomSheet)

| 요소 | Tailwind 클래스 패턴 | 설명 |
|---|---|---|
| Overlay | `fixed inset-0 bg-black/50 z-40` | 딤 배경 (클릭 시 닫기) |
| Sheet | `fixed bottom-0 left-0 right-0 max-w-[360px] mx-auto bg-white rounded-t-2xl z-50 max-h-[80vh] overflow-y-auto` | 컨텐츠 영역 |
| Header | `flex items-center justify-between px-4 py-3 border-b border-gray-200` | 타이틀 + [✕] 닫기 |
| Body | `px-4 py-3` | 본문 |
| Footer | `px-4 py-3 border-t border-gray-200` | CTA 버튼 |
| 용도 | 옵션 변경, 쿠폰 적용, 배송지 선택, 배송비 결제 | |

### Skeleton (로딩)

| 요소 | Tailwind 클래스 패턴 | 설명 |
|---|---|---|
| Block | `bg-gray-200 rounded-lg animate-pulse` | 카드/섹션 플레이스홀더 |
| Line | `h-3 bg-gray-200 rounded animate-pulse` | 텍스트 줄 플레이스홀더 |
| Circle | `w-10 h-10 bg-gray-200 rounded-full animate-pulse` | 아바타/아이콘 플레이스홀더 |
| 사용법 | `{loading && <Skeleton />}` → API 응답 후 실제 데이터로 교체 | |
