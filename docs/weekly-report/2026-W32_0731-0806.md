### 2.2 (08/04) 방법론 보완 + 인터페이스 명세 + 기술참조문서 + 보고용 자료 (3개 커밋, 가장 큰 작업일)

  ~15 endpoints/11 error codes 작성. 프로모션 할인 유형 체계 반영(상품단위 택1 + 플랫폼단위 분리),

  크리티컬 패스)
- **도메인 의존관계 보강**: Member 도메인 신규 편입(포인트·배송지·인증 관련 우선업무 P2→P1

  병렬 타임라인**으로 확장, 의존관계 맵·타이밍 다이어그램 PlantUML 2건 추가. §5.9 "도메인 내부
  선행 관계" 신설(Catalog 7단계/Promotion 4단계/Member 6단계), 3개 도메인은 Phase 0 전체 Mock
  대체 가능 표기. 정책 결정 필요 3건 식별(장바구니 할인 수치·등급 기준·적립률)

  지침서·작성가이드 다이어그램 전량 PlantUML 전환
