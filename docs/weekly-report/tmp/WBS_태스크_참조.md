
A. WBS 초안(6개월)
6개월을 24주로 보고 초안을 수립

WBS의 최상위 구조 자체를 프로젝트 단계로 잡고, 실제 개발 단위는 Bolt 아래로 내려가는 방식.

B. 24주 일정으로 배치
핵심은 Bolt 개발을 순차적으로 하지 않고 병렬로 진행하는 것입니다.

1.대략 구조
| Phase                      |  기간 | 주차     |
| -------------------------- | --: | ------ |
| **착수**                     |  2주 | 1~2주   |
| **범위정의**                   |  4주 | 2~5주   |
| **구조설계**                   |  4주 | 4~7주   |
| **Bolt 상세설계/구현/단위·기능 테스트** | 12주 | 7~18주  |
| **통합 테스트**                 |  4주 | 17~20주 |
| **시스템 테스트**                |  3주 | 20~22주 |
| **오픈 준비/오픈**               |  2주 | 22~23주 |
| **안정화**                    |  2주 | 23~24주 |

D.산출물 검토는 단계의 마지막 Gate Task
범위정의
  ↓
[산출물 검토]
  ↓
구조설계
  ↓
[산출물 검토]
  ↓
Bolt 개발
  ↓
[개발 결과물 품질 점검]
  ↓
통합/시스템 테스트
  ↓
오픈
  ↓
안정화
  ↓
[최종 산출물 검토]
