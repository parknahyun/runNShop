## 14.1 검색 기준

| 항목 | 기준 |
|------|------|
| 검색 대상 필드 | 상품명·브랜드·태그 전체 |
| 검색 방식 | 키워드 부분 일치 (Like 검색) |
| 기본 정렬 | **출시일 내림차순** (최신 출시 상품 우선) |
| 품절 상품 노출 | **동일 위치 노출** (하단 이동·숨김 없음) |
| 검색 결과 없음 | 연관 상품 추천 (MD 수동 설정) |
| 출시일 필드 | `release_date` — 입점사·MD가 상품 등록 시 직접 입력 |

## 14.2 정렬 옵션

| 정렬 | 기준 | 기본값 |
|------|------|--------|
| 최신순 | 상품 출시일 내림차순 | ✅ 기본 |
| 인기순 | 최근 30일 판매량 기준 | |
| 낮은 가격순 | 판매가 오름차순 | |
| 높은 가격순 | 판매가 내림차순 | |
| 리뷰 많은순 | 리뷰 수 내림차순 | |
| 평점 높은순 | 평균 별점 내림차순 | |

## 14.3 필터 항목

| 필터 | 항목 | 선택 방식 |
|------|------|----------|
| 카테고리 | 러닝화·의류·기어·보충제·디바이스 | 단일 선택 |
| 브랜드 | 등록 브랜드 목록 | 복수 선택 |
| 가격대 | 직접 입력 또는 구간 선택 | 범위 입력 |
| 성별 | 남성·여성·공용 | 복수 선택 |
| 사이즈 | 카테고리별 사이즈 목록 | 복수 선택 |
| 평점 | 4점 이상·3점 이상 | 단일 선택 |
| 배송 | 무료배송만 보기 | 단일 선택 |

## 14.4 운영 기준

- 자동완성: 브랜드명·상품명 기준 제공
- 최근 검색어: 로그인 회원 기준 최대 10개 저장
- 인기 검색어: MD 수동 관리 (실시간 집계 미적용, 추후 배치 추가 가능)
- MD 추천 상품: 검색 결과 상단 고정 가능 (MD 수동 설정)
