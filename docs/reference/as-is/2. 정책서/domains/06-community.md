## 6.1 운영 단계

**1단계 (기본)**: 리뷰·평점·QnA 기반 단순 게시판
- 구매 인증 리뷰에 포인트 지급하여 참여 유도

**2단계 (러너의 놀이터)**:

| 기능 | 내용 |
|------|------|
| 러닝 기록 공유 | Apple Watch·Garmin 등 웨어러블 데이터 연동, 러닝 로그 게시 |
| 크루 기능 | 러닝 크루 생성·가입·활동 기록 공유 |
| 챌린지 | 거리·페이스·횟수 기반 챌린지, 달성 시 쿠폰·배지 지급 |
| 코스 추천 | 지역별 러닝 코스 등록·추천·리뷰 |
| AI 코치 연동 | 훈련 데이터 기반 개인화 피드백 및 용품 추천 연계 |

## 6.2 운영 기준

- 비방·허위 리뷰는 모니터링 후 삭제 처리
- 커뮤니티 활동 지수를 회원 등급에 반영
- 입점사의 커뮤니티 직접 마케팅 행위 금지
