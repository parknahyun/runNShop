## 18.1 외부 연동 대상

| 연동 대상 | 용도 | 연동 방식 |
|----------|------|----------|
| PG사 | 결제 승인·취소·환불 | API |
| 배송사 2곳 | 운송장 등록·배송 추적·완료 이벤트 | API |
| 본인인증 서비스 | 회원가입·비밀번호 찾기 인증 | API |
| 카카오 알림톡 | 알림 발송 1순위 채널 | API |
| SMS 서비스 | 알림 발송 2순위 채널 | API |
| 웨어러블 (Apple Health·Garmin·Strava) | 러닝 데이터 연동 | OAuth + API |

## 18.2 API 장애 처리 기준

| 연동 대상 | 장애 시 처리 | Fallback |
|----------|-----------|---------|
| PG사 | 결제 실패 처리 + 운영팀 알림 | 없음 (결제 중단) |
| 배송사 API | 수동 운송장 등록 허용 | 수동 처리 |
| 본인인증 | 인증 불가 안내 + 재시도 유도 | 없음 |
| 카카오 알림톡 | SMS Fallback 자동 전환 | SMS → 이메일 |
| SMS | 이메일 Fallback 자동 전환 | 이메일 |
| 웨어러블 | 연동 해제 안내 + 수동 입력 유도 | 수동 입력 |

## 18.3 API 재시도 정책

| 연동 대상 | 재시도 횟수 | 재시도 간격 |
|----------|-----------|-----------|
| PG사 결제 | 동기: 없음 / 비동기: 3회 | 즉시 → 30초 → 1분 |
| 배송사 | 3회 | 즉시 → 30초 → 1분 |
| 알림 발송 | 3회 | 즉시 → 30초 → 1분 |
| 웨어러블 | 1회 | 즉시 |

## 18.4 API 정합성 검증 기준

| 항목 | 기준 |
|------|------|
| 결제 금액 검증 | PG사 승인 금액과 주문 금액 일치 여부 확인. 불일치 시 결제 취소 + 운영팀 알림 |
| 배송 상태 검증 | 배송사 상태와 주문 상태 불일치 시 운영팀 알림 |
| 재고 정합성 | 주문 처리 후 실재고와 시스템 재고 불일치 시 운영팀 알림 |
