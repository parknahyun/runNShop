## 17.1 로그 레벨 정의

| 레벨 | 코드 | 용도 | 예시 |
|------|------|------|------|
| 오류 | `ERROR` | 시스템 오류·예외 발생 | 결제 승인 실패, API 오류 |
| 경고 | `WARN` | 비정상이지만 처리 가능 | 재시도 발생, 임계치 근접 |
| 정보 | `INFO` | 주요 비즈니스 이벤트 | 주문 생성, 배송 시작 |
| 디버그 | `DEBUG` | 개발·운영 디버깅용 | 파라미터 값, 처리 흐름 |

### 환경별 로그 레벨 기준

| 환경 | 최소 로그 레벨 | 비고 |
|------|-------------|------|
| 운영 (Production) | `INFO` | ERROR·WARN·INFO만 수집 |
| 스테이징 (Staging) | `DEBUG` | 전체 수집 |
| 개발 (Development) | `DEBUG` | 전체 수집 |

## 17.2 트랜잭션 추적 (Trace) 정책

액션 하나에 대한 전체 흐름을 Trace ID 기반으로 추적한다.

### 추적 ID 구조

```
Trace ID  : 액션 최초 진입 시 발급. 전체 흐름 추적 단위
Span ID   : Trace 내 각 처리 단계 단위
Parent ID : 상위 Span 참조 (계층 구조)
```

### Trace ID 생성 규칙

```
TRC-{YYYYMMDD}-{일련번호 8자리}
예) TRC-20260617-00000001
```

### 예시 — 주문 결제 흐름 추적

```
[Trace ID: TRC-20260617-00000001]
    │
    ├─ Span 1: 주문 요청 수신 (INFO)
    ├─ Span 2: 임시 주문 생성 (INFO)
    ├─ Span 3: 재고 확보 시도 (INFO)
    │       └─ Span 3-1: 재고 선점 (DEBUG)
    ├─ Span 4: 결제 승인 요청 (INFO)
    │       ├─ Span 4-1: PG API 호출 (DEBUG)
    │       └─ Span 4-2: PG 응답 수신 (DEBUG)
    └─ Span 5: 주문 상태 PAYMENT_COMPLETED 전환 (INFO)
```

### 추적 ID 전파 기준

| 항목 | 기준 |
|------|------|
| 발급 시점 | 고객 요청 최초 진입 시 |
| 전파 방식 | HTTP Header `X-Trace-Id` 로 전 서비스 전달 |
| 외부 API 호출 시 | Trace ID 함께 전달 (PG사·배송사·알림) |
| 로그 출력 형식 | `[TraceID] [SpanID] [레벨] 메시지` |
| Trace 조회 | 운영 어드민에서 Trace ID 기반 전체 흐름 조회 가능 |

## 17.3 감사 로그 수집 항목

| 도메인 | 수집 항목 |
|--------|----------|
| 주문 | 주문 생성·상태 변경·취소·반품·교환 |
| 결제 | 결제 요청·승인·실패·환불·보상 처리 |
| 재고 | 재고 등록·수정·선점·복구·품절 전환 |
| 가격 | 정가·판매가·공급가 변경 (변경 전·후값·변경자·변경 시각) |
| 상품 상태 | DRAFT → ON_SALE → SOLD_OUT → DISCONTINUED 등 모든 상태 전이 |

## 17.4 로그 기록 기준

| 항목 | 기준 |
|------|------|
| 기록 시점 | 이벤트 발생 즉시 |
| 기록 항목 | Trace ID·Span ID·이벤트 유형·처리 시각·처리 주체·변경 전값·변경 후값 |
| 처리 주체 구분 | 시스템 자동 처리 / 고객 / 입점사 / 운영자 |
| 수정·삭제 | 로그 수정·삭제 불가 (Append-only) |

## 17.5 로그 보존 기간

| 유형 | 보존 기간 | 비고 |
|------|----------|------|
| ERROR 로그 | 1년 | |
| WARN 로그 | 1년 | |
| INFO 로그 | 1년 | |
| DEBUG 로그 | 30일 | 운영 환경 미수집, 스테이징만 |
| Trace 전체 | 1년 | Trace ID 기준 묶음 보존 |
| 만료 처리 | 보존 기간 초과 시 자동 삭제 | |

## 17.6 로그 활용 기준

| 활용 목적 | 대상 로그 |
|----------|----------|
| 정산 분쟁 증빙 | 주문·결제·가격 변경 로그 |
| 클레임 귀책 판단 | 주문·재고·상품 상태 로그 |
| 가격 이력 추적 | 가격 변경 로그 |
| 상품 운영 이력 | 상품 상태 변경 로그 |
| 오류·보상 처리 추적 | 결제·재고 로그 + Trace 추적 |
| 운영팀 수동 처리 이력 | 전체 로그 |

## 17.7 모니터링 연동

| 항목 | 기준 |
|------|------|
| ERROR 발생 | 즉시 운영팀 알림 |
| 동일 ERROR 반복 | 10분 내 2회 이상 → 관리자 알림 |
| Trace 조회 | 운영 어드민에서 Trace ID 기반 전체 흐름 조회 |
