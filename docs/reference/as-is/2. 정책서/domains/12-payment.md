## 12.1 지원 결제 수단

| 단계 | 수단 | 조건 |
|------|------|------|
| 1단계 (기본) | 신용카드 | 런칭 시점 |
| 2단계 | 간편결제 (카카오페이·네이버페이·토스) | 추후 추가 |

## 12.2 결제 처리 기준

| 항목 | 기준 |
|------|------|
| 재고 선점 시점 | TEMP 생성 시 |
| 선점 유지 시간 | 30분 (결제 페이지 체류 기준) |
| 미결제 자동 취소 | 30분 경과 시 재고 해제 + 임시 주문 소멸 |
| 결제 실패 재시도 | 동기: 없음 / 비동기: 최대 3회 |
| PG 응답 대기 시간 | 30초 (초과 시 결제 실패 처리) |
| PROCESSING 최대 시간 | 3분 (초과 시 자동 CANCELLED + 보상 처리) |

## 12.3 혼합 결제 (포인트 + 카드)

```
결제금액 = 포인트 사용금액 + 카드 결제금액

적용 순서:
1. 포인트 차감 (최소 1,000원, 최대 결제금액 100%)
2. 잔여 금액 카드 결제
```

| 항목 | 기준 |
|------|------|
| 포인트 단독 결제 | 허용 |
| 카드 단독 결제 | 허용 |
| 포인트 + 카드 혼합 | 허용 |
| 취소 시 환불 | 포인트 복원 + 카드 취소 각각 처리 |

## 12.4 결제 취소·환불 처리

| 결제 수단 | 환불 방식 | 소요 기간 |
|----------|----------|----------|
| 신용카드 | 카드사 취소 | 영업일 3~5일 |
| 포인트 | 즉시 복원 | 즉시 |
| 혼합 결제 | 각 수단별 환불 | 수단별 기준 적용 |

## 12.5 결제 보안 기준

- PG사 표준 보안 모듈 적용 (카드 정보 플랫폼 미저장)
- 이상 결제 탐지 시 FDS 연동 자동 차단
- 결제 실패 3회 연속 시 해당 카드 당일 사용 제한
