## 9.1 쿠폰

- **발행 주체**: 플랫폼 발행 쿠폰 / 입점사 발행 쿠폰 구분
- **적용 기준**: 상품 단위·카테고리 단위·주문 단위 적용 구분
- **중복 사용**: 플랫폼 쿠폰과 입점사 쿠폰은 중복 적용 가능하나, 동일 주체 쿠폰은 1장만 적용
- **비용 부담**: 플랫폼 쿠폰은 플랫폼 부담, 입점사 쿠폰은 입점사 부담, 공동 쿠폰은 계약 비율에 따라 분담
- **유효기간**: 발행일 기준 최대 90일, 이벤트성 쿠폰은 별도 기간 설정 가능

## 9.1-1 행사가 수량 관리

- 행사가 수량은 Redis에서 실시간 관리한다
- 주문 시 Redis DECR로 차감, 취소 시 INCR로 복구 (행사 기간 내)
- Redis 장애 시 DB 기준으로 fallback 처리

## 9.2 장바구니 할인

- 주문 금액 구간별 자동 할인 적용 (예: 5만원 이상 3,000원 할인)
- 특정 상품 조합 구매 시 추가 할인 적용 가능
- 장바구니 할인과 쿠폰 중복 적용 가능 여부는 프로모션 설정에서 개별 제어

## 9.3 회원등급 쿠폰

- **등급 체계**: New → Runner → Pacer → Elite (4단계)
- **쿠폰 지급 시점 1**: 등급 승급 시 즉시 지급 (승급 등급 기준 쿠폰 수)
- **쿠폰 지급 시점 2**: 매년 12월 31일 현재 등급 기준 일괄 지급
- **등급별 쿠폰 수량**: New 0장 / Runner 1장 / Pacer 2장 / Elite 3장
- **등급 산정 주기**: 월 1회 갱신, 하향 시 1개월 유예 기간 부여
