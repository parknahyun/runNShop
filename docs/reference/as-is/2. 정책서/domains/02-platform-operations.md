# 러닝 커머스 플랫폼 정책서 — 2. 플랫폼 운영 정책

## 2.1 운영 방식

플랫폼은 **직매입(DIRECT)**과 **입점형(VENDOR)**의 하이브리드 구조로 운영한다.

## 2.2 입점 유형 정의

| 구분 | 직매입 (DIRECT) | 입점형 (VENDOR) |
|------|----------------|----------------|
| 재고 소유 | 플랫폼 | 입점사 |
| 출고 주체 | 플랫폼 물류 | 입점사 직접 |
| 가격 결정 | 플랫폼 MD | 입점사 (최저가 유지 요구 정책 적용) |
| 정산 방식 | 매입가 기준 내부 정산 | 판매가 기준 수수료 차감 |
| CS 1차 대응 | 플랫폼 | 플랫폼 (이행은 입점사) |
| 주요 리스크 | 재고 부담 | 이행 품질 부담 |

## 2.2-1 직매입 기초 데이터 설정

- 플랫폼 직매입 전용 입점사 계정을 시스템 기초 데이터로 생성
- vendor_id = 1 예약 (시스템 고정값)
- vnd_vendor.is_platform_direct = TRUE
- 정산 계산 대상에서 제외 (내부 정산 처리)
- 상품 등록·심사·배송·클레임은 플랫폼 어드민에서 처리

## 2.3 단일 공급 원칙 (1 Product : 1 Supplier)

- 동일 상품(`product_id`)은 직매입·입점형 구분 없이 **단일 공급 주체만 허용**한다.
- 플랫폼 직매입과 입점사 공급이 동시에 존재할 수 없다.
- 공급 주체 변경 시 기존 계약 종료 후 신규 등록으로 처리한다.
- 상품 등록 시 `supplier_id` 기준 중복 체크로 중복 공급을 차단한다.

## 2.4 상품 등록 권한

| 항목 | 직매입 | 입점형 |
|------|--------|--------|
| 상품 등록 | 플랫폼 MD | 입점사 BO |
| 가격 수정 | 플랫폼 MD | 입점사 BO (최저가 유지 요구 정책 범위 내) |
| 재고 수정 | 플랫폼 WMS | 입점사 BO |
| 노출 관리 | 플랫폼 어드민 | 공동 (플랫폼 최종 승인) |

## 2.5 입점 자격 기준

- 입점 가능 사업자 유형: 법인·개인사업자·브랜드 직영
- 러닝 전문 카테고리 적합성 기준 충족 (러닝화·의류·기어·보충제·웨어러블 등)
- 브랜드 정품 인증 요건 충족
- 최소 상품 수 및 월 거래 가능 물량 기준 충족

## 2.6 입점 심사 프로세스

신청 → 서류 검토 → 상품 적합성 심사 → 계약 → 입점

- 심사 기간: 영업일 기준 7일 이내
- 결과 통보: 심사 완료 후 1영업일 이내
- 재심사 조건: 거절 사유 해소 후 30일 이후 재신청 가능

**입점사 상태 전이**

```
신청 → 서류검토 → 심사중 → 계약체결 → 운영중
                         ↓
                       거절 → (재신청)
```

## 2.7 입점 계약 조건

| 항목 | 기준 |
|------|------|
| 계약 기간 | 1년 (기본), 만료 30일 전 미해지 시 자동 갱신 |
| 계약 형태 | 전자계약 (공인전자서명 기반) |
| 독점 공급 | 기본 비독점, 브랜드 독점 계약 별도 협의 |
| 최저가 유지 요구 | 타 채널 대비 낮은 가격 인지 시 가격 인상 요구권 행사. 미수용 시 플랫폼 임의 행사 제외 가능. 고객 보상 없음 |

## 2.8 입점사 등급 체계

입점사 등급은 **고객 회원 등급과 동일한 4단계 명칭**을 사용한다.

### 등급 구분

| 등급 | 명칭 | 진입 조건 |
|------|------|----------|
| 1 | 신규 (New) | 입점 후 3개월 미만 또는 기준 미달 |
| 2 | 일반 (Runner) | 60점 이상 + 월 거래액 100만원 이상 |
| 3 | 우수 (Pacer) | 75점 이상 + 월 거래액 500만원 이상 |
| 4 | 프리미엄 (Elite) | 90점 이상 + 월 거래액 2,000만원 이상 |

### 등급 산정 기준 (월 1회 자동 산정)

| 지표 | 가중치 | 측정 기준 |
|------|--------|----------|
| 월 거래액 | 40% | 최근 3개월 평균 구매확정 거래액 |
| 주문 이행률 | 30% | 정상 출고 건수 / 전체 주문 건수 |
| 클레임율 | 20% | 클레임 건수 / 전체 주문 건수 (낮을수록 유리) |
| 리뷰 평점 | 10% | 최근 3개월 평균 별점 |

### 등급별 혜택

| 혜택 항목 | 신규 | 일반 | 우수 | 프리미엄 |
|-----------|------|------|------|----------|
| 수수료 감면 | 0% | -1% | -2% | -3% |
| 정산 주기 | 익월 15일 | 익월 15일 | 익월 10일 | 익월 5일 |
| 노출 우선순위 | 기본 | 기본 | 우선 | 최우선 |
| 전담 MD 배정 | X | X | O | O |
| 광고 크레딧 | X | X | 월 10만원 | 월 30만원 |
| 챌린지 공식 스폰서 | X | X | X | O |

### 등급 운영 기준

- **산정 주기**: 매월 1일 전월 데이터 기준 자동 갱신
- **하향 유예**: 등급 하향 시 1개월 유예 후 적용
- **신규 보호**: 입점 후 3개월간 등급 하향 없음
- **이의신청**: BO를 통해 7일 이내 신청, 14일 이내 결과 통보

## 2.9 입점 제한 및 퇴점 정책

- 판매 금지 상품: 모조품, 미인증 건강기능식품 등
- 운영 기준 미달 시: 경고 → 판매 중지 → 강제 퇴점 단계 적용
- 퇴점 시 진행 중인 주문·정산·재고는 별도 기준에 따라 처리

## 2.10 직매입 전환 프로세스

### 전환 원칙

- 입점형 상품의 직매입 전환은 **입점 계약과 무관하게 상품 단위**로 처리한다.
- 입점사는 계약을 유지한 채 해당 상품만 판매 종료하며, 플랫폼은 직매입 신규 상품으로 등록한다.
- 직매입 전환 상품은 **신규 `product_id`를 발번**한다.

### 전환 트리거 유형

| 유형 | 트리거 | 주도 주체 |
|------|--------|----------|
| 전략적 전환 | 플랫폼이 직매입 전환 대상으로 지정 | 플랫폼 MD |
| 계약 종료 전환 | 입점사 계약 만료·해지 후 직매입 유지 결정 | 플랫폼 MD |
| 강제 전환 | 입점사 운영 기준 미달·퇴점 후 상품 유지 필요 | 플랫폼 운영팀 |

### 전환 단계별 프로세스

| 단계 | 내용 | 처리 주체 |
|------|------|----------|
| Step 1. 전환 협의 | 전환 대상 상품 지정 및 입점사 통보 (최소 14일 전), 매입가·재고 처리 방식 협의 | 플랫폼 MD |
| Step 2. 판매 종료 | 대상 상품 신규 주문 차단, 진행 중 주문은 입점사 계속 이행, 입점사 계약 유지 | 플랫폼 운영팀 |
| Step 3. 재고 처리 | [경로A] 재고 인수: 실사 → 매입가 협의 → 플랫폼 입고 / [경로B] 재고 소진: 입점사 자체 소진 후 직매입 발주 | 플랫폼 MD / 입점사 |
| Step 4. 신규 등록 | 직매입 신규 상품 등록 (product_id 신규 발번), 1 Product : 1 Supplier 원칙 적용 | 플랫폼 MD |

### 데이터 승계 처리

| 데이터 항목 | 승계 여부 | 처리 방식 |
|------------|----------|----------|
| 리뷰·평점 | 미승계 (원칙) | 신규 상품이므로 미승계. 운영 정책으로 별도 허용 가능 |
| 판매 통계 | 미승계 | 입점형 이력은 별도 보존 |
| 상품 이미지·설명 | 협의 | 저작권 확인 후 재사용 또는 재제작 |
| 가격 | 미승계 | 플랫폼 직매입가로 신규 설정 |

### 콘텐츠 저작권 처리 기준

| 콘텐츠 유형 | 저작권 귀속 | 처리 방식 |
|------------|-----------|----------|
| 입점사 자체 촬영 이미지 | 입점사 | 사용 시 입점사 서면 동의 필수. 미동의 시 플랫폼 재촬영 |
| 브랜드 공식 제공 이미지 | 브랜드사 | 브랜드사 직접 사용 허가 확인 후 재사용 가능 |
| 입점사 작성 상품 설명 | 입점사 | 사용 시 입점사 서면 동의 필수. 미동의 시 플랫폼 재작성 |
| 브랜드 공식 제공 설명 | 브랜드사 | 브랜드사 허가 확인 후 재사용 가능 |
| 고객 리뷰 이미지·텍스트 | 고객 | 직매입 신규 상품으로 미승계 (원칙) |

콘텐츠 사용 동의 여부는 전환 협의(Step 1) 시 동시에 협의하며, 미동의 시 플랫폼이 자체 재제작하고 비용은 플랫폼이 부담한다.
