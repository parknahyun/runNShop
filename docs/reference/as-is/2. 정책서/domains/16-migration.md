## 16.1 초기 데이터 기준

신규 플랫폼으로 초기 데이터 이관 없음. 모든 데이터는 런칭 후 신규 등록으로만 적재한다.

| 항목 | 기준 |
|------|------|
| 초기 데이터 | 없음 (신규 플랫폼 런칭) |
| 마이그레이션 대상 | 해당 없음 |
| 런칭 시 초기 적재 | 입점사·상품·회원 데이터 신규 등록만 허용 |

## 16.2 시스템 전환 기준

Monolith → MSA 전환 시 서비스 무중단 원칙을 적용한다.

| 항목 | 기준 |
|------|------|
| 전환 방식 | Blue-Green 배포 |
| 무중단 원칙 | 서비스 중단 없이 전환 |
| 데이터 정합성 | 전환 전·후 데이터 검증 필수 |
| 롤백 기준 | 전환 후 오류 발생 시 즉시 이전 버전으로 롤백 |
| 전환 완료 기준 | 1시간 무오류 운영 확인 후 확정 |
