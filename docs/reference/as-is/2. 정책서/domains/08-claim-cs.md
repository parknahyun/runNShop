## 8.1 클레임 접수 기준

- **취소**: 출고 전(PREPARING 이전) 언제든 신청 가능
- **반품·교환**: 배송완료일 기준 **10일 이내** 신청 가능
- 클레임 신청 채널: 플랫폼 내 주문 상세 페이지
- 플랫폼이 1차 접수 및 대응하며, 필요 시 입점사와 협업한다.

## 8.2 귀책 판단 기준

### 판단 프로세스

```
클레임 신청 → 고객 사진 첨부 → 플랫폼 1차 판단
    ↓
[입점사 귀책]               [고객 귀책]
입점사에 통보               고객에 통보
입점사 비용 부담            고객 비용 부담
                              ↓
                          실물 수령 후 협의로 변경 가능
```

### 귀책 판단 기준표

| 귀책 주체 | 사유 예시 |
|----------|----------|
| 입점사 귀책 | 상품 불량, 오배송, 상품 설명 상이, 파손 배송 |
| 고객 귀책 | 단순 변심, 사이즈 오선택, 사용 후 반품 |
| 협의 대상 | 사진으로 판별 불가한 경우, 실물 수령 후 재판단 |

### 귀책 변경 프로세스

- 초기 판단은 고객이 첨부한 사진을 기준으로 한다.
- 실물을 수령한 후 고객 귀책으로 확인되는 경우, 입점사와 고객 간 협의를 통해 귀책을 변경할 수 있다.
- 귀책 변경 시 플랫폼이 중재하며, 최종 결정은 플랫폼이 내린다.

## 8.3 유형별 처리 기준

### 취소

| 시점 | 처리 기준 |
|------|----------|
| 결제 후 출고 전 | 즉시 취소·환불 처리 |
| 출고 후 배송 중 | 반품 접수로 전환 |
| 배송완료 후 | 반품 절차 적용 |

### 반품

- 반품 신청 → 반품 배송 → 상품 검수 → 환불 처리
- 검수 완료 후 영업일 기준 3일 이내 환불
- 반품 배송비: 귀책 주체 부담
- 반품 확정 후 재고 복구. 단, 상품 상태(`SOLD_OUT`)는 담당자 수동 확인 후 변경

### 교환

- 교환 신청 → 회수 배송 → 상품 검수 → 교환 출고
- 교환 가능 조건: 동일 상품 내 옵션 변경 (색상·사이즈)
- 재고 없는 경우 교환 불가, 반품 후 재구매로 안내
- 교환 배송비: 귀책 주체 부담

## 8.4 환불 처리 기준

| 결제 수단 | 환불 방식 | 소요 기간 |
|----------|----------|----------|
| 신용카드 | 카드사 취소 | 영업일 3~5일 |
| 무통장입금 | 계좌 환불 | 영업일 3일 이내 |
| 포인트 결제 | 포인트 복원 | 즉시 |
| 혼합 결제 | 각 수단별 환불 | 수단별 기준 적용 |
