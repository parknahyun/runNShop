## 4.1 일반 회원

- **가입 방식**: 이메일 or SNS (네이버·Apple)
- **필수 수집 항목**: 이름·이메일
- **본인인증**: 가입 시 옵션널. 단, 주문 시 휴대폰 본인인증 필수 (세션 기준 1회). 동일 번호 중복 가입 불가
- **선택 수집 항목**: 러닝 경력·주 훈련 거리·착용 신발 사이즈·선호 브랜드
- **탈퇴 처리**: 즉시 탈퇴 처리, 거래 데이터는 관련 법령에 따라 보존

## 4.2 SNS 회원

- **지원 채널**: 네이버·Apple (1단계 런칭 기준)
- **최초 로그인 시**: 추가 정보(휴대폰·생년월일) 입력 필수
- **SNS 연동 해제 시**: 이메일 계정으로 자동 전환

## 4.3 회원 등급 체계

입점사 등급과 동일한 4단계 명칭을 사용한다.

### 등급 구분

| 등급 | 명칭 | 진입 조건 |
|------|------|----------|
| 1 | New | 가입 후 기준 미달 |
| 2 | Runner | 누적 구매 100만원 이상 + 활동지수 10점 이상 |
| 3 | Pacer | 누적 구매 200만원 이상 + 활동지수 20점 이상 |
| 4 | Elite | 누적 구매 300만원 이상 + 활동지수 30점 이상 |

> 등급 기준: 누적 구매금액 100만원 단위 + 커뮤니티 활동지수 10단위 합산

### 활동지수 산정 기준

| 활동 | 지수 |
|------|------|
| 구매 인증 리뷰 작성 | +2 |
| 러닝 기록 공유 | +1 |
| 크루 활동 참여 | +1 |
| 챌린지 완료 | +3 |
| QnA 답변 채택 | +2 |

### 등급별 혜택

| 혜택 항목 | New | Runner | Pacer | Elite |
|-----------|-----|--------|-------|-------|
| 기본 할인율 | 없음 | 없음 | 없음 | 없음 |
| 무료배송 기준 | 5만원 이상 | 3만원 이상 | 2만원 이상 | 무조건 무료 |
| 등급 승급 쿠폰 | 0장 | 1장 | 2장 | 3장 |
| 연말 등급 쿠폰 (12/31) | 0장 | 1장 | 2장 | 3장 |
| 챌린지 우선 참여 | X | X | O | O |
| 포인트 적립률 | 0.5% | 1.0% | 1.5% | 2.0% |

### 등급 운영 기준

- **산정 주기**: 매월 1일 자동 갱신
- **하향 유예**: 등급 하향 시 1개월 유예 후 적용
- **구매금액 기준**: 구매확정 완료 금액 기준 (취소·반품 제외)

## 4.4 포인트 정책

### 적립 기준

| 항목 | 기준 |
|------|------|
| 등급별 적립률 | New 0.5% / Runner 1.0% / Pacer 1.5% / Elite 2.0% |
| 최대 적립 한도 | 1건당 최대 1,000원 |
| 적립 시점 | 구매확정 완료 후 |

### 사용 기준

| 항목 | 기준 |
|------|------|
| 최소 사용 금액 | 1,000원 이상 보유 시 사용 가능 |
| 사용 비율 | 결제금액의 100%까지 사용 가능 |
| 사용 단위 | 1원 단위 |

### 유효기간 및 소멸

| 항목 | 기준 |
|------|------|
| 유효기간 | 적립일로부터 3년 |
| 소멸 방식 | 선적립 선소멸 (FIFO) |
| 소멸 안내 | 소멸 30일 전 알림 발송 |

### 포인트 비용 부담

결제 시 사용된 포인트는 상품별 공급가 비중에 따라 배분하며, 플랫폼과 입점사가 계약된 비율로 공동 부담한다.

- 플랫폼 부담: 70%
- 입점사 부담: 30%

## 4.5 러닝 데이터 연동 (선택)

- **연동 플랫폼**: Apple Health·Garmin Connect·Strava
- **수집 데이터**: 러닝 거리·페이스·심박수·케이던스
- **활용 범위**: AI 추천·커뮤니티 기능에 활용. 제3자 제공 금지

## 4.6 개인정보 보호

- 수집·이용·보관·파기 기준은 개인정보처리방침에 따름
- 마케팅 수신 동의는 채널별(이메일·SMS·앱푸시) 개별 관리
