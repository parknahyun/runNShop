## 19.1 소프트 삭제 원칙

> **물리적 삭제(DELETE) 없음. 모든 삭제는 소프트 삭제(Soft Delete) 플래그로 처리한다.**

| 항목 | 기준 |
|------|------|
| 삭제 방식 | `is_deleted = true` 플래그 설정 |
| 물리적 DELETE | **전면 금지** |
| 삭제 시각 | `deleted_at` 컬럼에 삭제 시각 기록 |
| 삭제 주체 | `deleted_by` 컬럼에 처리 주체 기록 |
| 조회 기본값 | `is_deleted = false` 조건 기본 적용 |
| 삭제 데이터 조회 | 관리자 어드민에서만 허용 |

## 19.2 공통 테이블 컬럼 기준

ERD 설계 시 모든 테이블에 아래 컬럼을 공통 적용한다.

```sql
is_deleted  BOOLEAN     NOT NULL DEFAULT FALSE,
deleted_at  DATETIME    NULL,
deleted_by  VARCHAR(50) NULL     -- 처리 주체 (시스템/운영자ID)
```

## 19.3 도메인별 소프트 삭제 적용 기준

| 도메인 | 삭제 트리거 | 비고 |
|--------|-----------|------|
| 회원 | 회원 탈퇴 | 거래 데이터 보존 의무 연동 |
| 입점사 | 퇴점·계약 해지 | 정산 이력 보존 |
| 상품 | 판매종료·강제 삭제 | `DISCONTINUED` 상태와 병행 |
| SKU | 옵션 삭제 | 주문 이력 보존 |
| 리뷰·QnA | 운영자 삭제 | 삭제 사유 기록 |
| 쿠폰 | 쿠폰 만료·삭제 | 사용 이력 보존 |
| 배송지 | 배송지 삭제 | 주문 이력 보존 |

## 19.4 소프트 삭제 감사 로그 연동

소프트 삭제 이벤트는 17장 로그·감사 정책 대상에 포함한다.

| 항목 | 기준 |
|------|------|
| 기록 항목 | 삭제 대상 테이블·PK·삭제 시각·삭제 주체·Trace ID |
| 보존 기간 | 1년 (17장 기준 동일 적용) |
