## FR-PAY-001 결제 처리
- **우선순위**: P1
- **내용**:
  - 1단계: 신용카드
  - 2단계: 간편결제 (카카오페이·네이버페이·토스)
  - 혼합 결제: 포인트 + 카드
  - PG 인증(AUTH_REQUEST → AUTH_APPROVED) → 결제 요청
  - PG 응답 대기: 30초
  - PG사: 토스페이먼츠 연동, 결제 완료 후 거래ID를 `TXN-{플랫폼주문번호 뒷 7자리}` 형식으로 발급해 결제정보에 표시
  - 주문서 화면에서 결제 수단 선택 UI 제공 (미선택 시 목록 첫 번째 수단 기본 선택)

## FR-PAY-002 재고 선점
- **우선순위**: P1
- **내용**:
  - 시점: PG 인증 완료 후 PG 결제 요청 시
  - Redis TTL 30분
  - 선점 실패 시 품절 안내·장바구니 복귀
  - TTL 만료 시 DB 동기화 배치
  - 관리자 주문 변경이력에 결제완료 직후 SKU 단위 재고 선점 이벤트 기록 (예: SKU-001 × 1)

## FR-PAY-003 결제 실패 보상
- **우선순위**: P1
- **내용**:
  - 동기 보상: 1회 시도 (재고·포인트·쿠폰 복원)
  - 실패 시 운영팀 이관
  - 비동기 재시도: 최대 3회 (즉시→30초→1분)
  - PROCESSING 타임아웃 (3분): CANCELLED + 보상

## FR-PAY-004 환불 처리
- **우선순위**: P1
- **내용**:
  - 신용카드: 카드사 취소 (영업일 3~5일)
  - 포인트: 즉시 복원
  - 혼합 결제: 각 수단별 처리
  - 반품 환불: 검수 완료 후 영업일 3일 이내

## FR-PAY-005 FDS 연동
- **우선순위**: P1
- **내용**:
  - PG사 FDS 연동 이상 결제 자동 탐지·차단
  - 결제 실패 3회 연속: 당일 카드 사용 제한
  - 이상 탐지 이력: pay_fds_log 저장
  - 임계치 초과 (10분 내 2회): 관리자 알림

## FR-PAY-006 추가 결제 (클레임)
- **우선순위**: P1
- **내용**:
  - 고객 귀책 반품 시 반품 배송비 추가 결제
  - pay_extra_payment 별도 관리
  - 정산 차감 아님 (별도 수납)
