## FR-ORD-001 장바구니
- **우선순위**: P1
- **내용**:
  - 입점사별 그룹핑 표시
  - 할인 혜택 안내 (쿠폰·포인트·장바구니할인)
  - 비로그인 장바구니 지원 (로그인 시 머지)
  - 수량 변경·삭제·전체 삭제
  - 입점사별 배송비·무료배송 기준 금액 표시 (기준 금액 이상 구매 시 무료배송)
- **관련 테이블**: ord_cart
- **관련 화면**: CUS-040

## FR-ORD-002 장바구니 유효성 검사
- **우선순위**: P1
- **내용**:
  - 재고 확인: 진입·머지 시 매번 실행
  - 행사 유효성: 변경 시에만 (carted_at vs updated_at)
  - 품절 SKU 비활성 처리·안내
  - 로그인 후 머지 시에도 동일 검사

## FR-ORD-003 주문서 처리
- **우선순위**: P1
- **내용**:
  - 주문 전 휴대폰 OTP 인증 필수 (세션 기준 1회)
  - 배송지 자동 선택 (기본 배송지)
  - 할인 적용: 행사가→수량할인→쿠폰→장바구니할인→포인트
  - 동기 사전 확인: Catalog·Promotion·Member API
  - 배송지: 기본 배송지 자동 선택 후 '변경' 버튼으로 등록된 다른 배송지로 교체 가능
  - 포인트: 최소 사용 금액(min_use) 이상만 사용 가능, 전액 사용 버튼 제공
  - 약관 동의: 전체 동의 체크박스 + 개별 약관(필수/선택) 동의 UI, 필수 약관은 라벨에 [필수] 표기
- **관련 화면**: CUS-041

## FR-ORD-004 주문 생성
- **우선순위**: P1
- **내용**:
  - 2계층: ord_platform_order (고객) + ord_order (입점사)
  - 비동기 생성: PROCESSING 상태 (3분 타임아웃)
  - 재고 확정 차감 후 품절 여부 자동 확인
  - TEMP 타임아웃: 30분 → CANCELLED (TempOrderTimeoutBatch)
  - 식별자 형식: 플랫폼 주문번호 `ORD-YYYYMMDD-NNN`(고객 노출), 입점사 주문ID `OD-NNNN`(내부 관리)

## FR-ORD-005 주문 목록·상세
- **우선순위**: P1
- **내용**:
  - 기간별 조회 (1개월·3개월·6개월·1년)
  - PlatformOrder 단위 표시
  - 3단계 클레임 액션 (Level 1: 전체·Level 2: 입점사·Level 3: 상품)
  - 배송 추적 연동
  - 주문 상태값: PAYMENT_COMPLETED(결제완료)·PREPARING(준비중)·IN_DELIVERY(배송중)·DELIVERED(배송완료)·CONFIRMED(구매확정)·CANCELLED(취소)·PAYMENT_FAILED(결제실패)
  - 고객 주문목록 상태별 액션 버튼: 결제완료(주문취소), 배송중(배송조회), 배송완료(구매확정·반품/교환), 구매확정(리뷰 작성)
  - 관리자 주문상세: 주문상품·결제정보·배송정보·CS·클레임·변경이력 탭으로 구성
  - 관리자 CS 액션: 클레임 접수, 장바구니 담아주기(교체), 결제완료 상태 주문에 한해 예외 취소 가능
- **관련 화면**: CUS-051, CUS-052

## FR-ORD-006 배송지 변경
- **우선순위**: P1
- **내용**:
  - PAYMENT_COMPLETED: 고객 직접 변경
  - PREPARING: CS(어드민) 직접 변경 + 입점사 알림
  - IN_DELIVERY 이후: 변경 불가

## FR-ORD-007 구매확정
- **우선순위**: P1
- **내용**:
  - 고객 수동 확정
  - 자동 확정: 배송완료 후 7일 (AutoConfirmBatch 매일 02:00)
  - 확정 후: 정산 대상 등록 + 포인트 적립 + 리뷰 작성 가능
  - 클레임 진행 중: 확정 보류
