## FR-CMT-001 상품 리뷰
- **우선순위**: P1
- **내용**:
  - 작성 조건: 구매확정 완료 후
  - 이미지: 최대 3장·1MB
  - 금지어 검증 (BLOCK·MASK)
  - 활동지수: +2점
  - 리뷰 포인트: ReviewCompleted → 적립
  - 평점 집계: cmt_rating (Catalog 연동)
  - 작성 단위: 구매확정된 주문상품(order_item) 1건당 리뷰 1건만 작성 가능
  - 상태값: 활성·숨김·삭제 — 숨김은 관리자가 사유를 입력해야 처리되며, 삭제는 고객 자진삭제·정책위반 등 외부 요인으로만 발생(관리자가 직접 삭제 처리하는 기능 없음)
  - 상품상세 화면에 평균평점·리뷰건수와 함께 평점별(5~1점) 분포를 그래프로 노출

## FR-CMT-002 상품 QnA
- **우선순위**: P1
- **내용**:
  - 고객 질문·입점사·MD 답변
  - 공개·비공개 설정
  - 금지어 검증
  - 활동지수: QnA 답변 채택 +2점
  - 유형: 상품문의(기본 공개, 운영자 또는 입점사 답변)·주문문의(개인정보 노출 우려로 공개여부 항상 비공개 고정, 운영자만 답변)로 구분해 통합 관리
  - 상태값: 답변대기·답변완료·숨김 — 답변 등록 시 답변완료로 전환, 숨김↔활성화 상호 전환 가능(숨김 사유 입력 없음)
  - 활동지수 지급은 답변 등록 이후에만 가능한 수동 지급 액션이며 1건당 1회만 지급(재지급 불가)
  - 고객의 문의 등록으로만 생성되며 운영자·입점사가 신규 QnA를 직접 등록하는 기능은 없음
