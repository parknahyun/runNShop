# runNshop 요구사항 정의서 — 15. 비기능 요구사항

> 상위 문서: [runNshop_requirements_v1_0.md](../runNshop_requirements_v1_0.md)
> 문서 버전: v1.0 | 상태: 확정 (Confirmed)
> 참고: 특정 도메인이 아닌 전체 시스템에 적용되는 교차(cross-cutting) 요구사항입니다.

---

## NFR-001 성능
- **우선순위**: P1
- **내용**:
  - 상품 목록 응답: 1초 이내
  - 주문·결제 처리: 5초 이내
  - 검색 응답: 0.5초 이내
  - 동시 접속: 1,000명 이상 처리

## NFR-002 가용성
- **우선순위**: P1
- **내용**:
  - 서비스 가용성: 99.9% 이상
  - 배포 시 무중단 (Blue-Green or Rolling)
  - 장애 복구: 1시간 이내

## NFR-003 보안
- **우선순위**: P1
- **내용**:
  - HTTPS 전 구간 적용
  - 개인정보 암호화 저장 (휴대폰·SNS ID)
  - 카드 정보 플랫폼 미저장 (PG사 위임)
  - SQL Injection·XSS 방어
  - IP 기반 어드민·입점사 BO 접근 제한

## NFR-004 확장성
- **우선순위**: P2
- **내용**:
  - Modular Monolith → MSA 전환 가능 구조
  - 도메인별 독립 스케일링 가능
  - Outbox → Kafka 전환 가능

## NFR-005 모니터링
- **우선순위**: P1
- **내용**:
  - Prometheus + Grafana
  - ERROR 발생 즉시 알림
  - DLQ 적재 즉시 알림
  - 결제 오류 임계치 (10분 내 2회) 관리자 알림

## NFR-006 데이터 보존
- **우선순위**: P1
- **내용**:
  - 주문·거래 이력: 5년 (전자상거래법)
  - 개인정보: 법령 기준 보존 후 파기
  - 감사 로그: 1년
