## FR-PRO-001 쿠폰 관리
- **우선순위**: P1
- **내용**:
  - 발행 주체: 플랫폼·입점사 구분
  - 적용 기준: 상품·카테고리·주문 단위
  - 중복: 플랫폼+입점사 중복 가능, 동일 주체 1장
  - 유효기간: 발행일 기준 최대 90일
  - 입점사 쿠폰: MD 승인 후 활성화
  - 비용 부담: 플랫폼/입점사/공동 구분
  - 쿠폰유형: 상품쿠폰(PRODUCT)/장바구니쿠폰(CART) 구분, 등록 후 변경 불가; 장바구니쿠폰은 적용상품이 항상 "전체"로 고정
  - 적용회원(전체/회원등급 다중선택/임의지정 엑셀업로드 .xlsx·.xls·.csv)과 적용상품(전체/임의선택/표준카테고리)은 서로 독립된 두 축으로 개별 구성 가능
  - 부분취소 정책(쿠폰 유지/재계산/부분취소 불가)은 장바구니쿠폰에만 적용(상품쿠폰은 상품 취소 시 혜택도 자연 무효화되어 정책 불필요)
  - 할인유형(정액/정률+최대할인금액), 발급방식(다운로드/자동발급/관리자 지급) 외 보유회원 관리 시 "임의발행" 발급경로 별도 지원
  - 보유회원(발급내역) 상태: 미사용/사용완료/만료
  - 입점사 등록 쿠폰은 승인대기→활성/반려/비활성 상태로 관리되며, 반려 시 반려사유를 화면에 노출
  - 비용분담률(0~100%) 필드로 플랫폼/입점사 비용 분담 비율 관리
  - 유효기간 90일 상한은 화면에서 강제하지 않고 자유 입력(이벤트성 쿠폰 등 예외 허용 목적)

## FR-PRO-002 행사가 관리
- **우선순위**: P1
- **내용**:
  - 기간·수량 한정 행사가 설정
  - Redis로 실시간 수량 관리 (DECR/INCR)
  - 수량 소진 시 EventPriceSoldOut 이벤트 발행
  - 장바구니 유효성 검사: updated_at 비교
  - 하나의 행사에 여러 상품을 함께 묶어 관리(상품 단위가 아닌 행사 단위), 상품마다 개별 수량한정 설정 가능
  - 행사 기본 할인율(%)을 지정하고 상품 추가 시 할인율/할인가가 연동 계산(할인가 = 정상가 × (1-할인율)); 실제로 상품에 최종 저장·적용되는 값은 정액할인(할인가 고정, 이후 재계산되지 않음)
  - 상품별 할인율 입력범위는 1~99%, 할인가는 정상가 미만이어야 함
  - 상태는 행사 단위(진행중/종료)로 관리, 개별 상품의 품절 여부는 상품별 수량한정·잔여수량으로 별도 표시

## FR-PRO-003 수량 할인
- **우선순위**: P1
- **내용**:
  - 적용 조건: MD 설정 + 동일 입점사 + 동일 판매가
  - 구간별 할인율 설정
  - 입점사 등록 후 MD 승인 필요
  - 구간설정 기준(tierScope): 구매수량을 적용상품별로 개별 카운트/적용상품 전체 합산으로 카운트 중 선택, 등록 후에도 변경 가능
  - 부분취소 정책(할인 유지/재계산/부분취소 불가) 개별 설정, 등록 후에도 변경 가능
  - 장바구니 수량 변경 시 그룹 전체가 재계산되며, 그룹 내 다른 상품의 적용 구간도 함께 바뀔 수 있음
  - 첫 상품 등록 후에는 동일 판매가 상품만 추가 가능(정책 검증)
  - 구간: 최소수량/최대수량(비우면 상한 없음)/할인율(1~100%)로 등록, 최소수량 오름차순 정렬 표시
  - 입점사(BO)도 자사 상품에 직접 수량할인을 등록할 수 있으며 승인대기→활성/반려/종료 상태로 관리, 반려 시 반려사유 표시, 활성 건은 입점사가 직접 종료 가능

## FR-PRO-004 장바구니 할인
- **우선순위**: P1
- **내용**:
  - 주문 금액 구간별 자동 할인
  - 주문서 진입 시 자동 적용
  - 쿠폰과 중복 적용 가능 여부 개별 제어
  - 적용단위(플랫폼 공통/입점사별) 구분
  - 할인유형(정액/정률+최대할인금액), 부분취소정책(할인 유지/재계산/부분취소 불가) 개별 설정
  - 최소주문금액을 기준으로 자동 적용 여부 판정

## FR-PRO-005 기획전 관리
- **우선순위**: P1
- **내용**:
  - 상품 목록·기간·배너 관리
  - 기획전 전시 페이지 연결
  - 상태: 진행중·D-N·종료
  - 고객 화면 기획전 메인·상세 페이지
  - 관리자 화면 상태는 미게시/예정/진행중/종료 4단계로 관리
  - 노출순서(MD 수동 지정) 필드로 목록 노출 순서 관리
  - 상세의 "소속 프로모션" 탭에서 즉시할인·쿠폰할인·수량별 할인·장바구니할인을 기획전에 묶어 순서(추가/이동/삭제)를 관리하도록 구현됨
  - 미리보기(모바일 프레임 시각화), 변경이력(변경일시/변경자/변경내용) 탭 제공

## FR-PRO-006 프로모션 그룹
- **우선순위**: P2
- **내용**:
  - 여러 프로모션을 그룹으로 묶어 관리
  - 그룹 단위 활성화·비활성화
  - 프로토타입에서는 별도의 "프로모션 그룹" 화면 대신, 기획전 상세의 "소속 프로모션" 탭 기능으로 일원화되어 구현됨(그룹이 기획전에 종속되며, 기획전과 무관한 전역 프로모션 묶음 기능은 화면 범위 밖)
