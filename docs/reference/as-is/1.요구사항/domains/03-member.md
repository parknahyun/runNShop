## FR-MBR-001 회원가입
- **우선순위**: P1
- **내용**:
  - 가입 방식: 이메일·네이버·Apple
  - 본인인증: 가입 시 옵션널 (주문 시 필수)
  - 이메일·휴대폰 중복 가입 불가
  - 약관 동의: 이용약관·개인정보 필수, 마케팅 선택
  - 웰컴 쿠폰 자동 발급
- **관련 화면**: CUS-081-01~05
- **관련 API**: `/api/v1/auth/join`

## FR-MBR-002 로그인·인증
- **우선순위**: P1
- **내용**:
  - 이메일·SNS (네이버·Apple) 로그인
  - JWT Access Token + Refresh Token 발급
  - 로그인 실패 5회 → 3일 계정 잠금
  - SNS 로그인 후 장바구니 머지
  - 머지 후 재고·행사 유효성 검사
  - 잠금 해제는 어드민이 회원 상태를 "정상"으로 변경하는 것으로 처리 (별도의 잠금해제 버튼 없음)
- **관련 화면**: CUS-080
- **관련 API**: `/api/v1/auth/login`, `/api/v1/auth/social/{provider}`

## FR-MBR-003 SNS OAuth 인증
- **우선순위**: P1
- **내용**:
  - 1단계: 네이버·Apple
  - OAuth URL 생성 → SNS 인증 → Token 교환 → 사용자 정보 수신
  - provider_id 기준 기존 회원 매칭
  - Apple: 이름 최초 1회, 이메일 릴레이 처리
- **관련 API**: `/api/v1/auth/social/{provider}`

## FR-MBR-004 회원 등급 관리
- **우선순위**: P1
- **내용**:
  - 4단계: New·Runner·Pacer·Elite
  - 산정 기준: 최근 3개월 구매금액 + 활동지수
  - 산정 주기: 매월 1일 자동 갱신 (MemberGradeBatch)
  - 하향 유예: 1개월
  - 등급 승급 시 즉시 쿠폰 지급
  - 매년 12/31 등급별 연말 쿠폰 일괄 지급 (YearEndGradeCouponBatch)
  - 구매금액·활동지수 중 더 높은 등급 기준을 충족하는 쪽으로 산정 (두 지표를 합산하지 않음)
  - 활동지수 적립: 구매인증리뷰 +2, 러닝기록공유 +1, 크루활동참여 +1, 챌린지완료 +3, QnA답변채택 +2

| 등급 | 구매금액 | 활동지수 | 적립률 | 무료배송 | 월 지급 쿠폰 |
|------|---------|---------|--------|--------|--------|
| New | - | - | 0.5% | 5만원 | 0장 |
| Runner | 100만원↑ | 10점↑ | 1.0% | 3만원 | 1장 |
| Pacer | 200만원↑ | 20점↑ | 1.5% | 2만원 | 2장 |
| Elite | 300만원↑ | 30점↑ | 2.0% | 무조건 | 3장 |

## FR-MBR-005 포인트 관리
- **우선순위**: P1
- **내용**:
  - 적립: 구매확정 후 등급별 적립률 (최대 1,000원/건)
  - 사용: 1,000원 이상 보유 시, 결제금액 100%까지
  - 유효기간: 3년 (소멸 30일 전 알림)
  - 입점사 부담: 30%
  - 거래유형: 적립(EARN)/사용(USE)/복원(RESTORE)/소멸(EXPIRE) — 취소·반품 시 사용 포인트는 복원 처리
  - 어드민에서 사유 입력 후 포인트 수동 지급 가능 (사유 필수, 지급 즉시 회원 포인트잔액에 반영)
- **관련 테이블**: mbr_point

## FR-MBR-006 쿠폰 관리
- **우선순위**: P1
- **내용**:
  - 보유 쿠폰 목록·사용 이력 조회
  - 쿠폰 적용: 주문서에서 선택
  - 유효기간: 발행일 기준 최대 90일
  - 복원: 취소·반품 시 자동 복원
  - 쿠폰 상태: 사용가능(AVAILABLE)/사용완료(USED)/만료(EXPIRED)
  - 어드민에서 CS 보상 쿠폰(5,000원/10,000원 정액), 재구매 유도 쿠폰(10%) 등 사전 정의된 쿠폰을 수동 발급 가능
- **관련 테이블**: mbr_member_coupon, mbr_member_coupon_log

## FR-MBR-007 배송지 관리
- **우선순위**: P1
- **내용**:
  - 최대 5개 배송지 등록
  - 기본 배송지 설정
  - 주문서 진입 시 기본 배송지 자동 선택
- **관련 화면**: CUS-063

## FR-MBR-008 약관 동의 관리
- **우선순위**: P1
- **내용**:
  - 약관 갱신 시 재동의 팝업 강제 노출
  - 필수 약관 미동의 시 서비스 이용 불가
  - 선택 약관 미동의 시 서비스 이용 가능
  - 동의 이력 저장 (mbr_terms_agreement)

## FR-MBR-009 러닝 프로필
- **우선순위**: P2
- **내용**:
  - 러닝 경력·주간 거리·신발 사이즈·선호 브랜드
  - 웨어러블 연동 정보 (Apple Health·Garmin·Strava)
- **관련 테이블**: mbr_member_running_profile

## FR-MBR-010 회원 관리 (어드민)
- **우선순위**: P1
- **내용**:
  - 회원 개인정보(이름·이메일·휴대폰) 조회 화면은 셋 중 1개 이상 입력해야만 검색 가능 (미입력 시 조회 불가, 목록 비노출)
  - 상태 4단계: 정상(ACTIVE)/잠금(LOCKED)/정지(INACTIVE)/탈퇴(WITHDRAWN) — 어드민은 상태만 변경 가능하며 이름·이메일·휴대폰 등 회원이 직접 등록한 정보는 수정 불가
  - 회원 검색·상세조회·상태변경·포인트지급·쿠폰발급은 모두 접근 이력(adt_member_access_log)에 기록되며, 검색어·회원명은 마스킹 저장 (예: `010-****-5678`)
  - 목록 요약: 전체/정상/잠금/정지/탈퇴 건수
- **관련 화면**: ADM-050-001, ADM-050-002
