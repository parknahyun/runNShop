## FR-CLM-001 취소
- **우선순위**: P1
- **내용**:
  - 신청 가능: PREPARING 이전 (출고 전)
  - 고객 직접 or CS 접수 (COUNSELOR 채널)
  - 자동 처리: PG 취소·재고 복구·포인트·쿠폰 복원
  - 예외 취소 (PREPARING 이후): CS + 입점사 협의
  - 입점사(파트너) 화면은 취소 건에 대해 조회만 가능 (배송 시작 전 플랫폼이 자동 처리하므로 별도 처리 액션 없음)

## FR-CLM-002 반품
- **우선순위**: P1
- **내용**:
  - 신청 기간: 배송완료 후 10일 이내 (ClaimExpireBatch 매일 02:00)
  - 다중 상품 선택·부분 수량 반품 지원
  - 사진 첨부: 최대 3장·1MB
  - 상태: RETURN_REQUESTED → RETURNING → RETURNED
  - 철회: 수거 전 가능 → RETURN_WITHDRAWN → DELIVERED 복귀
  - 고객 변심: 반품 배송비 추가 결제
  - 입점사 처리 상태: 접수 → 수거 운송장 등록 → 수거 완료 처리 → 재고 수동 복구 → (플랫폼 처리) 완료
  - 수거 운송장 등록 시 택배사(CJ대한통운·한진택배·롯데택배·로젠택배·우체국택배 중 선택) + 운송장번호(필수) 입력, 교환과 공용 폼 사용
  - 검수 완료 후 영업일 3일 이내 환불 처리
  - 고객 클레임 상세 화면에 반품 배송비, 수거 정보(택배사·운송장번호·수거상태·요청일시), 환불 정보(수단·상태·예상일)가 노출됨

## FR-CLM-003 교환
- **우선순위**: P1
- **내용**:
  - 신청 기간: 배송완료 후 10일 이내
  - 동일 상품 내 옵션 변경만 가능 (색상·사이즈)
  - 재고 없는 경우: 반품(환불) 전환
  - 상태: EXCHANGE_REQUESTED → EXCHANGING → EXCHANGED
  - 철회: 수거 전 가능 → EXCHANGE_WITHDRAWN → DELIVERED 복귀
  - 입점사 처리 상태: 접수 → 재고 확인 → 수거 운송장 등록 → 수거 완료 처리 → 교환 출고 완료

## FR-CLM-004 귀책 판단
- **우선순위**: P1
- **내용**:
  - 1차 판단: 플랫폼 CS (고객 사진 기준)
  - 입점사 이의제기 가능
  - 최종 결정: 플랫폼 확정
  - 귀책값: 고객귀책 / 입점사귀책 / 플랫폼귀책 / 판단중(기본값)
  - 입점사는 반품 건에 한해 귀책 판정에 대한 이의제기 의견을 등록 가능 (건당 1회, 등록 후 재등록 불가·이력에 기록)
  - 어드민 클레임현황(전체 유형 공통) 처리상태: 접수 → 처리중 → (완료 | 반려); 반려 시 반려사유 입력 필수이며 이력에 기록되고 고객에게 전달되는 것으로 처리

| 귀책 | 배송비 부담 |
|------|-----------|
| 고객 | 고객 |
| 입점사 | 입점사 |
| 플랫폼 | 플랫폼 |
