## FR-CFG-001 운영자 계정·권한
- **우선순위**: P1
- **내용**:
  - 5개 롤: 슈퍼관리자·MD·CS·정산담당·입점관리
  - 운영자 신청 → 슈퍼관리자 승인
  - 롤별 메뉴·기능 접근 권한 관리
  - 운영자 신청은 신청(APPLIED) → 승인(APPROVED)/반려(REJECTED) 단일 스텝으로 처리, 반려 시 반려사유 입력 필수
  - 자기신청 가능 역할: MD·CS·정산담당·입점관리(슈퍼관리자는 시스템 최초 계정에만 부여, 자기신청 대상 제외)
  - 운영자 상태: 신청(APPLIED)·활동(ACTIVE)·중지(SUSPENDED)·탈퇴(WITHDRAWN)
  - 롤(Role)은 상태(활성·중지·폐기)와 메뉴별 조회·수정 권한 매트릭스로 관리하며, 수정 권한은 조회 권한을 포함(수정 활성화 시 조회 자동 활성화, 조회 비활성화 시 수정 자동 비활성화)
  - 운영자 개별 권한 편집은 지원하지 않으며 소속 롤(Role) 단위로만 권한을 관리

## FR-CFG-002 어드민 UI 패턴
- **우선순위**: P1
- **내용**:
  - Top Bar 풀다운 메뉴 (최대 9개 1depth)
  - LRU 탭 (최대 9개, 초과 시 오래된 탭 자동 닫힘)
  - 홈 탭: 고정·닫기 불가
  - 상세·등록·수정: Layer Popup

## FR-CFG-003 공통코드 관리
- **우선순위**: P1
- **내용**:
  - 코드 그룹·코드값 관리
  - 복제 테이블 동기화 (CodeSyncBatch 1분)
  - 그룹코드 상태: 활성(ACTIVE)·비활성(INACTIVE), 상세코드 상태: 활성(ACTIVE)·중지(SUSPENDED)·폐기(DEPRECATED)
  - 상세코드는 정렬순서(sortOrder)로 노출 순서 관리

## FR-CFG-004 공지사항·약관·배너 관리
- **우선순위**: P1
- **내용**:
  - 공지: 대상별 노출 (고객·입점사·전체)
  - 약관: 버전 관리·갱신 시 재동의 처리
  - 배너: 위치·기간·노출 순서 관리
  - 공지: 팝업노출·중요공지 여부를 독립적으로 설정 가능, 노출기간 미설정 시 상시 노출
  - 약관: 유형(서비스·개인정보·마케팅)별 버전 단위 불변 레코드로 관리, 등록 후 수정 불가하며 개정 시 신규 버전 등록(동일 유형+버전 중복 등록 불가)
  - 배너: 노출위치(메인 상단·메인 중단·카테고리 상단)별 정렬순서로 노출 순서 관리, 노출기간 미설정 시 상시 노출

## FR-CFG-005 금지어 관리
- **우선순위**: P2
- **내용**:
  - 게시글·리뷰·문의 등 사용자 입력에서 자동 필터링할 금지어 등록·수정·삭제
  - 금지어 분류: 비속어·개인정보·스팸·기타

## FR-AUD-001 감사 로그
- **우선순위**: P1
- **내용**:
  - 전 도메인 주요 이벤트 기록
  - TraceID 기반 전 구간 추적
  - 보존: ERROR·WARN·INFO 1년, DEBUG 30일
  - 작업구분: 생성(CREATE)·수정(UPDATE)·삭제(DELETE)·상태변경(STATUS_CHANGE)
  - 실행주체유형: 시스템·회원·운영자·입점사
  - 변경 전/후 값을 함께 기록하며 조회 전용(수정·삭제 API 없음)

## FR-AUD-002 개인정보 접근 이력
- **우선순위**: P1
- **내용**:
  - AOP 기반 자동 기록 (adt_member_access_log)
  - 기록 대상: 회원·주문·클레임 조회 및 액션
  - 회원 목록: 필수 검색어 1개 이상 입력 후 조회
  - 접근구분: 목록조회(LIST)·상세조회(DETAIL), 목록조회에는 조회건수 함께 기록
  - 검색어·대상 회원명은 마스킹 처리 후 기록

## FR-AUD-003 배치 관리
- **우선순위**: P1
- **내용**:
  - 배치 목록·실행 이력·로그 조회
  - 즉시 실행·상태 변경 (활성·비활성)
  - 관련 화면: ADM-100-001
  - 배치 상태: 활성(ACTIVE)·비활성(INACTIVE), 실행 상태: 성공(SUCCESS)·실패(FAILED)·실행중(RUNNING)·SKIPPED
  - 트리거유형: 스케줄(SCHEDULED)·수동(MANUAL), 파라미터 값을 입력해 수동 재실행 가능
  - 배치잡별 파라미터 정의(키·설명) 등록·관리

## FR-AUD-004 DLQ·Outbox 관리
- **우선순위**: P1
- **내용**:
  - DLQ 목록·상세·재시도·무시 처리
  - Outbox 이벤트 모니터링
  - 관련 화면: ADM-100-002
  - Outbox 상태: 대기(PENDING)·처리중(PROCESSING)·처리완료(PROCESSED)·실패(FAILED)
  - DLQ 상태: 대기(PENDING)·해결(RESOLVED)·무시(IGNORED), 대기 상태에서만 재시도·무시 조치
  - 재시도는 원클릭 처리(재시도 횟수 증가, 처리메모 자동 기록), 무시는 처리메모 입력 필수

## FR-AUD-005 프로그램 관리·모니터링
- **우선순위**: P2
- **내용**:
  - 화면(PAGE)·API·배치(BATCH)·이벤트(EVENT) 단위로 프로그램을 등록·관리, 상태(운영·비활성·폐기예정) 관리
  - 프로그램별 30일 호출 수·평균 응답시간·오류율 모니터링, 오류율 1% 초과 시 경고 표시
  - 프로그램별 최근 호출 로그(호출자·역할·요청 URI·응답코드·응답시간) 조회
