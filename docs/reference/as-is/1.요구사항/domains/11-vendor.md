## FR-VND-001 입점 신청·심사
- **우선순위**: P1
- **내용**:
  - 신청: 사업자번호 인증 + 서류 첨부 + 담당자 정보
  - 심사 단계: 신청→서류검토→심사중→계약체결→승인
  - 심사 기간: 7영업일 이내
  - 반려 후 재신청: 30일 이후
  - 계약 결렬 후 재신청: 6개월 이후
  - 사업자유형: 법인사업자(CORPORATION)/개인사업자(INDIVIDUAL)/브랜드직영(BRAND_DIRECT) 중 택1
  - 상태 코드: 신청(APPLIED)→심사중(REVIEWING)→계약진행(CONTRACT)→승인(APPROVED), 심사중·계약진행 단계에서 언제든 반려(REJECTED) 가능하며 역방향 전이는 없음. 승인·반려는 최종 상태
  - 반려 시 반려사유 입력 필수, 반려횟수 누적 기록 및 이력에 추가

## FR-VND-002 입점사 온보딩
- **우선순위**: P1
- **내용**:
  - 최초 로그인 비밀번호 변경 강제
  - 2FA 설정 필수 (이메일·SMS·TOTP 중 택1)
  - 배송 설정: 배송사·배송비·무료배송 기준
  - 정산 계좌: 1원 송금 인증 (3회 실패 시 수동)
  - 비밀번호 변경: 현재 비밀번호·새 비밀번호·새 비밀번호 확인 3항목 입력, 새 비밀번호와 확인값 불일치 시 오류 처리
  - 배송 설정 항목: 택배사 선택, 무료배송 최소금액, 기본배송비, 반품배송비, 제주/도서산간 추가배송비
  - 정산계좌 등록 항목: 은행(국민·신한·우리·하나·농협·IBK기업은행 중 선택)·계좌번호·예금주, 목록·상세에서는 계좌번호 중간 자리를 마스킹 표시

## FR-VND-003 입점사 인증 정책
- **우선순위**: P1
- **내용**:
  - 2단계 인증 필수
  - 세션: 3시간 유지
  - 동시 세션: 최대 2개 (초과 시 오래된 세션 만료)
  - 만료 10분 전 팝업 안내
  - 관련 테이블: vnd_vendor_session
  - 계정 관리 화면에서 전체 세션 종료(로그아웃) 기능 제공, 확인 팝업 후 즉시 모든 세션 종료

## FR-VND-004 입점사 등급 관리
- **우선순위**: P2
- **내용**:
  - 4단계: New·Runner·Pacer·Elite
  - 등급별 수수료 감면율: 0%·0.5%·1.0%·1.5%
  - 최종 수수료율 = 카테고리 기본 수수료율 - 감면율
  - 관련 테이블: vnd_vendor_grade
  - 수수료율은 카테고리별로 관리되며 기본수수료율·등급감면율·최종수수료율·적용시작일을 함께 표시 (어드민 읽기전용)
  - 어드민 mock 데이터 기준 Elite 등급 감면율은 2.0%로 적용됨 (본 문서 표는 1.5%로 상이)

## FR-VND-005 배송사 관리
- **우선순위**: P1
- **내용**:
  - 플랫폼 제공 2개사 중 택1
  - 미선택 시 수동 운송장 등록
  - 배송 관련 분쟁 귀책 입점사 귀속
  - 어드민 배송사 관리 화면에서 배송사코드·배송사명·API 엔드포인트(선택)·배송조회 URL(선택, `{trackingNo}` 치환자 사용)·정렬순서·상태(활성/비활성)·API연동여부를 CRUD로 관리
  - 배송사코드는 등록 시에만 입력 가능하고 수정 시 변경 불가(비활성화 처리)
  - 배송사코드·배송사명·정렬순서 미입력 시 등록/수정 차단, 삭제 시 확인 팝업 후 즉시 제거

## FR-VND-006 패널티 관리
- **우선순위**: P2
- **내용**:
  - 운영 정책·계약 위반 시 패널티 부과
  - 해당 월 정산에서 차감
  - 초과 시 이월 처리
  - 관련 테이블: vnd_vendor_penalty
  - 부과 시 유형·금액·사유 입력 필수, 부과일은 등록일 기준 자동 기록
  - 패널티 유형 예시: 배송지연·오배송·CS응대지연·품질불량·계약위반
  - 패널티 3건 누적 시 입점사 상태가 자동으로 주의(WARNING)로 전환 (실 서비스 기준)

## FR-VND-007 입점사 상태 관리 (어드민)
- **우선순위**: P1
- **내용**:
  - 입점이 확정된 입점사를 사업자명·사업자번호·대표자명으로 검색·조회
  - 상태 4단계: 정상(ACTIVE)/주의(WARNING)/정지(SUSPENDED)/해지(TERMINATED) — 어드민은 상태만 변경 가능하며 사업자정보·연락처는 직접 수정 불가
  - 정산계좌 1건을 은행/계좌번호(마스킹)/예금주/대표계좌 여부/계좌인증일시로 표시, 미등록 시 안내 문구 표시
  - 목록 요약: 전체/정상/주의/정지/해지 건수
- **관련 화면**: ADM-060-002
