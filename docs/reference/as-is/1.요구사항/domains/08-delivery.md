## FR-DEL-001 출고 처리
- **우선순위**: P1
- **내용**:
  - 출고 의무: 결제완료 후 1영업일 이내
  - 초과 시: 입점사 즉시 알림 + 운영팀 모니터링 (ShippingDeadlineBatch 매일 09:00)
  - 반복 초과: 입점사 등급 산정 이행률 반영
  - 입점사 주문목록에서 결제완료(PAYMENT_COMPLETED) 상태 주문만 출고 처리 가능, 처리 시 준비중(PREPARING)으로 전환되고 처리이력에 기록
  - 입점사 주문목록에 개별 출고 처리 외 일괄 출고 처리 UI 제공

## FR-DEL-002 운송장 관리
- **우선순위**: P1
- **내용**:
  - 개별 입력 or 엑셀 일괄 업로드
  - 수정: IN_DELIVERY 이전만 가능
  - 배송사 선택: 플랫폼 제공 2개사 중 택1
  - 미선택 시: 수동 운송장 등록 (API 미연동)
  - 배송 관리 화면 구현상 선택 가능 배송사: CJ대한통운·한진택배·롯데택배·우체국택배·로젠택배 5개사
  - 운송장 입력: 택배사 선택 + 운송장번호 필수 입력(미입력 시 등록 차단), 등록 시 배송중(IN_DELIVERY)으로 전환되며 발송일시 자동 기록
  - 입점사 배송 관리 화면에 배송 엑셀 양식 다운로드·엑셀 업로드·일괄 배송정보 입력 UI 제공

## FR-DEL-003 배송 추적
- **우선순위**: P1
- **내용**:
  - 택배사 API 자동 추적
  - 고객 화면에서 실시간 추적
  - API 미연동 시: 수동 배송완료 처리
  - 관리자 주문상세 배송정보 탭: 배송사·운송장번호·출고일·배송상태(출고 대기/배송중/배송완료) 표시

## FR-DEL-004 배송완료 처리
- **우선순위**: P1
- **내용**:
  - 택배사 API 자동 수신 or 수동 처리
  - DELIVERED 전환 후 구매확정 안내 알림
  - 분실·파손 시 반품 프로세스 (입점사 귀책)

## FR-DEL-005 배송사 관리
- **우선순위**: P2
- **내용**:
  - 플랫폼이 연동하는 배송사(택배사) 기준정보 등록·수정·삭제
  - 배송사코드는 등록 시에만 입력 가능, 등록 후에는 수정 화면에서 변경 불가(비활성화)
  - 상태: 활성(ACTIVE)·비활성(INACTIVE), 비활성 배송사는 배송 등록 시 선택 목록에서 제외
  - API연동여부(apiConnected)는 상태와 별도인 체크박스 플래그로 관리
  - API 엔드포인트(운송장 조회 API 주소), 배송조회 URL(`{trackingNo}` 치환자 사용, 고객 노출용) 등록
  - 정렬순서로 배송사 선택 드롭다운 등 노출 순서 관리
