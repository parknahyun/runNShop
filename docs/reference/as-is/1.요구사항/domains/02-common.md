## FR-COM-001 다국어 지원
- **우선순위**: P3
- **내용**: 1단계 한국어 단일 언어. 2단계 다국어 확장 고려
- **제약**: 현재 한국어만 지원

## FR-COM-002 직매입 운영
- **우선순위**: P1
- **내용**:
  - 플랫폼 직매입 전용 입점사 계정 기초 데이터 생성
  - vendor_id=1 예약, is_platform_direct=TRUE
  - 정산 계산 제외
  - 상품 등록·배송·클레임 어드민 처리

## FR-COM-003 알림 발송
- **우선순위**: P1
- **내용**:
  - 채널 우선순위: 카카오 알림톡 → SMS → 이메일 (Fallback)
  - 야간 차단: 22시~08시 마케팅 알림
  - 거래 알림: 24시간 필수 발송
  - 재시도: 최대 3회 (즉시→30초→1분)
  - 취합 배치: 09·13·18시
  - 알림 템플릿(코드·채널·수신자유형·이벤트유형 단위) 등록·수정·삭제 관리, 템플릿코드는 등록 후 변경 불가
  - 거래 알림(필수 발송)과 마케팅성 알림(선택)을 템플릿 단위로 구분 관리
  - 입점사는 이벤트별(신규주문접수·클레임접수·정산확정·QnA등록·상품승인·상품반려)로 채널(이메일·SMS·앱푸시) 수신 여부를 설정 가능

## FR-COM-004 Outbox Pattern 이벤트 처리
- **우선순위**: P1
- **내용**:
  - 비즈니스 로직 + Outbox 저장 단일 트랜잭션
  - Consumer 상시 대기·PENDING 즉시 감지
  - 실패 시 DLQ 적재·운영팀 알림
  - 재기동 시 PENDING·PROCESSING 자동 재발행
  - Outbox 상태: 대기(PENDING)·처리중(PROCESSING)·처리완료(PROCESSED)·실패(FAILED)
  - DLQ 상태: 대기(PENDING)·해결(RESOLVED)·무시(IGNORED), 대기 상태에서만 재시도·무시 조치 가능(역방향 전이 없음)

## FR-COM-005 소프트 삭제
- **우선순위**: P1
- **내용**:
  - 전 테이블 물리적 DELETE 금지
  - is_deleted=TRUE 소프트 삭제만 허용
  - deleted_at·deleted_by 기록

## FR-COM-006 개인정보 보호
- **우선순위**: P1
- **내용**:
  - 휴대폰·SNS ID 암호화 저장
  - 회원 목록 조회 시 필수 검색어 입력 필수
  - 접근 이력 자동 기록 (AOP)
  - 접근 이력은 목록조회(LIST)·상세조회(DETAIL)로 구분 기록, 검색어·대상 회원명은 마스킹 처리 후 저장
