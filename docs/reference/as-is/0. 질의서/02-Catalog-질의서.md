# 질의서 — Catalog (상품, 발주사 대상)

> **목적**: 상품 도메인의 업무 범위·정책을 발주사로부터 확인한다.
> **사용 시점**: 착수(Kick-off) 미팅 또는 도메인정의서(DB)·상위유스케이스(DC) 작성 전
> **반영 대상**: `DB-도메인정의서`(Catalog 책임 정의), `D8-NFR`(SKU 규모 등 확장성 기준)

| # | 질문 | 답변 | 비고 |
|---|---|---|---|
| 1 | 취급 상품은 단일 상품형인가, 옵션(색상·사이즈 등)이 있는 조합형인가, 세트 상품도 있는가? | 단일 상품형(옵션 없음, 예: 보충제 단일 용량)과 옵션 조합형을 모두 지원한다. 옵션은 색상(1depth)·사이즈(2depth) 최대 2단계까지만 허용하며 SKU별 재고는 개별 관리하되 가격은 상품 단위로 통일한다(SKU별 개별가 미허용). 세트 상품(여러 상품을 묶어 판매) 취급 여부는 문서에 명시되어 있지 않다. | 정책서 3.4 SKU 정책, 세트 상품은 '-' |
| 2 | 초기 예상 상품 수(SKU)와 오픈 후 1년 내 예상 성장 규모는? | - | 문서에 구체적 SKU 수량·성장률 수치 없음. NFR-001에 상품 목록 응답 1초 이내·동시접속 1,000명 이상이라는 성능 목표만 정의되어 있음 |
| 3 | 카테고리 체계는 몇 단계(대/중/소분류)로 구성되며, 이미 정의된 분류 기준이 있는가? | 중·소분류 없이 대분류 단일 계층으로 운영하며, 상품은 대분류 1개에만 귀속(다중 카테고리 미허용)된다. 이미 5개 대분류가 정의되어 있다: 러닝화(수수료 8%)·러닝 의류(12%)·러닝 기어·액세서리(15%)·보충제·영양식품(10%)·웨어러블·디바이스(8%). 검색·필터 세분화는 카테고리 대신 태그·속성 기반으로 운영한다. | 정책서 3.2 카테고리 정책 |
| 4 | 브랜드 관리가 필요한가? (브랜드관·브랜드별 필터링 등) | 필요하다. 브랜드 등록·수정·삭제, 브랜드 인증 여부 관리 기능이 있으며, 상품-전시카테고리 자동 매핑 시 우선순위가 브랜드(2) > 카테고리(1) > 기본값(0) 순으로 브랜드가 최우선 적용된다. 검색 필터에도 브랜드(복수 선택)가 포함된다. | 요구사항 FR-CAT-001·007, 정책서 14.3 |
| 5 | 재고 관리는 실시간(즉시 반영)이어야 하는가, 배치(주기적 동기화)로도 괜찮은가? | 실시간이어야 한다. 상품(cat_sku)→재고(cat_sku_stock)→재고이력(cat_sku_stock_history)의 3테이블 구조로 즉시 반영되며, 가용 재고가 0이 되면 자동으로 품절(SOLD_OUT) 상태로 전환된다. 다만 검색 인덱스(ES) 동기화는 실시간 이벤트 수신과 매일 03:00 전체 배치 동기화를 병행한다. | 요구사항 FR-CAT-004, BC 4.Catalog |
| 6 | 입점사가 상품을 등록할 때 플랫폼 운영자의 승인(검수) 절차가 필요한가? | 필요하다. DRAFT(임시저장)→REVIEW_REQUESTED(심사요청)→UNDER_REVIEW(심사중)→ON_SALE(판매중)/REJECTED(반려)의 상태 전이를 거치며, 심사 기간은 7영업일 이내, 반려 3회 이상 시 MD 특별 검토로 에스컬레이션되고 재심사는 반려 후 30일 이후 가능하다. 이미지 검수는 Rekognition 비동기 분석을 병행한다. | 요구사항 FR-CAT-002~003, 정책서 3.1 |
| 7 | 상품 전시(디스플레이) 관리(기획전, 추천 상품, 배너)가 필요한가? | 필요하다. 홈·카테고리·기획전 유형의 전시 페이지 관리(즉시/예약 게시, DRAFT_EDIT을 통한 운영 중 수정, 편집 30분 잠금)와 기획전(Promotion 도메인) 관리를 지원한다. 1단계는 MD가 노출 순서를 수동 설정(md_override 최우선 적용)하며, 2단계에서 AI 스코어링 배치로 확장 가능한 플러그인 구조로 설계되어 있다. | 요구사항 FR-CAT-006, FR-PRO-005, 정책서 3.5 |
| 8 | 상품 정보(스펙, 상세페이지) 관리 방식은 어떻게 되는가? (직접 등록 vs 외부 연동) | 입점사/MD가 직접 등록하는 방식이다. 기본정보·가격·이미지·상세소개·SKU·완료의 6단계 등록 프로세스를 거치며 임시저장(DRAFT)을 지원한다. 이미지는 최대 10장·5MB, 금지어는 차단(BLOCK) 또는 마스킹(MASK) 처리된다. 외부 상품정보 연동(PIM 등)에 대한 언급은 없다. | 요구사항 FR-CAT-002 |
