# 질의서 — Search (검색, 발주사 대상)

> **목적**: 검색 도메인의 업무 범위·정책을 발주사로부터 확인한다.
> **사용 시점**: 착수(Kick-off) 미팅 또는 도메인정의서(DB) 작성 전
> **반영 대상**: `DB-도메인정의서`(Search 책임 정의), `D8-NFR`(검색 응답시간 기준)

| # | 질문 | 답변 | 비고 |
|---|---|---|---|
| 1 | 검색 기능에 자동완성·오타교정·유사어 검색이 필요한가? | 자동완성은 지원한다(브랜드명·상품명 기준). 오타교정·유사어 검색에 대한 요구사항은 문서에 명시되어 있지 않다. | 요구사항 FR-SCH-002, 정책서 14.4 — 오타교정·유사어는 '-' |
| 2 | 검색 결과 정렬 기준은 무엇인가? (정확도, 인기도, 최신순, 가격순) | 기본 정렬은 출시일(release_date) 내림차순(최신순)이며, 그 외 인기순(최근 30일 판매량 기준)·낮은 가격순·높은 가격순·리뷰 많은순·평점 높은순을 지원한다. 품절 상품도 검색 결과에서 동일 위치에 노출되며(하단 이동·숨김 없음) 검색 대상 필드는 상품명·브랜드·태그다. | 정책서 14.1~14.2 |
| 3 | 인기 검색어·추천 검색어 노출이 필요한가? | 필요하다. 인기 검색어는 1단계에서 MD가 수동으로 관리하며(실시간 자동 집계는 미적용, 추후 배치 자동화 가능한 구조로 설계), MD 추천 상품은 검색 결과 상단에 수동 고정할 수 있다. | 요구사항 FR-SCH-002, 정책서 14.4 |
| 4 | 검색 필터(가격대, 브랜드, 카테고리 등)의 범위는 어느 정도인가? | 카테고리(단일 선택)·브랜드(복수 선택)·가격대(직접입력/구간선택)·성별(복수 선택)·사이즈(카테고리별, 복수 선택)·평점(4점 이상/3점 이상)·배송(무료배송만 보기)의 7개 필터를 지원한다. | 정책서 14.3 |
| 5 | 검색 응답 속도에 대한 기대 수준이 있는가? | 있다. 검색 응답은 0.5초 이내를 목표로 하며, 이는 Elasticsearch 기반 인덱스와 Redis 캐시로 달성한다. 참고로 상품 목록 응답은 1초 이내, 동시 접속 1,000명 이상 처리를 함께 요구한다. | 요구사항 NFR-001 |
