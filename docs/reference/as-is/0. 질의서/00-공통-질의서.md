# 질의서 — 공통 (발주사 대상, 착수 전)

> **목적**: B2C 커머스 플랫폼 신규 구축 프로젝트 착수 전, 발주사에게 확인해야 할 프로젝트 전체(Project 범위) 질문을 정리한다.
> **대상 독자**: 발주사 사업 담당자·의사결정권자
> **사용 시점**: RFP 응답 준비 또는 착수(Kick-off) 미팅
> **반영 대상**: `D1-문제정의서`, `D2-목표KPI`, `D3-이해관계자맵`, `D4-범위(Scope)`, `D5-대안비교`, `D6-리스크가정`, `D7-제약사항`, `D8-NFR`, `DA-시스템구성도`, `DB-도메인정의서` 작성 시 입력자료로 활용
> **작성일**: 2026-08-26

| 9-3 | 개발/스테이징/운영 환경을 분리해야 하는 조직 정책이 있는가? | 있다. prototype(프로토타입)·local(로컬 개발·검증)·dev(개발서버)·staging(스테이징)·prod(운영)의 5개 프로파일로 환경을 분리하여 운영하는 정책이 정의되어 있다. | 정책서 1.0 |
