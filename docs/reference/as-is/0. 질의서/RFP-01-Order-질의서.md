# 질의서 — Order (주문, 발주사 대상)

> **목적**: 주문 도메인의 업무 범위·정책을 발주사로부터 확인한다.
> **사용 시점**: 착수(Kick-off) 미팅 또는 도메인정의서(DB)·상위유스케이스(DC) 작성 전
> **반영 대상**: `DB-도메인정의서`(Order 책임 정의), 이후 상위UC·EARS·상태머신(DG)의 입력자료

| # | 질문 | 답변 | 비고 |
|---|---|---|---|
| 1 | 주문 프로세스는 어떤 단계로 구성되는가? (장바구니 → 주문서 작성 → 결제 → 배송 → 구매확정) 각 단계에서 특별히 다르게 처리할 부분이 있는가? | 장바구니 → 주문서 작성 → 결제 → 배송(상품준비중→배송중→배송완료) → 구매확정의 표준 5단계로 구성된다. 주문서 단계에서 주문 전 휴대폰 OTP 본인인증이 필수(세션 기준 1회)이며, 할인은 행사가→수량할인→쿠폰→장바구니할인→포인트 순서로 적용된다. 결제 단계에서는 PG 인증 완료 후 재고를 선점(Redis TTL 30분)하며, 재고확보와 결제 승인은 동기/비동기(3분 타임아웃) 두 경로로 분기 처리된다. | 정책서 7.1~7.4, 요구사항 FR-ORD-001~004 |
| 2 | 하나의 주문에 여러 판매자(입점사) 상품이 섞일 수 있는가? 이 경우 판매자별로 주문을 분할해서 처리하는가? | 가능하다. 고객 결제 단위인 PlatformOrder(플랫폼주문)와 입점사 이행 단위인 Order(입점사주문)의 2계층 구조로 설계되어, 결제는 통합 처리하되 이행(출고·배송·클레임)은 입점사별로 자동 분할되어 처리된다. | 요구사항 FR-ORD-004, BC 3.Order |
| 3 | 주문 취소는 어느 단계까지 허용하는가? (결제 전/후, 배송 시작 전/후) | 출고 전(PREPARING 이전)까지는 고객이 자유롭게 취소 신청 가능하며 전액 즉시 환불·재고 자동복구 처리된다. 출고 이후~배송 중에는 반품 절차로 전환되고, 배송완료 후에도 반품 절차가 적용된다(10일 이내). 출고 이후 단계의 예외 취소는 CS 상담원과 입점사 협의를 거쳐 처리한다. | 정책서 8.1·8.3, BC 3.Order 취소유형 |
| 4 | 반품·교환 정책은 어떻게 되는가? (수거 방식, 처리 기한, 판매자 vs 플랫폼 책임 구분) | 반품·교환 모두 배송완료일 기준 10일 이내 신청 가능하며, 신청→수거→상품검수→환불/교환출고 순으로 처리하고 검수완료 후 영업일 3일 이내 환불한다. 교환은 동일 상품 내 옵션(색상·사이즈) 변경만 허용하며 재고 없을 시 반품으로 전환된다. 귀책은 1차로 플랫폼 CS가 고객 첨부 사진 기준 판단하고(상품불량·오배송·파손=입점사 귀책, 단순변심·사이즈오선택=고객 귀책), 입점사 이의제기가 가능하며 최종 결정은 플랫폼이 내린다. 배송비는 귀책 주체가 부담한다. | 정책서 8.2~8.4, FR-CLM-002~004 |
| 5 | 부분 취소(주문 항목 중 일부만 취소)와 부분 배송(항목별로 다른 시점에 배송)을 지원해야 하는가? | 부분 취소(주문 항목 단위 취소)와 다중 상품 선택/부분 수량 반품은 지원한다. 다만 항목별로 시점을 달리하는 부분 출고(부분 배송)는 정책 범위에서 명시적으로 제외되어 있으며 2단계에서 별도 검토 예정인 미확정 항목이다. | 요구사항 FR-CLM-002, 요구사항 16.미확정항목 #3, 정책서 13.0 |
| 6 | 재고 부족·품절 시 주문 처리는 어떻게 되는가? (자동 취소, 대체 상품 안내 등) | 결제 요청 시점(PG 결제 요청 시)에 재고를 확정 선점하며, 선점 실패 시 품절 안내 후 장바구니로 복귀시킨다. 비동기 처리 중 PROCESSING 상태가 3분을 초과하면 자동으로 CANCELLED 처리되며 재고·포인트·쿠폰이 보상(복원)된다. 대체 상품 자동 안내 기능은 문서에 명시되어 있지 않다. | 요구사항 FR-PAY-002~003, FR-ORD-004 |
| 7 | 구매확정은 자동(예: 배송완료 후 7일)인가, 고객이 직접 확정해야 하는가? | 둘 다 지원한다. 고객이 직접 확정 버튼을 클릭하는 수동 확정이 가능하며, 별도 확정이 없으면 배송완료 후 7일 경과 시 배치(AutoConfirmBatch, 매일 02:00)가 자동 확정 처리한다. 취소·반품·교환 등 클레임이 진행 중인 주문은 확정이 보류된다. | 요구사항 FR-ORD-007, 정책서 7.5 |
| 8 | 배송비 정책(무료배송 기준, 판매자별 배송비 차등)이 있는가? | 있다. 배송비는 상품 단위가 아닌 입점사 단위로 부과하며 동일 입점사 상품은 묶음배송을 적용한다. 무료배송 기준은 입점사가 자율 설정하되 플랫폼은 5만원 이상을 권고 기준으로 제시한다. 별도로 고객 회원등급별 무료배송 기준 차등도 있다(New 5만원↑/Runner 3만원↑/Pacer 2만원↑/Elite 무조건 무료). | 정책서 3.6, 요구사항 FR-MBR-004 |
| 9 | 주문 이력·상태 변경 알림이 필요한 대상은 누구인가? (고객, 판매자, 운영자) | 세 대상 모두 필요하다. 고객에게는 주문완료·상품준비중·배송시작·배송완료·구매확정 등 상태 변경 시마다 필수 거래 알림이 즉시 발송된다. 입점사에는 신규 주문 접수 시 즉시, 클레임 접수는 09/13/18시 취합 배치로 발송된다. 운영자(운영팀)에는 결제 승인 오류·재고/포인트/쿠폰 복원 실패·출고기한 초과 등에 대한 모니터링 알림이 발송된다. | 정책서 11.4, 요구사항 FR-COM-003 |
