# 질의서 — Member (회원, 발주사 대상)

> **목적**: 회원 도메인의 업무 범위·정책을 발주사로부터 확인한다.
> **사용 시점**: 착수(Kick-off) 미팅 또는 도메인정의서(DB)·상위유스케이스(DC) 작성 전
> **반영 대상**: `DB-도메인정의서`(Member 책임 정의), `D7-제약사항`(개인정보 관련 법적 제약)

| # | 질문 | 답변 | 비고 |
|---|---|---|---|
| 1 | 회원가입 방식은 무엇인가? (이메일/휴대폰 인증, 소셜 로그인 — 어느 채널) | 이메일 가입과 소셜 로그인(1단계: 네이버·Apple)을 지원한다. 본인인증(휴대폰)은 가입 시점에는 선택이지만 주문 시에는 필수이며, 동일 휴대폰 번호로는 중복 가입이 불가하다. 이용약관·개인정보 수집은 필수 동의, 마케팅 수신은 선택 동의이며 가입 시 웰컴 쿠폰이 자동 발급된다. 2단계에 카카오·구글 채널이 추가될 예정이다. | 요구사항 FR-MBR-001·003, 정책서 4.1~4.2 |
| 2 | 비회원 주문(게스트 주문)을 허용하는가? | 문서에 게스트(비회원) 주문을 명시적으로 허용/불허한다는 규정은 없다. 다만 비로그인 상태의 장바구니는 지원(로그인 시 자동 머지, 비회원 장바구니 보관 7일)하며, 주문서 진입 전 별도 회원가입 강제 여부는 명시되지 않았다. 일반적인 B2C 커머스 관행상 게스트 주문을 지원하는 사례가 많으므로 착수 단계에서 발주사 확인이 필요하다. | 정책서 7.4.1 (REQ-ORD-102), 명확한 결정 필요 — 착수 단계 확인 권고 |
| 3 | 회원 등급·포인트·마일리지 제도를 운영할 계획이 있는가? 있다면 산정 기준은? | 운영한다. 4단계 등급(New→Runner→Pacer→Elite)을 두며, 산정 기준은 최근 3개월 구매금액(누적 100/200/300만원 이상)과 활동지수(10/20/30점 이상, 리뷰작성+2·러닝기록공유+1·크루활동+1·챌린지완료+3·QnA채택+2)의 조합이다. 매월 1일 자동 갱신, 하향 시 1개월 유예를 적용한다. 포인트는 등급별 적립률(0.5~2.0%, 건당 최대 1,000원)로 구매확정 후 적립되며 유효기간은 3년(FIFO 소멸)이다. 별도의 마일리지 제도는 없다(포인트 제도로 통합 운영). | 요구사항 FR-MBR-004~005, 정책서 4.3~4.4 |
| 4 | 배송지는 몇 개까지 등록 가능해야 하는가? (기본 배송지 지정 등) | 최대 5개까지 등록 가능하며, 기본 배송지 지정 기능이 있고 주문서 진입 시 기본 배송지가 자동 선택된다. | 요구사항 FR-MBR-007 |
| 5 | 탈퇴 시 개인정보 처리 방침은? (즉시 삭제 vs 법정 보관기간 후 파기) | 탈퇴는 즉시 처리하되, 거래(주문·결제) 데이터는 관련 법령(전자상거래법 등)에 따른 보존 의무 기간 동안 보존 후 파기한다. 주문·거래 이력은 5년(전자상거래법 기준) 보존 규정이 별도로 있다. 삭제는 물리적 DELETE가 아닌 소프트 삭제(is_deleted=TRUE) 방식이 전 테이블 공통 원칙이다. | 정책서 4.1·19.1, 요구사항 NFR-006·FR-COM-005 |
| 6 | 휴면 계정 정책(장기 미접속 시 처리)이 필요한가? | 문서에 휴면 계정 전환 기준(예: 1년 미접속)이나 처리 절차가 별도로 정의되어 있지 않다. | - (정보통신망법상 일반적으로 1년 미접속 시 휴면 전환하는 관행이 있으나, 본 프로젝트 문서에는 미기재이므로 착수 단계 확인 필요) |
| 7 | 회원 정보 변경 시 이력 관리가 필요한가? (감사 목적) | 필요하다. 회원(개인정보) 조회·변경에 대한 접근 이력은 AOP 기반으로 자동 기록(adt_member_access_log)되며, 회원 목록 조회 시에는 필수 검색어 입력이 강제된다. 이는 감사 로그 정책(1년 보존)의 일부로 관리된다. | 요구사항 FR-AUD-002, FR-COM-006 |
