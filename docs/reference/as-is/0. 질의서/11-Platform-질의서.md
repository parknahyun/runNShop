# 질의서 — Platform (플랫폼/인증/보안, 발주사 대상)

> **목적**: 플랫폼(인증·공통설정·보안) 도메인의 업무 범위·정책을 발주사로부터 확인한다.
> **사용 시점**: 착수(Kick-off) 미팅 또는 도메인정의서(DB)·제약사항(D7) 작성 전
> **반영 대상**: `DB-도메인정의서`(Platform 책임 정의), `D7-제약사항`(보안·인증 관련), `D8-NFR`(보안 기준)

| # | 질문 | 답변 | 비고 |
|---|---|---|---|
| 1 | 관리자(어드민) 권한 체계가 필요한가? (역할별 권한 분리, 예: 전체관리자/CS담당/정산담당) | 필요하며 이미 정의되어 있다. 슈퍼관리자·MD·CS·정산담당·입점관리의 5개 롤로 구분되며, 운영자 신청 후 슈퍼관리자 승인을 거쳐 계정이 발급되고 롤별로 접근 가능한 메뉴·기능이 제한된다(예: MD는 Catalog·Promotion·Search, CS는 Order·Claim·Member, 정산담당은 Settlement·Vendor). | 요구사항 FR-CFG-001, BC 13.Config |
| 2 | 기존 사내 시스템과 SSO(통합 로그인) 연동이 필요한가? | - | 문서에 사내 기존 시스템 또는 SSO 연동 관련 요구사항이 명시되어 있지 않음 |
| 3 | 회원가입 시 소셜 로그인(카카오·네이버·구글 등)을 지원해야 하는가? | 지원한다. 1단계 런칭 시점에는 네이버·Apple을 지원하며, 카카오·구글은 2단계 확장 대상으로 미확정 항목에 포함되어 있다. | 요구사항 FR-MBR-003, 16.미확정항목 #5 |
| 4 | 2단계 인증(2FA)이 필요한 대상이 있는가? (특히 입점사·관리자 계정) | 입점사 BO 계정에는 2FA가 필수다(이메일·SMS·TOTP 중 택1, 세션 3시간, 동시 세션 최대 2개). 관리자(어드민) 계정은 2FA 대신 허용 IP 기반 접근 제한(VPN/IP 화이트리스트)으로 통제하며, 고객 계정은 2FA를 적용하지 않는다. | 요구사항 FR-VND-002~003, 정책서 15.8~15.9 |
| 5 | 보안 심사(ISMS-P 등)를 받을 계획이 있는가? | - | 문서에 ISMS-P 등 외부 보안 인증/심사 계획이 명시되어 있지 않음 |
| 6 | 이용약관·개인정보처리방침 등 정책 문서를 관리(버전관리, 동의 이력)해야 하는가? | 필요하며 이미 정의되어 있다. 약관은 버전 관리되고 갱신 시 재동의 팝업이 강제 노출되며(필수 약관 미동의 시 서비스 이용 불가), 동의 이력은 mbr_terms_agreement 테이블에 저장된다. 공지사항·배너도 함께 Config 도메인에서 관리한다. | 요구사항 FR-MBR-008, FR-CFG-004 |
