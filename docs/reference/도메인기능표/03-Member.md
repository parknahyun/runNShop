# Member 도메인 기능표

> 핵심 책임: 고객 계정·등급·포인트·쿠폰을 관리한다.

> **진행 상태 전제(2026-07-28)**: 고객화면(mobile)·배치·컨슈머(비동기 처리)는 아직 미착수,
> admin·partner도 초안 작업 상태 — 아래 N/A·스텁·dead code 발견은 결함이 아니라 진행 전 상태.
> 상세는 `README.md`의 "현재 진행 상태 안내" 절 참고.

**API 호출 개수 카운트 기준**: 화면/탭 로드 1개 = API 1개, 실제 제출 버튼 1개 = API 1개(취소·
편집토글처럼 API를 호출하지 않는 UI 전용 버튼은 제외). 화면 자체가 없는 코드/구성 자산은 "N/A"로
표기. 한 화면/탭을 두 소분류가 함께 쓰는 경우(예: 회원 상태 변경은 기본정보 탭을, 포인트 적립
등은 포인트이력 탭을 공유) 화면 로드는 먼저 나오는 행에서 1회만 산정하고, 공유하는 행은
"0(◯◯ 탭 공유)"로 표기해 중복 집계를 피한다.
