## 1. 배경

Promotion 상위 유스케이스(DC) 작성 중, 도메인정의서(DB)의 Promotion "핵심 책임"에 포함된 **"운영·CS·마케팅 시스템"** 항목이 상위 유스케이스로 분해되지 않는 문제가 확인되었다.

이 항목의 출처를 추적한 결과, 도메인 고유 책임이 아니라 **범위(Scope) 재분류 과정에서 편입된 항목**임이 확인되었다.

### 편입 경위

```
2026-07-30  D4-범위(Scope)
  → Out-of-Scope였던 "운영·CS·마케팅 시스템"을 In-Scope로 편입
  → "신규 도메인을 만들지 않고 도메인 수 12개 유지"를 위해 Promotion에 편입 (사업 오너 확인)
                    ↓
  DB-도메인정의서 Promotion "책임"에 "운영·CS·마케팅 시스템" 추가
```

> 범위 문서 원문: "인프라 보안·운영·CS·마케팅 시스템도 **신규 도메인이 아니라** 각각 Config·Promotion에 편입 확정 — **도메인 수 12개 유지**"

## 2. 문제점

| # | 문제 | 상세 |
|---|---|---|
| 1 | 횡단(cross-cutting) 개념을 단일 도메인에 편입 | "운영·CS·마케팅"은 특정 도메인 고유 책임이 아니라 시스템 전반에 걸친 개념. Promotion 단독 책임으로 보기 부적절 |
| 2 | 편입 사유가 행정적 | "도메인 수 12개 유지" 목적의 편입이며, 도메인 책임 관점의 순수 분류가 아님 |
| 3 | 실제 소속 불일치 | CS: 주문/클레임 CS→Order, 회원 CS→Member 등 여러 도메인에 걸침. 마케팅: 쿠폰·할인·이벤트 외 영역도 존재. 운영: 전 도메인 공통 |
| 4 | 상위 유스케이스 분해 곤란 | "운영·CS·마케팅"을 독립 업무그룹으로 세우면 구체 유스케이스가 도출되지 않음 (도메인정의서 문구만 있고 실체 부족) |

### Promotion에 실제 귀속되는 부분만 추리면

| 편입 항목 | Promotion 실제 귀속 여부 |
|---|---|
| CS | 쿠폰 임의 발행·회수(CS)만 Promotion 소관. 그 외 CS는 타 도메인 |
| 마케팅 | 쿠폰·할인 타겟팅은 Promotion 소관. "마케팅 시스템" 전반은 더 넓은 개념 |
| 운영 | 프로모션 현황·성과 조회 정도. "운영" 일반은 전 도메인 공통 |

## 3. 현재 임시 처리 (상위 유스케이스 DC)

편입 항목을 독립 업무그룹으로 두지 않고, 실제 기능만 각 업무그룹에 흡수 처리함 (B안):

| 편입 기능 | → 처리 |
|---|---|
| 쿠폰 임의 발행 (CS) | 쿠폰관리 "쿠폰 발급(일괄·임의)"으로 흡수 |
| 쿠폰 타겟팅 (마케팅) | 쿠폰관리 하위 기능으로 흡수 |
| 프로모션 운영 현황·성과 조회 | 부록 A(구체 근거 확정 후 편입)로 분리 |

## 4. 결정 요청 사항

| # | 질문 | 결정 필요 |
|---|---|---|
| 1 | "운영·CS·마케팅 시스템"을 Promotion 책임으로 유지할지, 문구를 구체화(예: "프로모션 운영·CS(쿠폰 발행)")할지 | 사업 오너 / 도메인정의서 결정권자 |
| 2 | 도메인정의서 Promotion 책임 문구를 실제 귀속 범위로 정정할지 | 도메인정의서 결정권자 |
| 3 | 상위 유스케이스의 B안(기능 흡수) 처리 방식 승인 여부 | 도메인정의서 결정권자 |

### 제안 (택1)

| 방안 | 내용 |
|---|---|
| A. 현행 유지 | 도메인정의서 문구 유지 + 상위UC는 B안(기능 흡수)으로 실무 정리 (현재 상태) |
| B. 문구 구체화 | 도메인정의서 책임을 "운영·CS·마케팅 시스템" → "프로모션 운영·CS(쿠폰 임의발행)·마케팅 타겟팅"으로 구체화하여 Promotion 실제 귀속 범위만 명시 |
| C. 편입 철회 | "운영·CS·마케팅"을 Promotion 책임에서 제외하고, 필요 시 별도 횡단 관심사로 재정의 |

> **작성자 의견**: B(문구 구체화)를 권장. 편입 결정 자체는 존중하되, 도메인정의서에 "Promotion이 실제로 무엇을 하는가"를 정확히 반영하여 상위 유스케이스 도출이 가능하도록 한다.
