# C2 용어컨벤션 프로모션 용어 등록 제안

> **작성일**: 2026-07-08
> **작성자**: 김승태 (Promotion 도메인)
> **협의 대상**: 용어컨벤션(C2) 결정권자 / 프로젝트 표준 관리자
> **상태**: 협의 대기
> **대상 문서**: `docs/자산화-컨벤션/C2-용어컨벤션.md` §2.4 복합 용어

---

## 1. 배경

Promotion EARS(DD) 작성 중 행사 유형을 "기간 한정 행사 / 수량 한정(선착순) 행사" 2종으로 구분하면서, "선착순 행사" 등 프로모션 용어가 용어컨벤션(C2)에 미등록 상태임이 확인되었다.

현재 C2 §2.4 복합 용어에는 주문·클레임 관련 용어만 있고 **프로모션(쿠폰·할인·행사) 용어가 하나도 없다**.

---

## 2. 등록 제안 용어

### C2 §2.4 복합 용어에 추가 제안

| 표준 용어 | 정의 | 금지/비권장 용어 |
|---|---|---|
| 행사가(즉시할인) | 대상 상품 판매가를 행사 기간 동안 직접 인하하는 할인 | 특가, 세일가 |
| 기간 한정 행사 | 행사 종료일 도래로만 종료되는 행사 (기본). 상품 재고 소진 시 품절일 뿐 행사는 유지 | — |
| 수량 한정 행사 (선착순) | 선착순 행사 수량 한도 내 행사가 판매, 수량 소진 시 행사 종료·원가 복원 (옵션) | 한정수량 특가 |
| 선착순 행사 수량 | 수량 한정 행사에서 행사가로 판매할 물량 한도 (Promotion이 Redis 관리). 상품 재고와 별개 | 행사재고, 특가수량 |
| 수량구간 할인 | 구매 수량 구간별 할인율 차등 (예: 3개 이상 10%) | 대량할인, 묶음할인 |
| 장바구니 할인 | 주문 총액 조건 충족 시 적용되는 플랫폼 단위 할인 | 주문할인, 총액할인 |
| 쿠폰 | 회원에게 발급되어 주문 시 사용하는 할인 수단 | 할인권, 쿠폰권 |
| 기획전 | 특정 주제로 상품·프로모션을 묶어 노출하는 캠페인 | 특별전, 이벤트페이지 |

### 핵심 구분 (혼동 방지)

| 개념 | 소유 도메인 | 관리 방식 |
|---|---|---|
| **선착순 행사 수량** | Promotion | Redis 카운터 (행사 종료 트리거) |
| **상품 재고 (SKU stock)** | Catalog | DB 재고 (소진 시 품절 SOLD_OUT) |

> 두 "수량"이 이름으로 구분되지 않으면 "행사 수량 소진 = 품절"로 오해되어, 기간 한정 행사에서 재고 소진 시 행사가 잘못 종료될 수 있다.

## 3. 배경 근거

| 항목 | 출처 |
|---|---|
| 행사 유형 2종 구분 | `DD-EARS기능요구(Promotion).md` REQ-PRM-010~012 + 용어 정의 섹션 |
| 선착순 행사 수량 관리 | 정책서 §9.1-1 "행사가 수량 관리" (Redis DECR/INCR) |
| 상품 재고 관리 | Catalog REQ-CAT (SKU stock, SOLD_OUT) |

---

## 4. 임시 처리 상태

- Promotion EARS(DD) 문서 내에 "용어 정의(Promotion)" 섹션을 추가하여 문서 자체 정합성은 확보함.
- 본 제안 승인 시 C2 §2.4에 정식 등록하고, EARS의 "C2 등록 대상" 표기를 "등록 완료"로 갱신 예정.
