## 상세디스크립션

### R1 — Header

| 항목 | 내용 |
|---|---|
| 역할 | 화면 타이틀과 전체 담은 수량을 보여준다 |
| 데이터 소스 | `GET /api/v1/cart` → `total_count` |
| 컴포넌트 스타일 | C7 mobile — `L-FORM` 레이아웃의 BackHeader가 아닌 `L-MAIN`형 sticky 헤더(`sticky top-0 z-20`) |
| 진입/노출 조건 | 항상 노출 |

### R2 — VendorGroup

| 항목 | 내용 |
|---|---|
| 역할 | 입점사 단위로 상품을 묶어 배송비 기준을 함께 안내 |
| 데이터 소스 | `GET /api/v1/cart` → `vendors[]` |
| 컴포넌트 스타일 | C7 mobile `VendorGroup` — `bg-white rounded-lg border border-gray-200 p-3` |
| 진입/노출 조건 | `vendors[]` 1건 이상일 때 |

| 코드 | 속성명 | 데이터 소스 | 표시 규칙 | 제약사항 |
|---|---|---|---|---|
| R2-P1 | 입점사명 | `vendors[].vendor_name` | — | — |
| R2-P2 | 배송비 안내 | `vendors[].shipping_fee_text` | "배송비 무료배송" 등 | — |

### R3 — CartItem (R2 하위, 상품별 반복)

| 항목 | 내용 |
|---|---|
| 역할 | 상품 1건의 이미지·옵션·가격·수량·삭제를 표시/조작 |
| 데이터 소스 | `GET /api/v1/cart` → `vendors[].items[]` |
| 컴포넌트 스타일 | C7 mobile `CartItem` 카드 — 이미지 `w-16 h-16` + 텍스트 |
| 진입/노출 조건 | 상품별 반복 |

| 코드 | 속성명 | 데이터 소스 | 표시 규칙 | 제약사항 |
|---|---|---|---|---|
| R3-P1 | 상품명 | `items[].name` | C8 §4.1 Label 규칙(명사형) | — |
| R3-P2 | 옵션(색상/사이즈) | `items[].option_text` | "블랙 / 265" 형식 | — |
| R3-P3 | 정상가 | `items[].original_price` | C8 §8.3 할인 전 — 취소선 | 할인 없으면 미노출 |
| R3-P4 | 판매가 | `items[].price` | C8 §8.3 금액 표기(`{숫자}원`, 천단위 콤마) | — |

| 코드 | 기능명 | 트리거 | 동작 | 검증/제약사항 |
|---|---|---|---|---|
| R3-F1 | 수량 변경 | `+`/`−` 버튼 클릭 | `PATCH /api/v1/cart/items/{cart_item_id}/quantity` | 최소 1개, 재고 초과 시 R3-S1로 전환 |
| R3-F2 | 옵션 변경 | [옵션변경] 클릭 | R8(옵션변경팝업) 오픈 | — |
| R3-F3 | 삭제 | [삭제] 클릭 | `DELETE /api/v1/cart/items/{cart_item_id}` | 확인 다이얼로그 없이 즉시 삭제(되돌리기 토스트 등은 미정의) |

| 코드 | 상태명 | 발생 조건 | 화면 표현 | 문구 |
|---|---|---|---|---|
| R3-S1 | 품절 | `status !== 'ON_SALE'`(실재고 − 장바구니 선점수량 ≤ 0) | C7 mobile 품절 배지(`absolute inset-0 bg-gray-500/70` + 중앙 텍스트) 오버레이, 수량 버튼 비활성화 | C8 §4.2 Badge 규칙 — 개별 아이템 오버레이이므로 C8 §7 Empty/Error 계열과는 다른 표현 |

> R3-S1은 다중 영향(배지 표시 + 수량버튼 비활성화 + 주문 시 제외) 기준 ①에 해당해 별도 상태로 승격했다.
