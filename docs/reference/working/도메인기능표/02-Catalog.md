# Catalog 도메인 기능표

> 핵심 책임: 상품 정보의 전체 생명주기와 가격·재고를 관리한다.

> **진행 상태 전제(2026-07-28)**: 고객화면(mobile)·배치·컨슈머(비동기 처리)는 아직 미착수,
> admin·partner도 초안 작업 상태 — 아래 N/A·스텁·dead code 발견은 결함이 아니라 진행 전 상태.
> 상세는 `README.md`의 "현재 진행 상태 안내" 절 참고.

**API 호출 개수 카운트 기준** (11-Config.md와 동일 기준 적용): 화면/탭 로드 1개 = API 1개, 실제 제출
버튼 1개 = API 1개(취소·편집토글처럼 API를 호출하지 않는 UI 전용 버튼은 제외). 아직 실제 백엔드 연동
전이라 미연결인 것도 많지만, 이 기준으로 API 표면 규모를 추정한다. 화면 자체가 없거나 코드가 전혀
존재하지 않는 항목은 "N/A"로 표기(추정치를 억지로 만들지 않음).
