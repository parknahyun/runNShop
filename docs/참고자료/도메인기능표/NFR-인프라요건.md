# NFR (비기능요건) — 인프라·보안 요건 목록

> 도메인 기능표에 `[NFR]` 태그로 남겨둔 항목의 교차 참조 문서
> 기능 수 카운트에서는 제외 가능하며, 별도 워크스트림으로 공수 산정 권장
> 작성일: 2026-07-29
> 2026-07-30 갱신: 舊 13-Security가 11-Config로 편입되어 "소속 도메인" 열을 정정함

---

## 개요

기능표 359건 중 **5건**이 비기능요건(NFR) 성격으로, 비즈니스 기능이 아닌 인프라·보안·관측성 설정 작업입니다.
각 도메인 기능표에 그대로 남겨두되, 비고에 `[NFR]` 태그를 붙여 구분합니다.

---

## NFR 목록

| # | 소분류(기능) | 소속 도메인 | 대분류 | 유형 | 설명 |
|---|-------------|-----------|--------|------|------|
| 1 | FDS 연동 | 04-Payment | 이상거래방지 | 보안 인프라 | PG사 FDS API 연동, 이상 결제 자동 차단 |
| 2 | SSO 연동(운영자) | 11-Config | 접근통제·모니터링 | 인증 인프라 | 사내 IdP 연동, 운영자 SSO 로그인 |
| 3 | 비정상 접근 탐지·Bot 차단·WAF 연동(운영자) | 11-Config | 접근통제·모니터링 | 네트워크 방어 | SQL Injection·XSS·CSRF·Bot 공격 방어 |
| 4 | 모니터링·알림 | 12-Audit | 장애처리연동 | 관측성 | ERROR 임계치(10분 내 2회) 시 관리자 알림 트리거 |
| 5 | API 연동 인증(입점사) | 11-Config | API보안 | API 게이트웨이 | OAuth2/API Key 발급·인증 메커니즘 |

## 구현 관점 분류

| 유형 | 항목 | 구현 방식 | 우선순위 |
|------|------|----------|---------|
| 보안 인프라 | FDS 연동, WAF·Bot 차단 | PG사/CDN/WAF 벤더 연동 설정 | 런칭 전 필수 |
| 인증 인프라 | SSO 연동, API 연동 인증 | IdP 설정 + API Gateway 구성 | 운영 시작 전 |
| 관측성 | 모니터링·알림 | 알림 규칙 설정 (CloudWatch/Datadog 등) | 운영 시작 전 |

## 프로토타입 단계 처리

코딩 표준에 따라 프로토타입에서는:
- HTTPS, Nginx, JWT 검증: **미적용**
- 인프라 보안: **미적용**
- 위 5건은 전부 **프로토타입 범위 밖** — 정책상 명시적으로 제외됨

본 프로덕션 구축 시 별도 인프라 워크스트림으로 편성합니다.
