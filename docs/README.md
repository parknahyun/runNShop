# docs

앞으로 실제 작업이 이뤄지는 폴더. 역할이 다른 두 하위 폴더로 구성된다(2026-07-28 확정).

## 폴더 구조

- `onboarding/` — **신규 참여자 가이드**. Kiro 설치 이후 git 연결·로컬 실행·방법론에 따른 산출물
  작성·AI 코딩까지 실습으로 따라가는 문서.
- `methodology/` — **지침서**. AI활용 개발방법론·산출물 표준양식·산출물 작성가이드·프롬프트
  라이브러리·산출물-샘플(공정별 실증 샘플) 등, "어떻게 작성하는가"를 정의하는 방법론 횡단 자산.
  필요할 때 계속 보완해나간다. (`docs_archive/docs_method/`에서 이동)
- `deliverables/` — **산출물**. 방법론을 실제로 적용해 만드는 실제 작업 결과물(단계별 실 프로젝트
  산출물, `conventions/` 포함).
- `reference/` — **참조 자료**. `reference/as-is/`(방법론 적용 이전 원본 문서, 이관 전 원본
  참조 자산, 수정하지 않음)와 `reference/working/`(도메인기능표·화면정의서 샘플·가이드 등 진행 중
  계속 갱신되는 보조 참고자료)로 구분한다.
- `weekly-report/` — 진행 중인 주간보고. (`docs_archive/docs/y.주간보고/`에서 이동, 2026-07-31)

## 관련 폴더 (프로젝트 루트, docs와 대등)

- `docs_archive/` — **참조문서**. 원본 9대공정 백업(`docs/`)과 자산화 작업 중 아직 정리 전인
  옛 산출물(`docs_ai/`의 02~09)을 그대로 보존. 평소엔 열람만, 수정하지 않는다.
- `docs_backup/` — 압축 스냅샷 백업(`.tar.gz`). 사고 대비용, 평소엔 열지 않는다.
