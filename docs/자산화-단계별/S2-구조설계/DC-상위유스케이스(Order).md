## ④ 권한 범위

| 규칙 | 도출 근거 |
|---|---|
| 고객은 본인 주문만 조회·결제·취소 가능 (`order.memberId == 로그인 사용자`) | 개인정보 보호 원칙 |
| 판매자는 자기 매장으로 걸린 주문만 출고·클레임 처리 가능 | 도메인정의서 §4: Vendor→Order 관계 |
| 고객의 단순 취소는 PAYMENT_COMPLETED 상태에서만 허용, PREPARING 상태는 CS 예외 취소만 가능, IN_DELIVERY 이후는 취소 불가(반품 신청으로 전환) | 상태머신(DG) 금지 전이 — PREPARING→CANCELLED(고객 불가)/IN_DELIVERY→CANCELLED(전체 불가) |
| 반품·교환 신청은 배송완료 후 10일 이내로 제한 | 반품 기한 규정 |
| 교환(EXCHANGE)은 맞교환 원칙 — 귀책판정 완료(PICKUP 진입) 시 판매자가 교환상품을 즉시 선출고, 원상품 수취는 그 이후 | 상태머신(DG) v4, REQ-ORD-056 |
| 배송지 변경은 고객 채널에서만 가능(CS 전용 API 미설계) | ⚠️ 정책 결정 필요 — CS가 대신 변경해야 하는 경우 처리 방법 미정 |
| ~~재고 수동 복구·귀책 이의제기 반품 건당 1회 제한~~ | ⚠️ 정책 결정 필요 — "귀책 이의제기"에 대응하는 요구사항·화면·API가 하위 산출물에 전혀 없음. 구현 대상인지, 폐기된 초안인지 확인 필요 |
