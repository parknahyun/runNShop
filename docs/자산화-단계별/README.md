# 자산화 — 단계별

> 산출물 흐름 문서의 7단계 체계에 따라, 실제 프로젝트 산출물을 **작성순서** 기준으로 배치한다.
> 방법론 샘플(`docs/방법론/산출물샘플-단계별/`)과 동일한 구조이며, 여기에는 **실제 프로젝트 산출물**이 들어간다.

---

## 폴더 구조

```
자산화-단계별/
├── S0-착수/        ← D1~D6 (문제정의서·목표KPI·이해관계자맵·범위·대안비교·리스크가정)
├── S1-범위정의/    ← D7~DB (제약사항·NFR·컴포넌트·시스템구성도·도메인정의서)
├── S2-구조설계/    ← DC~DI (상위UC·메뉴구조도·EARS·ERD·상태머신·프로세스·이벤트) + Bolt 분할
├── S3-상세설계/    ← DJ~DQ (GWT·세부UC·인터페이스·시퀀스·화면·ADR·클래스·프로그램목록)
├── S4-구현/        ← 코드·자동검증·단위테스트
├── S5-테스트/      ← 통합테스트·E2E·GWT실행
└── S6-안정화/      ← 성능튜닝·버그수정·NFR검증·운영이관
```

---

## 공정별 자산화와의 관계

| 관점 | 폴더 | 용도 |
|---|---|---|
| **공정별** (`자산화-공정별/`) | Spec/Design 성격별 분류 | 산출물 찾기, 표준양식 참조 |
| **단계별** (`자산화-단계별/`) | 작성 순서별 분류 | 실행 순서 확인, 선후행 추적 |

> 하나의 산출물은 **한 곳에만** 원본을 두고, 다른 쪽에서는 링크로 참조하는 것을 권장한다.
> 현재는 공정별에 기존 산출물이 있으므로, 단계별 폴더에서 공정별을 참조하거나
> 새로 작성하는 산출물은 단계별에 원본을 두고 공정별에서 참조한다.
