# 샘플: 문제 정의서

> **단계**: 착수
> **문서범위**: Project
> **문서종류**: Proposal
>
> **작성 목적**: "왜 이 프로젝트를 하는가"를 명확히 한다.
> 현재 문제(Pain)와 방치 시 영향(Impact), 해결 시 기회(Opportunity)를 정의하여
> 프로젝트 수행 여부의 판단 근거를 제공한다.
>
> **흐름 내 위치**:
> ```
> 착수: 문제정의서 → 목표KPI → 이해관계자맵 → 범위 → 대안비교 → 리스크가정
>   ↓
> 범위정의: ① 제약사항 ...
> ```
>
> **작성 주체**: PM/사업 담당자 + AI 협업 (의사결정권자 승인)

## 필수 항목

| # | 항목 | 설명 | 작성 가이드 |
|---|---|---|---|
| 1 | **Background** | 프로젝트 배경·맥락 | "누가, 무엇을, 왜 시작하려 하는가" 1~2문단 |
| 2 | **Problem** | 현재 문제 정의 (1~3개) | 핵심 문제를 번호로 나열, 증상과 원인 구분 |
| 3 | **Impact** | 문제 방치 시 영향 | 비용·시간·기회비용 등 수치화 가능한 것은 수치로 |
| 4 | **Opportunity** | 해결 시 기대 효과 | 정량(비용 절감 %) + 정성(자산화, 재사용) |

## 샘플 (이커머스 플랫폼)

### Background

3TOP 2본부가 러닝 전문 B2C 이커머스 "runNshop"을 신규 구축한다.
자사 상품 + 입점사 오픈마켓 모델로, 12개 도메인(주문·결제·상품·회원 등)을 포함하는 풀 스펙 플랫폼이다.

### Problem

1. **자산화 부재**: 이전 프로젝트의 설계·코드가 정리되지 않아 매번 처음부터 작업
2. **AI 협업 산정 불확실**: AI 활용 시 공수·기간 산정 기준이 없음
3. **방법론 부재**: 산출물 정의·선후행 관계·표준 양식이 없어 품질 편차 발생

### Impact (방치 시)

- 사업비 산정 실패 위험 (baseline 16억원/6개월 대비 비교 근거 없음)
- 인력 투입 후 자산 미정리 → 다음 프로젝트에서 동일 비용 반복
- AI 협업 경험 부재 → 조직 경쟁력 저하

### Opportunity (해결 시)

- 비용 30% 절감 목표 (16억 → 11.2억)
- 방법론 자산화 → 타 프로젝트 재사용 (뷰티샵 등)
- AI 협업 산정 모델 확보 → 영업·제안 시 근거 제공

## 작성 팁

| 팁 | 설명 |
|---|---|
| **Problem은 3개 이내** | 많으면 핵심이 흐려짐 |
| **Impact는 수치로** | "매출 감소"보다 "연간 2억 기회비용 손실" |
| **Opportunity는 실현 가능한 것만** | 희망사항이 아닌 검증 가능한 목표 |
| **발주자가 읽을 문서** | 기술 용어 최소화, 비즈니스 언어 사용 |
