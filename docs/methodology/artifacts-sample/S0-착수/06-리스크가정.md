# 샘플: 리스크·가정

> **단계**: 착수
> **문서범위**: Project
> **문서종류**: Proposal
>
> **작성 목적**: 프로젝트 시작 전에 식별된 리스크와 전제 가정을 기록한다.
> 리스크는 "발생하면 프로젝트에 부정적 영향을 주는 불확실성",
> 가정은 "참이라고 전제하지만 검증이 필요한 것"이다.
>
> **흐름 내 위치**:
> ```
> 대안비교 → 리스크가정 → (착수 완료) → 범위정의
> ```
> Tasks 단계에서 "리스크 대응계획"으로 확장, 안정화 단계에서 현행화.
>
> **작성 주체**: PM + 시니어 개발자 + AI 협업

## 작성 팁

| 팁 | 설명 |
|---|---|
| **리스크 ≠ 문제** | 리스크는 "아직 발생하지 않은 것", 이미 발생하면 이슈로 전환 |
| **확률×영향 = 우선순위** | 높음×높음은 반드시 대응 전략 필요 |
| **가정이 틀리면?** | 가정 실패 시 대안(Plan B)을 미리 생각해둘 것 |
| **Tasks 단계로 이관** | 여기서 식별한 리스크는 Tasks의 "리스크 대응계획"에서 구체화 |
| **안정화에서 현행화** | 실제 발생 여부를 기록하여 다음 프로젝트 참고자료로 활용 |
