# 샘플: 프로그램 목록

> **단계**: 상세설계
> **문서범위**: Domain
> **문서종류**: Design
>
> **작성 목적**: 해당 도메인에서 구현해야 할 화면·API·컨슈머·배치 프로그램을 전수 도출하여,
> WBS/백로그의 입력물로 활용한다. 누락 없는 구현 범위 확정이 핵심 목적이다.
>
> **흐름 내 위치**:
> ```
> ⑮ 인터페이스명세 + ⑯ 시퀀스 + ⑰ 화면레이아웃 → ⑳ 프로그램 목록 → WBS/백로그
> ```
>
> **작성 주체**: 시니어 개발자 + AI 협업
