# 화면정의서 — Vendor (입점사) 도메인

> **작성 목적**: `runNshop_screen_definition_v1_1.md`에서 v1.0→v1.1 전환 시 삭제된 와이어프레임을 보완한다. `화면정의서_작성_표준안.md` 방식(메타정보+영역·속성·기능·UI상태)을 따르되 와이어프레임(ASCII)과 상세디스크립션을 한 파일에 통합했다.

> **작성일**: 2026-08-26

|---|---|---|
| F1 | 배송사코드 | **등록 시에만 입력 가능, 수정 모드에서는 비활성화(disabled)** — 코드 변경 시 배송 추적 연동이 끊길 수 있어서로 추정 |
| F2, F5 | 배송사명, 정렬순서 | 필수 입력(미입력 시 인라인 에러) |
| F3, F4 | API 엔드포인트, 배송조회 URL | 선택 입력 — `01-Order.md` VND-020-002(배송 관리)의 배송사 셀렉트(`DELIVERY_COMPANIES`)와 이 목록이 같은 소스를 참조해야 하나, 현재 `ShippingPage.tsx`(partner)는 별도 하드코딩 배열을 쓰는 것으로 확인됨(Human Review) |

> **API연동 개념(추정)**: `apiConnected=true`인 배송사는 배송조회를 자동화(API 연동)할 수 있고, `false`인 배송사는 수기로 운송장을 관리하는 것으로 추정된다 — `01-Order.md` VND-020-002의 배송정보 입력이 배송사별로 다르게 동작하는지는 확인되지 않았다.
