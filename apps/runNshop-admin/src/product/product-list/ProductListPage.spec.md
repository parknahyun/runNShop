# 상품 목록 (ProductListPage)

## 개요
플랫폼에 등록된 전체 상품(마스터 데이터)을 조회·관리하는 현황목록 화면.
브랜드·표준카테고리 마스터를 참조하며, 신규 등록 상품의 실제 판매 승인은 "상품 심사" 화면에서 이루어진다.
(ADM-020-002, `prd_product`)

## 판매상태 / 심사상태
| 구분 | 코드 | 라벨 |
|------|------|------|
| 판매상태 | ON_SALE / SOLD_OUT / DISCONTINUED | 판매중 / 품절 / 판매종료 |
| 심사상태 | PENDING / APPROVED / REJECTED | 심사대기 / 승인 / 반려 |

판매상태는 심사상태가 "승인"인 상품에만 실질적인 의미를 가진다. 심사대기·반려 상품의 판매상태는
승인 시 적용될 "의도한 상태"를 미리 담아두는 값이다.

## 필터바
- 키워드 (상품ID / 상품명 / 입점사)
- 브랜드 선택
- 판매상태 선택
- 심사상태 선택
- 조회 버튼

## 요약바
전체 / 판매중 / 품절 / 심사대기 건수 표시 (조회 후 등록 버튼과 함께 노출)

## 목록 테이블
| 컬럼 | 설명 |
|------|------|
| 상품ID | PRD-001 형식 |
| 상품명 | 클릭 시 상세 모달 오픈 |
| 브랜드 | 브랜드관리 마스터 참조 |
| 표준카테고리 | 표준카테고리관리 마스터 참조 |
| 정상가 | |
| 판매가 | |
| 판매상태 | 배지 |
| 심사상태 | 배지 |
| 최종수정 | 수정자 / 수정일시 2줄 표기 |

## 규칙 (현황목록 공통)
- 진입 시 TitleBar + FilterBar만 표시, 데이터 미노출
- 조회 버튼 클릭 후 SummaryBar + Table + Pagination 동시 노출 (Enter 키 조회 가능)
- 행 클릭 → 상세 모달 오픈 (탭으로 열지 않음)
- 등록 버튼 → 등록 모달 오픈

## 등록 (AddProductModal)
단일 스텝 등록: 상품명, 브랜드(선택), 표준카테고리(선택), 입점사명, 정상가/판매가, 판매상태.
등록된 상품은 **항상 심사상태 = 심사대기로 시작**하며, "상품 심사" 화면에서 승인해야 실제 판매 화면에 노출된다.
이미지·옵션·재고는 등록 후 상세의 각 탭에서 구성하며, 문의·상품평은 고객이 남기는 데이터이므로 등록 시 항상 빈 상태로 시작한다.

## 상세 모달 (ProductDetail)
탭 구성: **기본정보 / 이미지 (N) / 옵션 (N) / 재고이력 (N) / 문의 (N) / 상품평 (N)**

`readOnly`/`footer` 옵션을 지원해 "상품 심사" 화면(ProductReviewDetail)이 동일한 컴포넌트를 조회 전용으로 재사용한다 —
심사 화면에서는 편집·추가·삭제 등 변경 액션이 모두 숨겨지고, `footer`로 전달된 승인/반려 액션 영역만 하단에 추가된다.

### 기본정보 탭
읽기/편집 토글 방식
- 읽기 모드: 상품ID, 상품명, 브랜드, 표준카테고리, 입점사, 정상가/판매가, 판매상태, 심사상태(+반려 시 반려사유), 등록/수정 정보, 하단에 **상세설명**(상품 상세페이지 노출용, 서식 없는 일반 텍스트로 줄바꿈은 그대로 표시)
- 편집 모드: 상품명, 브랜드, 표준카테고리, 입점사명, 정상가/판매가, 판매상태, 상세설명 수정 가능
- **심사상태는 이 화면에서 변경할 수 없다** — 승인/반려 처리는 "상품 심사" 화면의 전용 액션으로만 가능하다(권한 분리)
- 상세설명이 비어 있으면 읽기 모드에 "등록된 상세설명이 없습니다" 안내가 표시된다

### 이미지 탭
- 썸네일 카드 그리드로 표시, "+ 이미지 추가"로 이미지 URL 등록(mock — 실제 업로드는 지원하지 않음)
- 각 카드 우상단에 **노출순서** 번호를 배지로 표시
- 카드별 ↑/↓(노출순서 변경), "대표설정"(대표이미지는 항상 1개만 유지), "삭제"
- 대표이미지를 삭제하면 남은 이미지 중 첫 번째가 자동으로 대표로 지정된다
- 순서·대표 변경 및 삭제는 저장 시에만 반영(취소 시 원복)

#### 대표이미지 리사이징
- 대표이미지 카드에는 "리사이징(N)" 버튼이 노출되며, 클릭하면 리사이징 관리 팝업이 열린다
- 리사이징은 화면 노출 용도(목록형/카드형/상세형/썸네일형)별로 별도의 이미지 URL과 가로×세로 크기(px)를 등록해두는 기능이다 — 용도당 1건만 등록 가능
- 팝업 내 추가/삭제는 **즉시** 대표이미지의 리사이징 목록에 반영되며, 이미지 탭의 저장 버튼을 눌러야 상품에 최종 반영된다(취소 시 원복)
- 대표이미지를 다른 이미지로 변경하면 리사이징은 새 대표이미지에 다시 등록해야 한다(기존 리사이징은 이전 이미지에 남아있는다)

### 옵션 탭
- 옵션그룹을 표(옵션명/옵션값/관리)로 표시. **옵션그룹은 최대 2개까지만 등록 가능**하며, 2개에 도달하면 "+ 옵션그룹 추가" 버튼이 비활성화된다
- "+ 옵션그룹 추가"/"편집": 옵션명과 옵션값을 **별도 입력창**으로 입력한다 — 옵션값은 쉼표(,)로 구분해 입력(예: 옵션명 "사이즈" / 옵션값 "S, M, L")
- 그룹별로 "편집"(옵션명·옵션값 수정) / "삭제" 가능
- 옵션이 없으면 "기본" 1개 조합으로만 재고이력이 관리된다
- 저장 시에만 반영(취소 시 원복)

#### SKU별 현재고
- 옵션 탭 하단에 "SKU별 현재고" 영역을 두며, 우측에 **"SKU생성"** 버튼이 있다
- SKU는 옵션조합처럼 자동으로 다 노출되는 것이 아니라, **"SKU생성" 버튼을 눌러야 실제 SKU 레코드로 생성**된다
  - 옵션그룹들의 **카테시안곱**으로 만들어지는 옵션조합 중, 아직 SKU가 생성되지 않은 조합 수가 버튼에 표시된다 (예: "SKU생성 (3)")
  - 예: 사이즈(S/M/L) × 색상(블랙/화이트) = 6개 조합 → 그중 미생성 조합만큼 버튼에 표시
  - 이미 생성된 SKU가 있는 조합은 다시 생성되지 않는다(중복 생성 방지). 생성할 조합이 없으면 버튼이 비활성화된다
- 생성된 SKU는 표(옵션조합/**상태**/현재고)로 표시된다
  - **상태**: 판매중 / 판매중지 — SKU(옵션조합) 단위로 개별 전환 가능한 셀렉트. 특정 옵션조합만 일시적으로 판매를 중단할 때 사용한다(예: 특정 사이즈만 단종)
  - 현재고는 재고이력 탭에 쌓인 입고/출고/조정 이력의 합으로 계산되며, 0 이하인 조합은 빨간색으로 강조된다
- SKU 생성, 상태 변경, 옵션그룹 추가/편집/삭제는 모두 저장 시에만 상품에 반영된다(취소 시 원복)

### 재고이력 탭
- 재고는 수량을 직접 수정하는 값이 아니라 **입고/출고/조정 이력의 합으로 계산되는 현재고**로 관리한다 (SKU별 현재고는 옵션 탭에서 확인한다)
- "+ 입출고 등록": 옵션조합 선택, 유형(입고/출고/조정) 선택, 조정인 경우 증가/감소 선택, 수량, 사유를 입력 → **즉시** 재고이력에 추가된다(별도 저장/취소 없음)
- 전체 재고이력을 표(이력ID/옵션조합/유형/변동수량/사유/등록자/등록일)로 최신순 표시. 변동수량은 입고·증가 조정은 초록색(+), 출고·감소 조정은 빨간색(-)으로 구분
- 등록된 이력은 삭제·수정할 수 없다(감사 기록 성격 — 실수를 바로잡으려면 반대 방향의 조정 이력을 추가한다)
- 옵션 탭에서 옵션조합을 바꾸면(옵션값 추가/삭제) 이후 "+ 입출고 등록"의 옵션조합 선택지도 즉시 함께 바뀐다. 더 이상 존재하지 않는 조합에 쌓인 과거 이력은 삭제되지 않고 그대로 남는다

### 문의 탭
- 고객이 남긴 상품문의를 표(문의ID/작성자/문의내용·답변/상태/등록일/관리)로 표시. 등록(작성) 기능은 없다(고객이 남기는 데이터)
- 미답변 문의에만 "답변" 버튼이 노출되며, 클릭하면 **답변창(팝업)** 이 열린다 — 문의ID/작성자/등록일, 문의내용, 답변 입력창으로 구성
- 답변창에서 "답변등록"을 누르면 **즉시** 답변완료로 반영되고 창이 닫힌다(별도 저장/취소 없음)
- 이미 답변완료된 문의는 재답변(수정)을 지원하지 않는다

### 상품평 탭
- 고객이 남긴 상품평을 표(상품평ID/작성자/평점/상품평내용/노출상태/등록일/관리)로 표시. 등록(작성) 기능은 없다
- 관리자는 "숨김처리"/"복원" 버튼으로 상품평 노출 여부를 **즉시** 전환할 수 있다(별도 저장/취소 없음). 숨김 처리된 행은 흐리게 표시된다

## 비고
- 브랜드·표준카테고리 셀렉트에는 사용 중(ACTIVE) 상태인 마스터만 노출된다.
- 상품 삭제는 지원하지 않는다 — 주문·프로모션 등에서 참조 중일 수 있으므로 판매상태를 "판매종료"로 전환한다.
