# 표준카테고리 관리 (StandardCategoryPage)

## 개요
상품 분류·통계·정책(쿠폰/할인 적용상품 등)에서 참조하는 내부 표준 분류체계를 등록·관리하는 현황목록 화면.
전시카테고리(고객에게 노출되는 GNB/내비게이션 분류)와는 별개의 체계이며, 두 체계 간 연결(매핑)은 전시카테고리 상세의 "표준카테고리" 탭에서 관리한다.
(ADM-020-003, `prd_category_std`)

## 구분 (depth, 레벨)
| 코드 | 라벨 |
|------|------|
| 1 | 대분류 |
| 2 | 중분류 |
| 3 | 소분류 |

3단계 계층 구조이며, 중분류는 반드시 하나의 대분류(depth 1)에, 소분류는 반드시 하나의 중분류(depth 2)에 속한다(parentId).
소분류는 선택 사항이다 — 모든 중분류가 소분류를 가질 필요는 없다.

## 상태
| 코드 | 라벨 |
|------|------|
| ACTIVE | 사용 |
| INACTIVE | 미사용 |

## 필터바
- 키워드 (카테고리ID / 카테고리명)
- 구분 선택 (전체/대분류/중분류/소분류)
- 상태 선택
- 조회 버튼

## 요약바
전체 / 대분류 / 중분류 / 소분류 건수 표시 (조회 후 등록 버튼과 함께 노출)

## 목록 테이블
| 컬럼 | 설명 |
|------|------|
| 카테고리ID | STD-001 형식 |
| 구분 | 대분류 / 중분류 / 소분류 |
| 카테고리명 | 클릭 시 상세 모달 오픈. 중분류는 "└ " 1단, 소분류는 "└ " 2단으로 들여쓰기하여 계층을 표시 |
| 상위카테고리 | 중분류는 소속 대분류명, 소분류는 소속 중분류명, 대분류는 "-" |
| 노출순서 | 같은 상위카테고리 내 정렬 순서 |
| 상태 | 배지 |
| 최종수정 | 수정자 / 수정일시 2줄 표기 |

목록은 등록 순서(대분류 → 소속 중분류 → 소속 소분류가 이어지는 순서)로 표시되어 계층 구조를 한눈에 볼 수 있다.

## 규칙 (현황목록 공통)
- 진입 시 TitleBar + FilterBar만 표시, 데이터 미노출
- 조회 버튼 클릭 후 SummaryBar + Table + Pagination 동시 노출 (Enter 키 조회 가능)
- 행 클릭 → 상세 모달 오픈 (탭으로 열지 않음)
- 등록 버튼 → 등록 모달 오픈

## 등록 (AddStandardCategoryModal)
단일 스텝 등록: 구분(대분류/중분류/소분류) 선택, 중분류는 상위카테고리(대분류) 선택 필수,
소분류는 상위카테고리(중분류) 선택 필수, 카테고리명, 노출순서, 상태.
상위카테고리 후보는 선택한 구분에 따라 자동으로 바뀐다(중분류 선택 시 대분류 목록, 소분류 선택 시 중분류 목록).

## 상세 모달 (StandardCategoryDetail)
읽기/편집 토글 방식의 단일 화면 (하위 탭 없음)
- 읽기 모드: 카테고리ID, 카테고리명, 구분, 상위카테고리, 노출순서, 상태, 등록/수정 정보
- 편집 모드: 카테고리명, 노출순서, 상태 수정 가능. 중분류·소분류는 상위카테고리도 변경 가능(단, 소분류는 다른 중분류로만 이동 가능하며 대분류로는 이동 불가)
- 카테고리ID·구분은 등록 후 변경 불가(구분을 바꾸려면 삭제 후 재등록해야 한다)

## 비고
- 카테고리 삭제는 지원하지 않는다 — 상품·프로모션 등 다른 데이터에서 참조 중일 수 있으므로 "미사용" 상태로 전환하여 신규 참조만 제한한다.
