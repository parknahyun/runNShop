# 전시카테고리 관리 (DisplayCategoryPage)

## 개요
고객 화면(GNB/내비게이션)에 노출되는 전시 분류체계를 등록·관리하는 현황목록 화면.
표준카테고리(내부 분류·통계·정책 참조용)와는 독립적인 별개의 체계이며, MD가 자유롭게 구성할 수 있다.
두 체계 간 연결(매핑)은 전시카테고리 상세의 "표준카테고리" 탭에서 전시카테고리 1건당 표준카테고리 여러 건을 지정하는 방식으로 관리한다.
(ADM-020-004, `prd_category_display`, `prd_category_display_std_map`)

## 구분 (depth, 레벨)
| 코드 | 라벨 |
|------|------|
| 1 | 대분류 |
| 2 | 중분류 |
| 3 | 소분류 |

3단계 계층 구조이며, 중분류는 반드시 하나의 대분류(depth 1)에, 소분류는 반드시 하나의 중분류(depth 2)에 속한다(parentId).
소분류는 선택 사항이다 — 모든 중분류가 소분류를 가질 필요는 없다.

## 상태 / GNB 노출
| 구분 | 코드 | 라벨 |
|------|------|------|
| 상태 | ACTIVE / INACTIVE | 사용 / 미사용 |
| GNB 노출 | true / false | 노출 / 숨김 |

**상태**와 **GNB 노출**은 별개의 축이다. 상태가 "사용"이어도 GNB 노출을 "숨김"으로 설정해 특정 기간 동안만 고객 화면에서 감출 수 있다(예: 시즌 종료 카테고리를 삭제 없이 잠시 숨기는 경우).

## 필터바
- 키워드 (카테고리ID / 카테고리명)
- 구분 선택 (전체/대분류/중분류/소분류)
- 상태 선택
- 조회 버튼

## 요약바
전체 / 대분류 / 중분류 / 소분류 / 숨김 건수 표시 (조회 후 등록 버튼과 함께 노출)

## 목록 테이블
| 컬럼 | 설명 |
|------|------|
| 카테고리ID | DPC-001 형식 |
| 구분 | 대분류 / 중분류 / 소분류 |
| 카테고리명 | 클릭 시 상세 모달 오픈. 중분류는 "└ " 1단, 소분류는 "└ " 2단으로 들여쓰기하여 계층을 표시 |
| 상위카테고리 | 중분류는 소속 대분류명, 소분류는 소속 중분류명, 대분류는 "-" |
| 노출순서 | 같은 상위카테고리 내 정렬 순서 |
| GNB노출 | 👁 노출 / — 숨김 (읽기 전용 표시, 변경은 상세에서) |
| 상태 | 배지 |
| 최종수정 | 수정자 / 수정일시 2줄 표기 |

목록은 등록 순서(대분류 → 소속 중분류 → 소속 소분류가 이어지는 순서)로 표시되어 계층 구조를 한눈에 볼 수 있다.

## 규칙 (현황목록 공통)
- 진입 시 TitleBar + FilterBar만 표시, 데이터 미노출
- 조회 버튼 클릭 후 SummaryBar + Table + Pagination 동시 노출 (Enter 키 조회 가능)
- 행 클릭 → 상세 모달 오픈 (탭으로 열지 않음)
- 등록 버튼 → 등록 모달 오픈

## 등록 (AddDisplayCategoryModal)
단일 스텝 등록: 구분(대분류/중분류/소분류) 선택, 중분류는 상위카테고리(대분류) 선택 필수,
소분류는 상위카테고리(중분류) 선택 필수, 카테고리명, 노출순서, GNB 노출, 상태.
상위카테고리 후보는 선택한 구분에 따라 자동으로 바뀐다(중분류 선택 시 대분류 목록, 소분류 선택 시 중분류 목록).

## 상세 모달 (DisplayCategoryDetail)
탭 구성: **기본정보 / 표준카테고리 (N)**

### 기본정보 탭
읽기/편집 토글 방식
- 읽기 모드: 카테고리ID, 카테고리명, 구분, 상위카테고리, 노출순서, GNB 노출, 상태, 등록/수정 정보
- 편집 모드: 카테고리명, 노출순서, GNB 노출, 상태 수정 가능. 중분류·소분류는 상위카테고리도 변경 가능(단, 소분류는 다른 중분류로만 이동 가능하며 대분류로는 이동 불가)
- 카테고리ID·구분은 등록 후 변경 불가(구분을 바꾸려면 삭제 후 재등록해야 한다)

### 표준카테고리 탭 (테이블 형태)
- 표준카테고리 전체(대/중/소분류, 계층 들여쓰기 표시)를 표(선택/카테고리ID/구분/카테고리명/상위카테고리)로 나열하고 체크박스로 다중선택
- 행 클릭으로도 선택 토글 가능
- 레벨(구분) 제한 없이 대분류·중분류·소분류를 자유롭게 조합해 매핑할 수 있다
- 저장 시에만 반영(취소 시 원복) — 기본정보 탭과 독립적으로 저장

## 비고
- "이벤트관"처럼 표준카테고리와 대응되지 않는 전시 전용 카테고리(캠페인/기획전 모음 등)는 표준카테고리 매핑 없이(0건) 운영할 수 있다 — 전시카테고리는 상품 분류가 아니라 "고객에게 어떻게 보여줄지"를 위한 체계다.
- 하나의 전시카테고리는 여러 표준카테고리에 매핑될 수 있고, 반대로 하나의 표준카테고리가 여러 전시카테고리에서 참조될 수도 있다(다대다 관계).
- 카테고리 삭제는 지원하지 않는다 — GNB 링크·기획전 등에서 참조 중일 수 있으므로 "미사용" 상태 또는 GNB 숨김으로 전환한다.
