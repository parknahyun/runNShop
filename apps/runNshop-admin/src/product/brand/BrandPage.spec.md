# 브랜드 관리 (BrandPage)

## 개요
상품에 연결되는 브랜드 마스터 데이터를 등록·관리하는 현황목록 화면.
(ADM-020-006, `prd_brand`)

## 상태
| 코드 | 라벨 |
|------|------|
| ACTIVE | 사용 |
| INACTIVE | 미사용 |

## 필터바
- 키워드 (브랜드ID / 브랜드명 / 영문명)
- 상태 선택
- 조회 버튼

## 요약바
전체 / 사용 / 미사용 건수 표시 (조회 후 등록 버튼과 함께 노출)

## 목록 테이블
| 컬럼 | 설명 |
|------|------|
| 브랜드ID | BRD-001 형식 |
| 브랜드명 | 클릭 시 상세 모달 오픈 |
| 영문명 | |
| 등록상품수 | 이 브랜드로 등록된 상품 수 (읽기 전용, 상품 등록 화면에서만 증가) |
| 상태 | 배지 |
| 최종수정 | 수정자 / 수정일시 2줄 표기 |

## 규칙 (현황목록 공통)
- 진입 시 TitleBar + FilterBar만 표시, 데이터 미노출
- 조회 버튼 클릭 후 SummaryBar + Table + Pagination 동시 노출 (Enter 키 조회 가능)
- 행 클릭 → 상세 모달 오픈 (탭으로 열지 않음)
- 등록 버튼 → 등록 모달 오픈

## 등록 (AddBrandModal)
단일 스텝 등록: 브랜드명, 영문명, 이미지 URL, 브랜드 소개, 상태. 등록 시 등록상품수는 0으로 시작한다.

## 상세 모달 (BrandDetail)
읽기/편집 토글 방식의 단일 화면 (하위 탭 없음)
- 읽기 모드: 이미지 미리보기(72×72) + 브랜드 소개, 브랜드ID, 브랜드명, 영문명, 상태, 등록상품수, 등록/수정 정보
- 편집 모드: 브랜드명, 영문명, 이미지 URL, 브랜드 소개, 상태 수정 가능
- 브랜드ID·등록상품수는 등록 후 변경 불가(읽기 전용)
- 이미지는 실제 업로드 없이 URL 입력만 지원한다(mock). URL이 비어있으면 "이미지 없음" placeholder를 표시한다.

## 비고
- 브랜드 삭제는 지원하지 않는다 — 이미 등록된 상품과의 참조 무결성을 위해 "미사용" 상태로 전환하여 신규 상품 등록 시 노출만 제한한다.
