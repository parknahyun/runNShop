# 리뷰 관리 (ReviewPage)

## 개요
고객이 작성한 상품 리뷰를 조회하고 부적절한 리뷰를 숨김·재활성화 처리하는 현황목록 화면.
(ADM-080-001, `cmt_review`. 상품별 평균평점·평점분포는 별도 집계 테이블 `cmt_rating`에서 관리하며 본 화면은 리뷰 원본만 다룬다.)

리뷰는 고객이 구매한 주문상품(`order_item`)당 1건만 작성할 수 있으며, 관리자가 신규로 리뷰를 등록하는 기능은 없다.
이 화면은 이미 작성된 리뷰를 조회하고 노출 여부(활성/숨김)를 관리하는 용도로만 사용된다.

## 상태 (status)
| 코드 | 라벨 | 의미 |
|------|------|------|
| ACTIVE | 활성 | 정상 노출 중인 리뷰 (기본 상태) |
| HIDDEN | 숨김 | 관리자가 사유를 입력하고 숨김 처리한 리뷰. 서비스 화면에는 노출되지 않음 |
| DELETED | 삭제 | 고객 스스로 삭제했거나 정책 위반으로 삭제된 리뷰. 관리자 화면에서도 액션 없이 조회만 가능 |

상태 전이: `ACTIVE ↔ HIDDEN` 양방향 전이만 상세 모달 하단 액션으로 가능하다. `DELETED`는 이 화면의 액션으로 도달하지 않는 상태이며(고객 삭제 등 외부 요인으로만 발생), 삭제된 리뷰에는 액션 버튼이 없다.

## 필터바
- 키워드 (상품명 / 작성자명)
- 평점 선택 (전체 / 1~5점)
- 상태 선택 (전체/활성/숨김/삭제)
- 포토리뷰만 보기 체크박스
- 조회 버튼

## 요약바
전체 / 활성 / 숨김 / 삭제 건수와, 현재 조회된 목록의 평균평점을 함께 표시한다 (조회 후 노출).

## 목록 테이블
| 컬럼 | 설명 |
|------|------|
| 리뷰번호 | RVW-001 형식, 클릭 시 상세 모달 오픈 |
| 상품명 | |
| 작성자 | 마스킹 표시 (예: 박*희) |
| 평점 | ★☆ 5개 만점 표시 |
| 포토리뷰 | 포토리뷰인 경우 배지 표시 |
| 내용 | 1줄 요약(말줄임) |
| 상태 | 배지 |
| 작성일시 | |

## 규칙 (현황목록 공통)
- 진입 시 TitleBar + FilterBar만 표시, 데이터 미노출
- 조회 버튼 클릭 후 SummaryBar + Table + Pagination 동시 노출 (Enter 키 조회 가능)
- 행 클릭 → 상세 모달 오픈 (탭으로 열지 않음)
- 등록 버튼 없음 (리뷰는 고객의 구매 후 작성 행위로만 생성됨)
- 일괄 숨김/일괄 활성화(체크박스 다중 선택)는 본 mock 구현 범위에서는 제공하지 않으며, 상세 모달에서 건별로만 처리한다.

## 상세 모달 (ReviewDetail)
탭 구성: **기본정보** (단일 탭)

### 기본정보 탭
리뷰번호, 상품명, 작성자, 평점(★☆ 텍스트 + N/5 표기), 상태, 포토리뷰 여부, 작성일시, 최종수정일시, 리뷰 내용, 첨부 이미지(썸네일 나열)를 읽기 전용으로 표시한다.
상태가 숨김/삭제인 경우 숨김(삭제)사유를 함께 노출한다.

## 상태 전이 액션 (모달 하단 고정 영역)
- 상태 = 활성: **숨김** 버튼 → 클릭 시 숨김사유 입력 폼이 펼쳐지며, 사유를 입력해야 "숨김 확정" 버튼이 활성화된다. 확정 시 상태가 숨김으로 전환되고 사유가 저장된다.
- 상태 = 숨김: **활성화** 버튼 → 즉시 상태를 활성으로 전환하고 숨김사유를 초기화한다 (별도 확인 입력 없음).
- 상태 = 삭제: 액션 버튼 없음 (조회만 가능)

## 비고
- 실 서비스에서는 리뷰 숨김·삭제 시 `cmt_rating`의 평점 집계(평균평점·건수·점수별 분포)가 함께 갱신되어야 하나, 본 mock 구현은 리뷰 원본 상태값만 관리하며 집계 테이블 연동은 표현하지 않는다.
- 일괄 숨김/일괄 활성화, 엑셀 다운로드는 API 목록(`/api/admin/v1/reviews/bulk-hide` 등)에는 정의되어 있으나 본 화면에서는 스텁(엑셀) 또는 범위 외(일괄 처리)로 처리한다.
