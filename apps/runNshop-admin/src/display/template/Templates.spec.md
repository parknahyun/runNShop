# 템플릿 관리 (TemplatePage)

## 개요
페이지 생성 시 기본 섹션 구성을 제공하는 템플릿을 관리하는 목록 화면.
페이지는 템플릿을 **복사**(참조 아님)하여 생성하므로, 템플릿 수정이 기존 페이지에 영향 없음.

## 템플릿 유형
| 코드 | 라벨 |
|------|------|
| HOME | 메인 |
| CATEGORY | 카테고리 |
| EXHIBITION | 기획전 |
| EVENT | 이벤트 |

## 상태
| 코드 | 라벨 |
|------|------|
| ACTIVE | 활성 |
| INACTIVE | 비활성 |
| DEPRECATED | 폐기 |

## 필터바
- 키워드 (템플릿ID / 템플릿명)
- 유형 선택 (전체/메인/카테고리/기획전/이벤트)
- 상태 선택 (전체/활성/비활성/폐기)
- 조회 버튼

## 요약카드
전체 / 활성 / 비활성 / 폐기 — 4개, 조회 후에만 노출 (섹션 관리 화면과 동일 구성)

## 목록 테이블
| 컬럼 | 설명 |
|------|------|
| 템플릿ID | TPL-001 형식 |
| 템플릿명 | 클릭 시 상세 모달 |
| 유형 | 배지. 색상 구분 없는 plain 배지 (`data-*-status` 속성 없음) |
| 영역 수 | 섹션 개수 |
| 적용 페이지 수 | 이 템플릿 기반으로 생성된 페이지 수 |
| 상태 | 배지. 전용 컴포넌트 없이 기존 `data-product-status` 속성 재사용
        (ACTIVE→ON_SALE, INACTIVE→DRAFT, DEPRECATED→DISCONTINUED로 매핑, 섹션 화면과 동일 패턴) |
| 최종수정 | 수정자 / 수정일시 |

## 크로스 도메인 의존성
- `display/section/mockData.ts`의 `MOCK_SECTIONS`를 직접 import — 영역 추가/편집의
  섹션 select 옵션(status==='ACTIVE'만)을 만드는 데 사용. 전용 헬퍼 함수는 없고
  화면 코드에서 직접 filter/map 한다.

## 템플릿 추가 (AddTemplateModal)
2-Step:
1. **기존 템플릿 선택** (복사 기반): 유형 필터 + 활성 템플릿 그리드 카드 (3열, 250x120px). "빈 템플릿으로 시작" 옵션 제공.
2. **상세 설정**: 기본 정보 탭 + 영역 목록 탭

## 상세 모달 (TemplateDetail)
탭 구성: **기본 정보 / 영역 목록 / 페이지 목록**

### 기본 정보 탭
- 읽기/편집 모드 전환
- 수정 제약 없음 (복사 방식이므로)

### 영역 목록 탭
- 순서: 섹션 → 영역명
- 영역 추가/편집 시 섹션 ID 선택 (select에 sectionCode만 표시)
- 영역명 기본값: `{섹션 라벨}_{번호}`
- 수정 제약 없음

### 페이지 목록 탭
- 이 템플릿 기반으로 생성된 페이지 목록 (읽기 전용)

## 영역 구조
```typescript
interface TemplateSection {
  sectionName: string     // 영역명
  sectionType: string     // 섹션 ID (sectionCode)
  sortOrder: number
}
```
