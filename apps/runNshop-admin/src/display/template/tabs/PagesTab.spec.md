# 템플릿 페이지 목록 탭 (PagesTab)

## 개요
이 템플릿을 기반으로 생성된 페이지 목록을 보여주는 읽기 전용 탭.

## 테이블 컬럼
| 컬럼 | 설명 |
|------|------|
| 페이지ID | PAGE-001 형식 |
| 페이지명 | - |
| 상태 | 게시중/예약/미게시 배지 |
| 게시일시 | - |

## 비고
- 읽기 전용 (이 탭에서 직접 수정 불가)
- 게시중: 실제 게시일시 표시
- 예약/미게시: 예정일 + "(예정)" 표기
