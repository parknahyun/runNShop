# 템플릿 영역 목록 탭 (SectionsTab)

## 개요
템플릿 상세 모달의 영역 목록 탭. 섹션 구성을 관리.

## 테이블 컬럼 순서
| 순서 | 섹션 | 영역명 | 편집/삭제 |
|------|----------|--------|-----------|
| ↑↓ 버튼 | sectionType (배지) | sectionName | 편집/삭제 버튼 |

## 영역 추가 모달
| 필드 | 설명 |
|------|------|
| 섹션 | select (sectionCode만 표시) |
| 영역명 | 기본값: `{섹션 라벨}_{번호}` |

순서: 섹션 → 영역명

## 영역 편집 모달
- 섹션 변경 가능
- 영역명 변경 가능

## 수정 제약
- 없음 (복사 방식이므로 자유 편집)
