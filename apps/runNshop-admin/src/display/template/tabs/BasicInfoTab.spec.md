# 템플릿 기본 정보 탭 (BasicInfoTab)

## 개요
템플릿 상세 모달의 기본 정보 탭.

## 읽기 모드
| 항목 | 설명 |
|------|------|
| 템플릿ID | TPL-001 형식 |
| 템플릿명 | - |
| 유형 | 배지 |
| 상태 | 배지 |
| 구성영역 수 | - |
| 적용 페이지 수 | - |
| 최초등록 | 등록자 / 등록일시 |
| 최종수정 | 수정자 / 수정일시 |

## 편집 모드
- 템플릿ID: 변경 불가
- 템플릿명: 텍스트 입력 (필수)
- 유형: 변경 불가 (disabled)
- 상태: 라디오 (활성/비활성/폐기)
- 저장/취소 버튼

## 수정 제약
- 없음 (복사 방식이므로 자유 편집)
