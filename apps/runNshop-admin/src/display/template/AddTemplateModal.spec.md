# 템플릿 추가 (AddTemplateModal)

## 개요
새 템플릿을 등록하는 2-Step 모달.

## Step 1: 기존 템플릿 선택 (복사 기반)
- 활성 상태 템플릿 목록을 그리드 카드로 표시
- 유형 필터 (전체/메인/카테고리/기획전/이벤트)
- 카드: 250px × 120px, 3열 고정, 간격 10px
- 선택 후 "다음" → 선택한 템플릿의 영역 구성을 복사하여 기본값 설정
- "빈 템플릿으로 시작" 버튼 제공

## Step 2: 상세 설정
InnerTabs:
- **기본 정보**: 템플릿ID, 템플릿명, 유형, 상태
- **영역 목록**: 복사된 섹션 편집/추가/삭제

### 영역 추가
- 섹션 select (sectionCode만 표시)
- 영역명 (기본값: `{섹션 라벨}_{번호}`)
- 순서: 섹션 → 영역명

## Footer
- Step 1: 취소 / 빈 템플릿으로 시작 / 다음
- Step 2: 이전 / 취소 / 저장
