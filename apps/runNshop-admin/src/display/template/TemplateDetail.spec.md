# 템플릿 상세 (TemplateDetail)

## 개요
템플릿 목록에서 행 클릭 시 나타나는 상세 모달.

## 헤더
- 제목: "템플릿 상세 - {templateName}"
- 부제: templateId + 유형 배지 + 상태 배지 + 영역 수 + 적용 페이지 수
- 닫기 버튼

## 탭 구성
| 탭 | 설명 |
|-----|------|
| 기본 정보 | 메타 정보 조회/편집 |
| 영역 목록 | 섹션 구성 관리 |
| 페이지 목록 | 이 템플릿 기반 페이지 목록 (읽기 전용) |

## 수정 제약
- 없음. 페이지는 템플릿을 복사하여 생성하므로 템플릿 수정이 기존 페이지에 영향 없음.
