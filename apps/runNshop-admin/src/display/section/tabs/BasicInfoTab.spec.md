# 섹션 기본 정보 탭 (BasicInfoTab)

## 개요
섹션 상세 모달의 기본 정보 탭. 섹션의 메타 정보를 조회/편집.

## 읽기 모드 (info-grid)
| 항목 | 설명 |
|------|------|
| 타입 ID | sectionCode |
| 라벨 | sectionName |
| 설명 | description |
| 프리뷰 색상 | 색상 칩 + hex |
| 상태 | 활성/비활성/폐기 배지 |
| 정렬 순서 | sortOrder |
| 최초등록 | 등록자 / 등록일시 |
| 최종수정 | 수정자 / 수정일시 |

## 편집 모드 (add-form)
- 타입 ID: 변경 불가 (disabled)
- 라벨: 텍스트 입력 (필수)
- 설명: 텍스트 입력
- 프리뷰 색상: 컬러피커 + hex 입력
- 정렬 순서: 숫자 입력
- 상태: 라디오 (활성/비활성/폐기)
- 저장/취소 버튼

## 제약사항
- 없음 (자유 편집 가능)
