# 필드 추가/편집 모달 (AddFieldModal)

## 개요
섹션 상세 > 필드 목록 탭에서 필드를 추가하거나 편집하는 모달.

## 입력 필드
| 필드 | 설명 | 비고 |
|------|------|------|
| 필드 키 | camelCase 식별자 | 편집 시 변경 불가 |
| 라벨 | 한글 표시명 | 필수 |
| 타입 | 필드 타입 선택 | 필수 |
| 입력조건 | 필수 / 선택 라디오 | - |
| 기본값 | 타입별 UI 분기 | - |
| 플레이스홀더 | 텍스트 타입일 때만 표시 | - |

## 필드 타입 목록
이미지, 상품, 텍스트, 링크, 색상, 숫자, 날짜시간, 선택, 이미지배열, 상품배열, 텍스트배열

## 기본값 UI 분기
| 타입 | 기본값 UI |
|------|-----------|
| 선택 | 공통코드 그룹 선택 셀렉트 — `common/commonCode.getGroupOptions()`로 그룹코드 목록을 채움
        (이 화면 도메인의 데이터가 아니라 시스템 > 공통코드 도메인 데이터를 그대로 가져다 쓴다) |
| 숫자 | type="number" 입력 |
| 기타 | type="text" 입력 |

## 크로스 도메인 의존성
- `common/commonCode.getGroupOptions()` — "선택" 타입의 기본값 드롭다운을 채우는 데 사용.
  이 컴포넌트 자체의 상태/데이터가 아니라 공통코드 도메인을 직접 참조한다.

## 배치 순서
1. 필드 키 + 라벨
2. 타입 + 입력조건
3. 기본값 + 플레이스홀더(텍스트만)
4. 취소 / 저장(수정) 버튼
