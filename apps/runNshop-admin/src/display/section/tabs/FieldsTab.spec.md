# 필드 목록 탭 (FieldsTab)

## 개요
섹션 상세 모달의 필드 목록 탭. 해당 섹션에 정의된 필드 스키마를 관리.

## 테이블 컬럼
| 컬럼 | 설명 |
|------|------|
| 순서 | ↑↓ 이동 버튼 |
| 필드 키 | code 스타일 표시 |
| 라벨 | 한글명 |
| 타입 | 배지 |
| 입력조건 | 필수(빨간 원) / 선택(—) |
| 기본값 | 값 또는 — |
| 편집/삭제 | 버튼 |

## 섹션 type별 기본 필드 구성
| type | 필드 |
|------|------|
| BANNER | 섹션 제목(텍스트), 이미지 목록(이미지배열), 노출방법(노출선택), 최대 수(숫자) |
| PRODUCT_GRID | 섹션 제목(텍스트), 상품 목록(상품배열), 노출방법(노출선택), 열 수(숫자) |
| PRODUCT_CAROUSEL | 섹션 제목(텍스트), 상품 목록(상품배열), 노출방법(노출선택), 더보기 링크(링크) |
| TEXT | 내용(텍스트), 배경색(색상) |
| IMAGE_LINK | 이미지(이미지) |
| COUNTDOWN | 제목(텍스트), 목표 일시(날짜시간) |
| COUPON_BAND | 버튼 문구(텍스트), 배경색(색상), 글자색(색상) |
| DIVIDER | 높이(숫자), 배경색(색상) |

## 동작
- "+" 필드 추가 → AddFieldModal 팝업
- 편집 → AddFieldModal (initialData 전달)
- 삭제 → 목록에서 제거
- ↑↓ → 순서 변경
