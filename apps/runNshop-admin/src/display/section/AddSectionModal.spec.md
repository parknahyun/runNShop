# 섹션 추가 (AddSectionModal)

## 개요
새 섹션을 등록하는 모달.

## 입력 필드
| 필드 | 설명 | 비고 |
|------|------|------|
| 타입 ID | sectionCode (영문 대문자 + 언더스코어) | 필수, 중복 불가 |
| 라벨 | 한글 표시명 | 필수 |
| 대분류 | type 선택 (BANNER, PRODUCT_GRID 등) | 필수 |
| 설명 | 섹션 설명 | - |
| 프리뷰 색상 | 컬러피커 | 기본 #f1f5f9 |
| 상태 | 활성/비활성 라디오 | 기본 활성 |

## 동작
- 저장 시 목록에 추가
- 취소 시 모달 닫기
