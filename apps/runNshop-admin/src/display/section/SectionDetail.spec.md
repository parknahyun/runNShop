# 섹션 상세 (SectionDetail)

## 개요
섹션 목록에서 행 클릭 시 나타나는 상세 모달.

## 헤더
- 제목: "섹션 상세 - {sectionName}"
- 부제: sectionCode + type 배지 + 상태 배지 + 필드 수
- 닫기 버튼

## 탭 구성
| 탭 | 설명 |
|-----|------|
| 기본 정보 | 메타 정보 조회/편집 |
| 필드 목록 | 필드 스키마 관리 |

## 동작
- 모달 외부 클릭 시 닫기
- 각 탭 독립적으로 편집/저장
