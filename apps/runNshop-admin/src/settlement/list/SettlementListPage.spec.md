# 정산 관리 (SettlementListPage)

## 개요
입점사별 월 정산 내역을 조회하고 확정 처리하는 현황목록 화면.
(ADM-070-001, `stl_settlement` + `stl_settlement_item` + `stl_settlement_adjustment`)

매월 배치가 주문 확정 건을 집계하여 `CALCULATING` 상태의 정산을 자동 생성한다(본 화면 밖의 배치 로직, mock 미표현).
본 화면은 이미 생성된 정산을 조회하고 정산금액 확정을 처리하는 관리자용 화면이며, 정산을 신규로 등록하는 기능은 없다.
지급 완료·보류 처리는 본 화면이 아닌 [지급 관리] 화면에서 이루어진다.

## 상태 (status)
| 코드 | 라벨 | 의미 |
|------|------|------|
| CALCULATING | 정산중 | 배치가 정산 항목을 집계 중인 초기 상태 |
| CONFIRMED | 확정 | 관리자가 정산금액을 확정한 상태. 이의제기 기간(확정일 + 5영업일)이 시작됨 |
| PAID | 지급완료 | [지급 관리] 화면에서 입점사 계좌로 지급이 완료된 상태 |
| HOLD | 보류 | [지급 관리] 화면에서 지급이 보류된 상태 |

상태 전이: `CALCULATING → CONFIRMED`는 본 화면 상세 모달에서, `CONFIRMED → (PAID | HOLD)`는 [지급 관리] 화면에서 처리한다. 역방향 전이는 없다.

## 재정산 유형 (adjustmentType)
| 코드 | 라벨 | 의미 |
|------|------|------|
| RETURN | 반품 | 정산 확정 이후 발생한 반품에 대한 재정산 |
| CANCEL | 취소 | 정산 확정 이후 발생한 취소에 대한 재정산 |
| EXCHANGE | 교환 | 정산 확정 이후 발생한 교환(배송비 등)에 대한 재정산 |

## 필터바
- 키워드 (정산번호 / 입점사명)
- 정산월 (YYYY-MM)
- 상태 선택

## 요약바
전체 / 정산중 / 확정 / 지급완료 / 보류 건수 표시 (조회 후 노출)

## 규칙 (현황목록 공통)
- 진입 시 TitleBar + FilterBar만 표시, 데이터 미노출
- 조회 버튼 클릭 후 SummaryBar + Table + Pagination 동시 노출 (Enter 키 조회 가능)
- 행 클릭 → 상세 모달 오픈 (탭으로 열지 않음)
- 등록 버튼 없음 (정산은 배치가 매월 자동 생성함)
- Toolbar의 `일괄 확정`은 여러 건을 한 번에 확정하는 기능이나, 본 mock 화면은 스텁(alert)으로만 동작한다

## 상세 모달 (SettlementDetail)
탭 구성: **기본정보 / 정산항목 / 재정산내역**

### 기본정보 탭
- 정산번호, 입점사, 정산월, 상태, 정산대상금액, 재정산액, 패널티, 이월액, 최종정산금액, 이의제기 건수, 이의제기 마감일, 확정일시, 확정자, 생성일시, 최종수정일시를 읽기 전용으로 표시

### 정산항목 탭
- `stl_settlement_item` 목록을 구분(itemType)·금액·설명으로 표로 표시 (읽기 전용)

### 재정산내역 탭
- `stl_settlement_adjustment` 목록을 유형·재정산금액·사유·발생일시로 표로 표시 (읽기 전용)

## 상태 전이 액션 (모달 하단 고정 영역)
- 상태 = 정산중: **정산 확정** 버튼만 노출
  - 클릭 시 상태를 `CONFIRMED`로 전이, `confirmedAt`(현재시각) · `confirmedBy`(현재 사용자) 기록
  - `objectionDeadline`을 확정일시 기준 영업일(주말 제외) 5일 후 날짜로 자동 계산
- 상태 = 확정 / 지급완료 / 보류: 액션 버튼 없음 (지급·보류 처리는 [지급 관리] 화면의 권한)

## 비고
- 실 서비스에서는 매일/매월 배치(`SettlementCalcBatch`)가 `stl_settlement_target`을 집계하여 정산 항목을 생성하며, 확정 후 입점사가 이의제기(`stl_settlement_objection`)를 제출하면 검토 후 수용 시 재정산(`stl_settlement_adjustment`)이 생성된다. 본 화면은 이러한 배치 집계·이의제기 접수 화면을 mock으로 표현하지 않으며, 정산항목·재정산내역은 미리 채워진 데이터로 조회만 가능하다.
- 목록/상세에 표시되는 금액은 시연용 예시 수치이며 항목별 합계가 정확히 재정산 공식과 일치하도록 산출되지는 않았다.
