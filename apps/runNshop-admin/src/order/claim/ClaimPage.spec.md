# 클레임 관리 (ClaimPage)

## 개요
고객이 신청한 취소·반품·교환 클레임을 조회·처리하는 현황목록 화면.
(ADM-040-002, FR-CLM-001/002/003/004, `ord_claim` + `ord_claim_item`)

클레임은 고객이 직접 신청하거나(SELF) CS가 고객을 대리해 접수한다(COUNSELOR, 주문상세 CS·클레임 탭 참고).
본 화면은 이미 접수된 클레임을 조회하고 귀책을 판단·처리하는 관리자용 화면이며, 클레임을 신규로 등록하는 기능은 없다.

## 유형 (claimType)
| 코드 | 라벨 |
|------|------|
| CANCEL | 취소 |
| RETURN | 반품 |
| EXCHANGE | 교환 |

## 상태 (status)
| 코드 | 라벨 | 의미 |
|------|------|------|
| REQUESTED | 접수 | 고객·CS가 클레임을 신청한 초기 상태 |
| PROCESSING | 처리중 | 담당자가 처리를 시작한 상태 (귀책 판단·검수 등) |
| COMPLETED | 완료 | 환불/교환 등 후속 처리가 완료된 상태 |
| REJECTED | 반려 | 클레임 요건 미충족 등으로 반려된 상태 |

상태 전이: `REQUESTED → PROCESSING → (COMPLETED | REJECTED)`. 상세 모달 하단 액션 버튼으로만 전이하며 역방향 전이는 없다.

## 귀책 (blameType)
| 코드 | 라벨 | 의미 |
|------|------|------|
| CUSTOMER | 고객귀책 | 단순변심·사이즈오선택 등, 배송비는 고객 부담 |
| VENDOR | 입점사귀책 | 상품불량·오배송·설명상이 등, 배송비는 입점사 부담 |
| PLATFORM | 플랫폼귀책 | 플랫폼 오류로 인한 클레임, 배송비는 플랫폼 부담 |
| PENDING | 판단중 | 아직 귀책이 확정되지 않은 상태 (기본값) |

1차 판단은 플랫폼 CS가 고객 제출 사진을 기준으로 하며, 입점사 이의제기가 가능하고 최종 결정은 플랫폼이 내린다.
상세 모달 기본정보 탭의 편집 모드에서 귀책과 CS 메모를 수정할 수 있다.

## 필터바
- 키워드 (클레임번호 / 원주문번호 / 구매자명)
- 유형 선택 (전체/취소/반품/교환)
- 상태 선택
- 귀책 선택
- 신청일 기간 (from ~ to)
- 조회 버튼

## 요약바
전체 / 접수 / 처리중 / 완료 / 반려 건수 표시 (조회 후 노출)

## 규칙 (현황목록 공통)
- 진입 시 TitleBar + FilterBar만 표시, 데이터 미노출
- 조회 버튼 클릭 후 SummaryBar + Table + Pagination 동시 노출 (Enter 키 조회 가능)
- 행 클릭 → 상세 모달 오픈 (탭으로 열지 않음)
- 등록 버튼 없음 (클레임은 고객/CS의 신청 행위로만 생성됨)

## 상세 모달 (ClaimDetail)
탭 구성: **기본정보 / 클레임 상품 / 처리이력**

### 기본정보 탭
- 읽기 모드: 클레임번호, 원주문번호, 입점사, 구매자, 유형, 상태, 신청경로, 귀책, 환불금액, 추가배송비, 신청일시, 처리완료일시, 신청사유, CS 메모, 최종수정 정보
- 편집 모드: 귀책, CS 메모만 수정 가능 (귀책 판단 액션에 해당)

### 클레임 상품 탭
- 클레임에 포함된 주문상품별 수량·환불금액·교환옵션(교환인 경우)·재고복구 여부를 표로 표시 (읽기 전용)

### 처리이력 탭
- 클레임 신청부터 처리 완료까지의 이력을 타임라인으로 표시 (읽기 전용)

## 상태 전이 액션 (모달 하단 고정 영역)
- 상태 = 접수: **처리 시작** 버튼 → 처리중으로 전이, 이력에 기록
- 상태 = 처리중: **반려** / **완료 처리** 버튼
  - 반려 시 반려사유 입력 필수, 반려사유는 이력에 기록되며 고객에게 전달되는 것으로 간주
  - 완료 처리 시 처리완료일시가 기록되고 이력에 추가됨
- 상태 = 완료/반려: 액션 버튼 없음 (최종 상태)

## 비고
- 실 서비스에서는 반품·교환 신청기간(배송완료 후 10일 이내) 만료 시 배치(`ClaimExpireBatch`, 매일 02:00)가 자동으로 상태를 만료 처리하며, 검수 완료 후 영업일 3일 이내 환불이 이루어진다. 본 화면은 이러한 배치·PG 연동을 mock으로 표현하지 않는다.
