# 등급 기준 관리 (GradeCriteriaPage)

## 개요
회원 등급(New/Runner/Pacer/Elite) 4단계의 산정 기준과 등급별 혜택을 관리하는 설정 화면.
(ADM-050-002, FR-MBR-004, `member_grade_discount_replica`)

목록 검색이 필요 없는 고정 4행 테이블로, [회원 목록](../list/MemberPage.spec.md) 화면과 달리 필터바·페이지네이션이 없다.

## 등급 산정 기준
등급은 **최근 3개월 구매확정금액**과 **활동지수** 중 더 높은 등급 기준을 충족하는 쪽으로 결정된다 (구매금액과 활동지수를 합산하지 않음).

| 등급 | 구매금액 기준 | 활동지수 기준 |
|------|------|------|
| New | - | - |
| Runner | 100만원 이상 | 10점 이상 |
| Pacer | 200만원 이상 | 20점 이상 |
| Elite | 300만원 이상 | 30점 이상 |

## 등급별 혜택
| 등급 | 포인트 적립률 | 무료배송 기준 | 월 지급 쿠폰 |
|------|------|------|------|
| New | 0.5% | 5만원 이상 | 0장 |
| Runner | 1.0% | 3만원 이상 | 1장 |
| Pacer | 1.5% | 2만원 이상 | 2장 |
| Elite | 2.0% | 무조건 무료 | 3장 |

무료배송 기준이 0원인 등급(Elite)은 "무조건 무료"로 표시한다.

## 목록 테이블
| 컬럼 | 설명 |
|------|------|
| 등급 | 배지, New→Elite 고정 순서 |
| 구매금액 기준 | 원 단위, 편집 모드에서 숫자 입력 |
| 활동지수 기준 | 점 단위 |
| 포인트 적립률 | % 단위, 소수점 첫째자리까지 |
| 무료배송 기준 | 원 단위, 0 입력 시 "무조건 무료"로 표시 |
| 월 지급 쿠폰 | 매월 정기 지급되는 등급 쿠폰 수 |
| 최종수정 | 수정자 / 수정일시 |

## 규칙
- 4개 등급 행은 고정이며 추가·삭제할 수 없다
- 상단 편집 버튼 클릭 시 전체 행이 동시에 입력모드로 전환된다 (행별 개별 편집 아님)
- 저장 시에만 반영, 취소 시 편집 전 값으로 원복
- 저장 시 4행 모두 최종수정자·수정일시가 갱신된다

## 비고
- 실 서비스에서는 이 기준값이 `member_grade_discount_replica` 테이블에 10분 주기 배치로 동기화되어 주문·할인 계산에 실시간 반영되며, 등급 재산정 자체는 매월 1일 `MemberGradeBatch`가 수행한다(등급 재산정 로직은 [회원 목록 화면](../list/MemberPage.spec.md) 비고 참고). 본 화면은 기준값 자체의 조회·수정만 다루며 배치·동기화는 mock으로 구현하지 않는다.
