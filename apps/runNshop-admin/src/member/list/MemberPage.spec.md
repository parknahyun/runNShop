# 회원 목록 (MemberPage)

## 개요
플랫폼에 가입한 회원을 검색·조회하고 상태·포인트·쿠폰을 관리하는 현황목록 화면.
(ADM-050-001, FR-MBR-002/004/005/006, `mbr_member` + `mbr_member_grade` + `mbr_point` + `mbr_member_coupon`)

회원 개인정보(이름·이메일·휴대폰 등)를 다루는 화면이므로 다른 현황목록과 달리 **검색어 없이는 목록을 노출하지 않는다.**

## 등급 (grade)
| 코드 | 라벨 | 최근 3개월 구매금액 | 활동지수 |
|------|------|------|------|
| NEW | New | - | - |
| RUNNER | Runner | 100만원 이상 | 10점 이상 |
| PACER | Pacer | 200만원 이상 | 20점 이상 |
| ELITE | Elite | 300만원 이상 | 30점 이상 |

구매금액·활동지수 중 더 높은 등급 기준을 충족하는 쪽으로 산정한다. 등급별 혜택(적립률·무료배송·월 쿠폰 수)은 [등급 기준 관리](../grade/GradeCriteriaPage.spec.md) 화면에서 관리한다.

## 상태 (status)
| 코드 | 라벨 | 의미 |
|------|------|------|
| ACTIVE | 정상 | 정상 이용 가능 |
| LOCKED | 잠금 | 로그인 5회 실패로 3일간 잠김 (FR-MBR-002) |
| INACTIVE | 정지 | 운영자에 의한 이용 정지 |
| WITHDRAWN | 탈퇴 | 회원 탈퇴 처리 완료, 거래데이터는 법령에 따라 보존 |

## 필터바
- 키워드 (이름 / 이메일 / 휴대폰) — **1개 이상 입력 필수**, 미입력 시 조회 버튼 클릭해도 검색되지 않고 안내 메시지 노출
- 등급 선택
- 상태 선택
- 가입일 기간 (from ~ to)
- 조회 버튼

## 요약바
전체 / 정상 / 잠금 / 정지 / 탈퇴 건수 표시 (조회 후 노출)

## 규칙 (현황목록 공통 + 개인정보 조회 특칙)
- 진입 시 TitleBar + FilterBar만 표시, 데이터 미노출
- **키워드(이름/이메일/휴대폰) 미입력 시 조회 불가** — 조회 버튼 클릭 시 안내 메시지만 노출되고 목록은 그대로 비노출 상태 유지
- 조회 성공 시 SummaryBar + Table + Pagination 동시 노출 (Enter 키 조회 가능)
- 행 클릭 → 상세 모달 오픈 (탭으로 열지 않음)
- 등록 버튼 없음 (회원은 자가 가입으로만 생성됨)
- 회원 목록 검색·상세 조회·상태변경·포인트지급·쿠폰발급은 모두 `adt_member_access_log`에 접근 이력이 자동 기록되는 개인정보 조회 행위다 (access_type: LIST/DETAIL/ACTION, target_type: MEMBER/MEMBER_POINT/MEMBER_COUPON). 검색어·회원명은 로그에 마스킹 저장된다(예: `010-****-5678`). 본 화면은 로그 기록 자체를 시뮬레이션하지 않으며 화면 동작만 구현한다.

## 상세 모달 (MemberDetail)
탭 구성: **기본정보 / 주문내역 / 클레임이력 / 포인트이력 / 쿠폰목록**

### 기본정보 탭
- 읽기 모드: 회원ID, 회원번호, 이름, 가입경로, 이메일, 휴대폰, 상태, 등급, 누적구매금액, 활동지수, 포인트잔액, 가입일시, 최근로그인, 탈퇴일시, 최종수정 정보
- 편집 모드: **상태**만 변경 가능 (정상/잠금/정지/탈퇴) — 계정 잠금 해제는 상태를 "정상"으로 변경하는 것으로 처리한다 (별도의 잠금해제 버튼을 두지 않음)
- 이름·이메일·휴대폰 등 회원이 직접 등록한 개인정보는 어드민에서 직접 수정하지 않는다

### 주문내역 탭
- 이 회원의 주문 목록을 표로 표시 (읽기 전용, 주문 상세로의 이동은 제공하지 않음)

### 클레임이력 탭
- 이 회원이 신청한 클레임 목록을 표로 표시 (읽기 전용)

### 포인트이력 탭
- 상단에 포인트 수동 지급 폼(지급 포인트·지급 사유) — 지급 시 포인트이력에 적립 건으로 추가되고 회원의 포인트잔액에 즉시 반영됨
- 이력 표: 구분(적립/사용/복원/소멸) / 포인트 / 변경 후 잔액 / 사유 / 일시 (최신순)

### 쿠폰목록 탭
- 상단에 쿠폰 수동 발급 폼(발급 쿠폰 선택) — 발급 시 목록에 사용가능 상태로 추가됨
- 보유 쿠폰 표: 쿠폰ID / 쿠폰명 / 상태(사용가능/사용완료/만료) / 발급일시 / 만료일시 / 사용일시

## 비고
- 실 서비스에서는 매월 1일 `MemberGradeBatch`가 최근 3개월 구매금액·활동지수를 집계해 등급을 자동 재산정하고, 등급 상승 시 즉시 혜택 쿠폰을 지급하며 하락에는 1개월 유예를 둔다. 본 화면은 등급을 표시만 하며 배치 로직은 mock으로 구현하지 않는다.
- 활동지수는 구매인증리뷰(+2)·러닝기록공유(+1)·크루활동참여(+1)·챌린지완료(+3)·QnA답변채택(+2) 등의 활동으로 누적된다 (정책서 §4.3).
