# 즉시할인 관리 (EventPricePage)

## 개요
기간·수량 한정 즉시할인을 등록·관리하는 현황목록 화면. 하나의 행사가 여러 상품을 함께 묶어 진행한다
(상품 단위가 아니라 행사 단위로 관리하며, 각 상품마다 개별 수량한정 설정을 가질 수 있다).
행사는 **할인율(%)** 기준으로 관리한다 — 행사에 기본 할인율을 지정하고, 상품을 추가할 때 기본값을 그대로 쓰거나 상품별로 조정할 수 있다.
다만 상품별로 최종 확정되는 할인은 결국 **정액할인**이다 — 할인율은 입력을 돕는 보조 값일 뿐, 실제로 상품에 저장·적용되는 것은 그 상품의 정상가를 기준으로 확정된 할인가(원)이며, 이 값은 이후 다시 계산되지 않고 고정된다(쿠폰/장바구니할인처럼 매번 조건에 따라 재계산되는 정률할인과 다름).
(ADM-030-002, FR-PRO-002, `prm_event_price` + 적용상품)

## 상태
| 코드 | 라벨 |
|------|------|
| ACTIVE | 진행중 |
| ENDED | 종료 |

상태는 행사 단위로 관리한다. 개별 상품의 품절 여부는 상품별 수량한정·잔여수량으로 별도 표시한다
(하나의 행사 안에서 일부 상품만 품절될 수 있으므로 행사 전체 상태와는 구분).

## 필터바
- 키워드 (즉시할인ID / 행사명 / 적용상품명)
- 상태 선택 (전체/진행중/종료)
- 조회 버튼

## 요약바
전체 / 진행중 / 종료 건수 표시 (조회 후 등록 버튼과 함께 노출)

## 규칙 (현황목록 공통)
- 진입 시 TitleBar + FilterBar만 표시, 데이터 미노출
- 조회 버튼 클릭 후 SummaryBar + Table + Pagination 동시 노출 (Enter 키 조회 가능)
- 행 클릭 → 상세 모달 오픈 (탭으로 열지 않음)
- 등록 버튼 → 등록 모달 오픈

## 즉시할인 등록 (AddEventPriceModal)
단일 스텝 등록: 행사명, **기본 할인율(%)**, 상태, 시작/종료 일시.
등록 시 적용상품은 빈 상태로 생성되며, 등록 후 상세 모달에서 상품을 추가한다.

## 상세 모달 (EventPriceDetail)
탭 구성: **기본정보 / 적용상품**

### 기본정보 탭
- 읽기 모드: 즉시할인ID, 행사명, 기본 할인율, 상태, 적용상품 수, 시작/종료 일시, 등록/수정 정보
- 편집 모드: 행사명, 기본 할인율, 상태, 시작/종료 일시 수정 가능
- 기본 할인율을 바꿔도 이미 추가된 상품의 할인율에는 영향을 주지 않는다 (신규 추가 시 기본값으로만 사용)

### 적용상품 탭
- 상품 검색 팝업에서 상품을 선택하면 **할인율(%)**과 **할인가(원)** 입력 화면으로 전환 (할인율 기본값 = 행사 기본 할인율)
- 할인율과 할인가는 서로 연동되어 계산된다 — 둘 중 하나를 입력하면 다른 값이 정상가 기준으로 자동 갱신된다 (할인가 = 정상가 × (1-할인율))
- 할인금액(정상가 - 할인가)을 참고용으로 함께 표시 — 상품에 최종 저장되는 것은 이 할인금액 기준의 정액할인이다
- 즉 할인율로 관리하는 것이 기본이지만, 상품별로 할인가(금액)를 직접 입력해 조정하는 것도 가능하다
- 수량 한정 체크 시 총수량 필수, 잔여수량은 총수량과 동일하게 초기화
- 이미 추가된 상품은 "수정" 버튼으로 할인율/할인가·수량한정·잔여수량을 다시 조정할 수 있음
- 삭제 가능, 저장 시에만 반영(취소 시 원복)

## 적용상품 구조
```typescript
interface EventPriceProduct {
  productId: string
  productName: string
  originalPrice: number
  discountRate: number   // 이 할인율·할인가를 산정할 때 사용한 할인율(%) — 입력 편의용 참고값
  eventPrice: number      // 상품에 최종 확정된 할인가(원). 정액할인으로 저장·적용되는 값
  quantityLimit: boolean
  totalQuantity: number | null
  remainingQuantity: number | null
}
```

## 비고
- 실 서비스에서는 잔여수량을 Redis로 실시간 관리(주문 시 DECR·취소 시 INCR)하며, 상품별로 소진 시 `EventPriceSoldOut` 이벤트를 발행한다. 본 화면의 잔여수량 조정은 관리자 화면상의 mock 표현이다.
