# 수량별 할인 관리 (QuantityDiscountPage)

## 개요
동일 입점사·동일 판매가 상품을 묶어 구매 수량 구간별 할인율을 적용하는 현황목록 화면.
(ADM-030-004, FR-PRO-003, `prm_quantity_discount` + `prm_quantity_discount_product` + `prm_quantity_discount_tier`)

## 상태
| 코드 | 라벨 |
|------|------|
| ACTIVE | 진행중 |
| ENDED | 종료 |

## 적용 조건 (정책, 3가지 모두 충족)
- MD가 수량 할인 행사로 설정한 상품
- 동일 입점사(vendor)
- 동일 판매가(price_sale)

장바구니 수량 변경 시 그룹 전체가 재계산되며, 그룹 내 다른 상품의 적용 구간도 함께 바뀔 수 있다.

## 구간설정 기준 (tierScope)
| 코드 | 라벨 | 의미 |
|------|------|------|
| PER_PRODUCT | 적용상품별 | 구매수량을 적용상품별로 개별 카운트하여 구간을 판정한다 |
| TOTAL | 적용상품전체 | 구매수량을 적용상품 전체의 합산 수량으로 카운트하여 구간을 판정한다 |

등록 시 결정하며 상세의 기본정보 탭에서 이후에도 변경할 수 있다.

## 부분취소 정책 (partialCancelPolicy)
| 코드 | 라벨 | 의미 |
|------|------|------|
| KEEP | 할인 유지 | 주문 일부가 취소되어도 할인 혜택을 그대로 유지한다 |
| RECALCULATE | 재계산 | 남은 구매수량 기준으로 구간을 다시 판정하고 할인을 재계산한다 |
| DENY | 부분취소 불가 | 이 수량별 할인이 적용된 주문은 부분취소 자체를 허용하지 않는다 |

등록 시 결정하며 상세의 기본정보 탭에서 이후에도 변경할 수 있다.

## 필터바
- 키워드 (수량할인ID / 행사명 / 입점사)
- 상태 선택
- 조회 버튼

## 요약바
전체 / 진행중 / 종료 건수 표시 (조회 후 등록 버튼과 함께 노출)

## 목록 테이블
| 컬럼 | 설명 |
|------|------|
| 수량할인ID | QTD-001 형식 |
| 행사명 | 클릭 시 상세 모달 오픈 |
| 입점사 | |
| 적용상품 | 등록된 상품 수 |
| 구간수 | 등록된 할인 구간 수 |
| 기간 | 시작일 ~ 종료일 |
| 상태 | 배지 |
| 최종수정 | 수정자 / 수정일시 |

## 규칙 (현황목록 공통)
- 진입 시 TitleBar + FilterBar만 표시, 데이터 미노출
- 조회 버튼 클릭 후 SummaryBar + Table + Pagination 동시 노출 (Enter 키 조회 가능)
- 행 클릭 → 상세 모달 오픈 (탭으로 열지 않음)
- 등록 버튼 → 등록 모달 오픈

## 등록 (AddQuantityDiscountModal)
단일 스텝 등록: 행사명, 입점사명, 상태, 구간설정 기준, 부분취소 정책, 시작일/종료일.
등록 시 적용상품·구간은 빈 상태로 생성되며, 등록 후 상세 모달에서 추가한다.

## 상세 모달 (QuantityDiscountDetail)
탭 구성: **기본정보 / 적용상품 / 구간설정**

### 기본정보 탭
- 읽기 모드: 수량할인ID, 행사명, 입점사, 상태, 적용상품/구간 수, 구간설정 기준, 부분취소 정책, 기간, 등록/수정 정보
- 편집 모드: 행사명, 입점사, 상태, 구간설정 기준, 부분취소 정책, 시작/종료일 수정 가능

### 적용상품 탭
- 상품 검색 팝업으로 추가, 첫 상품 등록 후에는 동일 판매가 상품만 추가 가능(정책 검증)
- 삭제 가능, 저장 시에만 반영(취소 시 원복)

### 구간설정 탭
- 상단에 현재 구간설정 기준(적용상품별/적용상품전체)과 그 의미를 안내
- 최소수량/최대수량(비우면 상한 없음)/할인율로 구간 추가
- 구간은 최소수량 오름차순으로 정렬 표시
- 삭제 가능, 저장 시에만 반영(취소 시 원복)
