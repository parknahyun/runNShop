# 장바구니할인 관리 (CartDiscountPage)

## 개요
주문 금액 구간에 따라 자동 적용되는 장바구니 할인을 등록·관리하는 현황목록 화면.
(ADM-030-005, FR-PRO-004, `prm_cart_discount`)

## 상태
| 코드 | 라벨 |
|------|------|
| ACTIVE | 진행중 |
| ENDED | 종료 |

## 적용단위 / 할인유형 / 부분취소정책
| 구분 | 코드 | 라벨 |
|------|------|------|
| 적용단위 | PLATFORM / VENDOR | 플랫폼 공통 / 입점사별 |
| 할인유형 | FIXED / RATE | 정액 / 정률 |
| 부분취소정책 | KEEP / RECALCULATE / DENY | 할인 유지 / 재계산 / 부분취소 불가 |

## 필터바
- 키워드 (장바구니할인ID / 할인명)
- 상태 선택
- 조회 버튼

## 요약바
전체 / 진행중 / 종료 건수 표시 (조회 후 등록 버튼과 함께 노출)

## 목록 테이블
| 컬럼 | 설명 |
|------|------|
| 장바구니할인ID | CTD-001 형식 |
| 할인명 | 클릭 시 상세 모달 오픈 |
| 적용단위 | 플랫폼 공통 / 입점사별 |
| 최소주문금액 | |
| 할인 | 정액(`N원 할인`) 또는 정률(`N% 할인 (최대 M원)`) |
| 부분취소정책 | |
| 기간 | 시작일 ~ 종료일 |
| 상태 | 배지 |
| 최종수정 | 수정자 / 수정일시 |

## 규칙 (현황목록 공통)
- 진입 시 TitleBar + FilterBar만 표시, 데이터 미노출
- 조회 버튼 클릭 후 SummaryBar + Table + Pagination 동시 노출 (Enter 키 조회 가능)
- 행 클릭 → 상세 모달 오픈 (탭으로 열지 않음)
- 등록 버튼 → 등록 모달 오픈

## 등록 (AddCartDiscountModal)
단일 스텝 등록: 할인명, 적용단위, 최소주문금액, 부분취소정책, 할인유형/값(+최대할인금액), 기간, 상태.

## 상세 모달 (CartDiscountDetail)
읽기/편집 토글 방식의 단일 화면 (하위 탭 없음)
- 읽기 모드: 장바구니할인ID, 적용단위, 최소주문금액, 할인 내용, 상태, 부분취소정책, 기간, 등록/수정 정보
- 편집 모드: 할인명, 적용단위, 최소주문금액, 상태, 할인유형/값(+최대할인금액), 부분취소정책, 기간 수정 가능

## 비고
- 쿠폰과의 중복 적용 여부는 프로모션 정책상 개별 제어 대상이나, 현재 스키마에는 별도 플래그가 없어 본 화면 범위에서는 다루지 않는다.
