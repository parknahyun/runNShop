# 기획전 관리 (ExhibitionPage)

## 개요
프로모션 목적의 기획전(상품목록·기간·배너)을 등록하고 관리하는 목록 화면. (ADM-030-001)

## 상태
| 코드 | 라벨 |
|------|------|
| DRAFT | 미게시 |
| SCHEDULED | 예정 |
| ACTIVE | 진행중 |
| ENDED | 종료 |

## 필터바
- 키워드 (기획전ID / 기획전명)
- 상태 선택 (전체/미게시/예정/진행중/종료)
- 기간 (시작일 ~ 종료일)
- 조회 버튼

## 요약바
전체 / 진행중 / 예정 / 미게시 / 종료 건수 표시

## 목록 테이블
| 컬럼 | 설명 |
|------|------|
| 기획전ID | EXH-001 형식 |
| 기획전명 | 클릭 시 상세 탭 오픈 |
| 상태 | 배지 |
| 기간 | YYYY-MM-DD ~ YYYY-MM-DD |
| 상품수 | N개 |
| 소속 프로모션 | 이 기획전에 묶인 프로모션 수 (없으면 -) |
| 노출순서 | MD 수동 노출 순서 |
| 최종수정 | 수정자 / 수정일시 |

## 기획전 등록 (AddExhibitionModal)
단일 스텝 등록: 기획전명, 배너 이미지 URL, 배너 링크 URL, 상태, 시작일/종료일.
등록 시 상품 목록은 빈 상태로 생성되며, 등록 후 상세 탭에서 상품을 추가한다.

## 상세 탭 (ExhibitionDetail)
탭 구성: **기본정보 / 상품관리 / 소속 프로모션 / 미리보기 / 변경이력**

### 기본정보 탭
- 제목 + 편집 버튼 같은 줄
- 읽기 모드: 기획전ID, 기획전명, 노출순서, 상태, 배너 이미지/링크, 시작/종료일, 등록/수정 정보
- 편집 모드: 기획전명, 배너 이미지/링크, 상태, 노출순서, 시작/종료일 수정 가능

### 상품관리 탭
- 기획전에 포함된 상품 테이블 (순서, 상품ID, 상품명, 브랜드, 가격, 상태)
- 상품 검색 팝업으로 신규 상품 추가 (중복 추가 불가)
- 행별 순서 이동(↑/↓), 삭제
- 저장 시에만 기획전 데이터에 반영 (취소 시 원복)

### 소속 프로모션 탭
- 이 기획전에 묶인 프로모션(즉시할인·쿠폰할인·수량별 할인·장바구니할인) 테이블 (순서, 유형, 프로모션ID, 프로모션명)
- 프로모션 검색 팝업으로 신규 프로모션 추가 (중복 추가 불가)
- 행별 순서 이동(↑/↓), 삭제
- 저장 시에만 기획전 데이터에 반영 (취소 시 원복)

### 미리보기 탭
모바일 프레임 내 배너 이미지 + 상품 그리드 시각화

### 변경이력 탭
변경일시 / 변경자 / 변경내용 테이블

## 상품 구조
```typescript
interface ExhibitionProduct {
  productId: string
  productName: string
  brand: string
  price: number
  status: string      // 판매중 / 품절 등 상품 마스터 상태 스냅샷
  sortOrder: number
}
```

## 소속 프로모션 구조
```typescript
interface ExhibitionPromotion {
  promotionType: 'EVENT_PRICE' | 'COUPON' | 'QUANTITY_DISCOUNT' | 'CART_DISCOUNT'
  promotionId: string
  promotionName: string
  sortOrder: number
}
```

## 비고
- 과거 별도 화면이었던 "프로모션 그룹 관리"는 폐지되었다. 여러 프로모션을 묶어 관리하는 기능은 기획전의 "소속 프로모션" 탭으로 일원화되었다.
- 기획전과 무관하게(플랫폼 전역으로) 여러 프로모션을 묶어야 하는 경우는 현재 화면 범위 밖이며, 필요 시 별도 논의가 필요하다.
