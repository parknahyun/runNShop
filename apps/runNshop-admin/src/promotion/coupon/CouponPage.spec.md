# 쿠폰할인 관리 (CouponPage)

## 개요
플랫폼·입점사가 발행하는 쿠폰을 등록·관리하는 현황목록 화면. (ADM-030-003, FR-PRO-001, `prm_coupon`)

## 상태
| 코드 | 라벨 |
|------|------|
| ACTIVE | 활성 |
| INACTIVE | 비활성 |
| EXHAUSTED | 소진 |

## 쿠폰유형 / 발행 주체 / 적용회원 / 적용상품 / 적용 단위 / 할인 유형 / 발급 방식
| 구분 | 코드 | 라벨 |
|------|------|------|
| 쿠폰유형 | PRODUCT / CART | 상품쿠폰 / 장바구니쿠폰 |
| 발행주체 | PLATFORM / VENDOR | 플랫폼 / 입점사 |
| 적용회원 | ALL / GRADE / MANUAL | 전체 / 회원등급(다중선택) / 임의지정(엑셀업로드) |
| 적용상품 | ALL / MANUAL / CATEGORY | 전체 / 임의선택(팝업검색, 다중선택) / 표준카테고리(다중선택) |
| 적용단위 | ORDER / PRODUCT / CATEGORY | 주문 / 상품 / 카테고리 |
| 할인유형 | FIXED / RATE | 정액 / 정률 |
| 발급방식 | DOWNLOAD / AUTO / ADMIN | 다운로드 / 자동발급 / 관리자 지급 |

적용회원과 적용상품은 서로 독립적인 두 축이다 — 예: "Elite 등급"이면서 "러닝화 카테고리"에만 적용되는 쿠폰도 구성 가능하다.

**쿠폰유형**은 등록 시 결정되며 이후 변경할 수 없다. **장바구니쿠폰**은 주문 전체에 적용되는 쿠폰이므로 적용상품이 항상 "전체"로 고정되고, 상세의 적용상품 탭에서도 유형 선택이 잠긴다. **상품쿠폰**은 적용상품을 임의선택/표준카테고리/전체 중에서 자유롭게 구성할 수 있다.

## 부분취소 정책 (partialCancelPolicy)
**장바구니쿠폰(couponType=CART)에만 적용**되는 정책이다. 상품쿠폰은 특정 상품에 결부되어 있어 해당 상품이 취소되면 혜택도 자연히 함께 무효화되므로 이 정책이 필요하지 않다.

| 코드 | 라벨 | 의미 |
|------|------|------|
| KEEP | 쿠폰 유지 | 주문 일부가 취소되어도 쿠폰 혜택 금액을 그대로 유지한다 |
| RECALCULATE | 재계산 | 남은 주문 금액 기준으로 쿠폰 혜택을 다시 계산한다 |
| DENY | 부분취소 불가 | 이 쿠폰이 적용된 주문은 부분취소 자체를 허용하지 않는다 |

등록 시 쿠폰유형이 장바구니쿠폰인 경우에만 등록 모달과 기본정보 탭에 노출되며, 상품쿠폰에서는 화면에 노출되지 않는다.

## 필터바
- 키워드 (쿠폰ID / 쿠폰코드 / 쿠폰명)
- 쿠폰유형 선택
- 발행주체 선택
- 상태 선택
- 조회 버튼

## 요약바
전체 / 활성 / 비활성 / 소진 건수 표시 (조회 후 등록 버튼과 함께 노출)

## 목록 테이블
| 컬럼 | 설명 |
|------|------|
| 쿠폰ID | CPN-001 형식 |
| 쿠폰명 | 클릭 시 상세 모달 오픈 |
| 쿠폰유형 | 상품쿠폰 / 장바구니쿠폰 |
| 할인 | 정액(`N원 할인`) 또는 정률(`N% 할인 (최대 M원)`) |
| 발급/한도 | 발급건수 / 발급한도(무제한 표기 가능) 2줄 표기 |
| 유효기간 | 시작일 / 종료일 2줄 표기 |
| 상태 | 배지 |
| 최종수정 | 수정자 / 수정일시 2줄 표기 |

쿠폰코드·발행주체는 그리드에는 노출하지 않으며 상세(기본정보 탭)에서 확인한다.

## 규칙 (현황목록 공통)
- 진입 시 TitleBar + FilterBar만 표시, 데이터 미노출
- 조회 버튼 클릭 후 SummaryBar + Table + Pagination 동시 노출 (Enter 키 조회 가능)
- 행 클릭 → 상세 모달 오픈 (탭으로 열지 않음)
- 등록 버튼 → 등록 모달 오픈

## 쿠폰할인 등록 (AddCouponModal)
단일 스텝 등록: 쿠폰유형(+장바구니쿠폰인 경우 부분취소 정책), 쿠폰코드/쿠폰명, 발행주체(+입점사명), 비용분담률, 적용단위,
할인유형/할인값(+최대할인금액), 최소주문금액, 발급방식/발급한도, 유효기간, 상태.
발행주체가 입점사인 경우 입점사명 입력 필수. 등록 시 발급건수는 0으로 시작하며,
**적용회원·적용상품은 이 모달에서 다루지 않는다** — 등록 후 자동으로 열리는 상세의 "적용회원"/"적용상품" 탭에서 구성한다
(신규 쿠폰은 적용회원=전체로 시작하며, 적용상품은 상품쿠폰이면 임의선택(빈 목록), 장바구니쿠폰이면 전체로 고정되어 시작한다).
쿠폰유형은 등록 후 변경할 수 없다.

## 상세 모달 (CouponDetail)
탭 구성: **기본정보 / 적용회원 / 적용상품 (N) / 보유회원 (N)**

### 기본정보 탭
- 읽기/편집 토글. 읽기 모드: 쿠폰ID/코드, 쿠폰유형, 발행주체·비용분담률, 상태, 적용단위, 할인 내용, 최소주문금액, 발급방식/발급현황, 유효기간, (장바구니쿠폰인 경우) 부분취소 정책, 등록/수정 정보
- 편집 모드: 쿠폰명, 상태, 할인유형/값(+최대할인금액), 최소주문금액, 발급한도, 유효기간, (장바구니쿠폰인 경우) 부분취소 정책 수정 가능
- 쿠폰코드·쿠폰유형·발행주체·발급건수는 등록 후 변경 불가(읽기 전용)

### 적용회원 탭
- 적용회원 유형(전체/회원등급/임의지정)을 선택
- **회원등급**: New/Runner/Pacer/Elite 체크박스 다중선택
- **임의지정**: 엑셀 파일 업로드(.xlsx/.xls/.csv) → 파일명과 확인된 대상 회원 수 표시 (실제 파싱은 백엔드 연동 후 처리, 화면은 mock)
- 저장 시에만 쿠폰 데이터에 반영(취소 시 원복) — 다른 탭과 독립적으로 저장

### 적용상품 탭 (테이블 형태)
- 상단에서 적용상품 유형(전체/임의선택/표준카테고리)을 선택
- **전체**: "전체 상품에 적용됩니다." 안내만 표시 (별도 선택 없음)
- **임의선택**: "+ 상품 추가" → 검색 팝업에서 상품 추가, 선택된 상품은 표(상품ID/상품명/브랜드/정상가/관리)로 표시, 행별 "삭제"
- **표준카테고리**: 전체 표준카테고리를 표(선택/카테고리ID/카테고리명)로 나열하고 체크박스로 다중선택 (행 클릭으로도 토글)
- 유형을 바꿔도 서로의 선택값은 유지되며, 저장 시 최종 선택된 유형의 값만 반영된다
- 저장 시에만 쿠폰 데이터에 반영(취소 시 원복) — 다른 탭과 독립적으로 저장
- **장바구니쿠폰(couponType=CART)인 경우 적용상품 유형이 "전체"로 고정되며 선택자체가 비활성화된다** (안내문 노출)

### 보유회원 탭
- 실제로 쿠폰이 발급된 회원 목록을 표(회원ID/회원명/등급/발급경로/발급일시/사용일시/상태)로 표시
- 발급경로: 다운로드/자동발급/관리자 지급/**임의발행**
- 상태: 미사용/사용완료/만료
- "+ 임의발행" → 회원 검색 팝업(회원ID/회원명/이메일 검색, 다중선택) → "선택 발행" 시 즉시 보유회원 목록에 추가되고 발급건수가 함께 증가한다 (별도의 저장/취소 없이 즉시 반영되는 액션)
- 이미 발급된 회원은 검색 결과에서 재선택할 수 없다(중복 발행 방지)

## 비고
- 정책상 유효기간은 발행일 기준 최대 90일이 원칙이나 이벤트성 쿠폰은 예외적으로 별도 기간 설정이 가능하므로, 화면에서는 상한을 강제하지 않고 자유 입력으로 둔다.
- 회원등급 쿠폰은 등급 승급 시 즉시 지급 + 매년 12/31 일괄 지급되며, 등급별 지급 수량(New 0 / Runner 1 / Pacer 2 / Elite 3장)은 별도 등급 정책 화면에서 관리한다(본 화면 범위 밖).
