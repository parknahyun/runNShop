# 작업 범위 기준

- 앞으로 수정 및 작성하는 모든 문서의 작업 범위는 **도메인 기준 "Promotion(프로모션)"** 이다.
- 다른 도메인(Order, Payment, Catalog 등) 문서는 Promotion과의 연동·참조 목적으로만 열람하며, 직접 수정하지 않는다. (수정이 필요하면 먼저 사용자에게 확인)
- 문서 작성 시 도출 근거 원칙:
  - 상위 산출물(착수 S0, 범위정의 S1)의 산출물을 근거로 작성한다.
  - 도메인정의서(DB), 정책서를 1차 근거로 사용한다.
  - 후행 산출물(EARS 등)이나 비공식 참고자료(도메인기능표 등)를 도출 근거로 역참조하지 않는다.
- 문서 패턴은 기존 확정 문서(Payment/Order S2·S3)의 형식·레벨을 따른다.
